The overlapping avatars no longer occlude each other, so the user sees a smear of overlapping bot outlines instead of the distinct colored chips. The per-agent hue is also gone from every subagent row.

- Where: `ui/src/styles/chat/details-desktop.css`:596
- Claimed failure: `.chat-details .chat-details-desktop-body .chat-pr__actions-trigger { margin-inline-end: -6px }` also matches the trigger inside `.chat-pr__publication-actions` (the Create PR / menu split button in the Environment branch controls, rendered by ChatBranchActions). The branch test now only checks scroll overflow at the scroll port, so it no longer catches this.
