## F1: Drop-tint ::after on the message surface overrides and hides the dictation edge animation in New Session
- Where: `ui/src/styles/new-session.css`:820
- Claimed failure: The New Session message surface is the same element that gets `agent-chat__input--dictating` (composer.tsx:542-545), whose dictation comet is drawn with `.agent-chat__input--dictating::after` (composer.css:87, specificity 0,1,1). The new `.new-session-page__composer > .agent-chat__input::after` rule (specificity 0,2,1) now targets that same pseudo-element and wins every shared property: `opacity: 0`, `background: var(--accent)` instead of the conic gradient, `inset: 0` instead of -1px, `z-index: 1` instead of 5. When a user starts dictation on the New Session page, the travelling accent edge that signals capture is active is invisible (opacity 0). If they then drag a file over the composer while dictating, they see a flat 10% accent ring masked to 1px instead of the drop tint or the comet. Before this change the drop tint lived on the shell's ::after, so the two never collided.
