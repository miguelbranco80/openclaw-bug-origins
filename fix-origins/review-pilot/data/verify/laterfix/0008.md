## F1: Grid on .chat-activity-group stretches the bubble-mode working pill and summaries to full width
- Where: `ui/src/styles/chat/tool-cards.css`:1038
- Claimed failure: `.chat-activity-group` is now `display: grid`. In bubble mode, `.chat-activity-group--bubble > .chat-activity-group__summary` sets `width: auto`, which overrides the `width: fit-content` from `.chat-inline-disclosure`. A grid item with `width: auto` stretches to fill its column; before, as an inline-flex child of a block container, it shrank to fit its content. The live 'working' bubble summary has a border, an elevated background, an 18px radius and centered dots. It now draws as a wide bar across the whole activity group (up to the 760px max width) instead of a compact pill. Completed bubble summaries likewise get a full-width click target and focus outline.

## F2: Subagent-wait toggle chevron becomes permanently invisible
- Where: `ui/src/styles/chat/tool-cards.css`:139
- Claimed failure: `.chat-tool-row__chevron` now defaults to `opacity: 0`, and every rule that reveals it again is scoped to `.chat-inline-disclosure` (hover, focus-within, aria-expanded) or to file and subagent rows. ChatSubagentWaitLine (chat-handoff-sessions.tsx) puts the same chevron class inside `.chat-subagent-wait__toggle`, which is not a `.chat-inline-disclosure`. Before this change that chevron showed at 0.55 opacity. When a handoff waits on several sessions, the 'Waiting on N sessions' toggle no longer shows a chevron in any state (collapsed, expanded, hovered or focused), so nothing on screen says the line can open or close.

## F5: Tool row text stays highlighted after a mouse click
- Where: `ui/src/styles/chat/tool-cards.css`:295
- Claimed failure: The new `.chat-tool-msg-summary:focus-within { color: var(--text) }` rule matches any focus inside the row, including focus from a mouse click. When a user clicks a tool row to expand or collapse it, or clicks its file link, the button keeps focus, so that row stays in full text color while every other row stays muted. It keeps the hover look until the user clicks somewhere else. The existing focus-visible rule kept the highlight for keyboard focus only.
