# Case 0131: findings to check

## F1: Loading rings disappear under same-origin-only image policies
- Where: `ui/src/styles/base.css`:366
- Claimed failure: If a reverse proxy adds an `img-src 'self'` Content Security Policy, the browser blocks the new `data:` SVG masks even though the Gateway's own policy allows them. The affected spinners previously rendered with CSS borders. After the change, the chat Send button can appear blank while a send is pending, and running-session rings disappear from the sidebar.
