# Case 0076: findings to check

## F1: Desktop size select keeps 88px width but now carries the shared select's wide chevron padding, truncating its value on touch
- Where: `ui/src/components/desktop/desktop-panel.css`:140
- Claimed failure: The desktop sizing select (non-menu presentation, including the desktop-touch-toolbar in document mode) stays at a fixed 88px but now takes settings-select chrome: --field-padding-inline (10px) on the left and calc(26px + 0.5em) on the right (36px in browsers without base-select), plus borders, instead of the old 0 6px padding and 12px type. That leaves about 40-42px for the value. On a coarse-pointer device the global 16px !important select floor applies, so 'Actual' (and 'Match') no longer fit and render as 'Actu...' / 'Matc...' via the new one-line clamp (or are clipped in Firefox). Longer translations are truncated even at desktop type size. The user cannot read the current sizing mode in the touch toolbar.

## F2: Long camera and microphone names become indistinguishable
- Where: `ui/src/styles/components.css`:1138
- Claimed failure: On a wide screen in a browser that supports customizable selects, two camera or microphone labels that share a long prefix and differ only at the end can appear identical in Settings. The popup previously had room to grow with the labels. It now stops at the 340px trigger minimum, clips the distinguishing suffixes, and the device options have no tooltip that reveals the full names.

## F3: The desktop sizing control truncates short mode labels on phones
- Where: `ui/src/components/desktop/desktop-panel.css`:141
- Claimed failure: In the touch desktop viewer at a 430px viewport width, the sizing select remains 88px wide. The new shared padding and 16px touch font leave only 42px for the selected label, so an English mode such as Actual can appear truncated even though it fit with the previous native control.

## F4: The chevron overlaps selected text in right-to-left layouts
- Where: `ui/src/styles/components.css`:1109
- Claimed failure: With Arabic or Persian selected in a browser that supports customizable selects, the chevron moves to the left but the extra padding stays on the right. A long selected value, such as a session group name, can extend under the chevron and obscure the end of the visible label or its ellipsis.

## F5: Systems machine picker loses its keyboard focus indicator
- Where: `ui/src/styles/systems.css`:656
- Claimed failure: At viewport widths of 768px or less, tabbing to the Systems machine picker in standard color mode produces no visible focus indicator. The new shared class removes the focus outline, and the more specific Systems border rule overrides the shared focus border color.
