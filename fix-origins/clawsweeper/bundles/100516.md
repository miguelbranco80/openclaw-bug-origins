- Fix: fix(update): retain plugin activation guidance after core upgrades (#171687)
- What the user saw: After `openclaw update --no-restart` changed both core and plugins, the update report showed cleanup advice instead of telling the operator to restart the Gateway to activate the changes.
- What the fix does: The fix forwards the restart option for every update so the CLI, JSON output, and stored reports can show the Gateway restart reminder after plugin changes.
- What in the causing PR was wrong: The commit introduced the restart reminder but passed `restart: params.coreAlreadyCurrent ? params.opts.restart : undefined`, so the resolver received `undefined` after a core upgrade and its `params.restart === false` check failed.
- Reasoning: PR #143174 introduced the reminder and the condition that excluded core-changing runs. I checked the parent of #140339 and confirmed that core-changing runs already passed the plugin-convergence result to the same next-action resolver, so #140339 moved the existing condition into a shared helper after the defect had already shipped.
