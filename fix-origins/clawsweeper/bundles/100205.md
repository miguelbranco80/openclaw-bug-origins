- Fix: fix(ui): preserve reader disclosure state across tab changes
- What the user saw: A file diff they had opened in the GitHub reader was collapsed when they switched back to its tab.
- What the fix does: The fix memoizes the document's expansion preference so tab changes preserve the user's toggle and a changed preference still updates the disclosure.
- What in the causing PR was wrong: The Solid port added `<details class="lr-file" open={props.expanded}>`, which reapplied the default closed state when a tab revision reached the file component.
- Reasoning: Before the migration, Lit's `?open=${expanded}` binding left the native toggle alone when the expansion preference stayed the same, and the existing GitHub panel E2E explicitly checked that an opened diff stayed open after switching away and back. The migration diff replaced that binding with a reactive Solid `open` binding that could reapply the unchanged default on a tab revision.

Moving focus to an outside control clears only focusInside, so PortaledHovercardController.scheduleClose sees the card as held and leaves it open; moving focus away before the delay can also allow a late card to appear.
