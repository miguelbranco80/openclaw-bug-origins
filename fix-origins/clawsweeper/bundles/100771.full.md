## How this fits together

The Control UI receives session and identity data from the Gateway and retains browser caches between visits. This change lets those caches populate the interface before connection, while live responses replace cached state.

```mermaid
flowchart TD
  A[Browser reload] --> B[Check credential-bound boot record]
  B -->|Usable record| C[Cached agents and sidebar]
  B -->|No usable record| D[Connection splash]
  C --> E[Cached chat transcript]
  C --> F[Gateway connection]
  D --> F
  F --> G[Validate profile and reconcile live data]
  E --> G
```
