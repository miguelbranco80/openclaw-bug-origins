# Rank 104: fix #191659 <- cause #150564

## The bug (from the fix-origins reader)
- Origin: regression (confidence high)
- Fix: fix: preserve command output with long temporary paths (#191659)
- What the user saw: With a sufficiently long temporary directory, buffered Gateway commands failed with EINVAL and affected native child sessions received files without private Git history.
- What the fix does: The fix applies the native-resource broker's socket path byte limit to buffered command output and uses a short private directory under `/tmp` when the configured path exceeds it.
- What in the causing PR was wrong: The broker introduced `const directory = await mkdtemp(path.join(tmpdir(), "oc-spawn-"));` and passed `path.join(directory, "out")` to `server.listen(socketPath)` without checking the Unix socket path length.
- Reasoning: The pre-change side of the command launcher diff shows that existing buffered commands ran through direct Execa, whose output path did not depend on a filesystem Unix socket under the temporary root. PR #150564 routed eligible commands through the broker and added that dependency before launch. The later refactor moved the same socket setup into the worker without changing the path construction.
