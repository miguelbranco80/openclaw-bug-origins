## The bug (from the fix-origins reader)
- Origin: never-worked (confidence high)
- Fix: fix: invitation limits suggest removing people or devices (#199266)
- What the user saw: When an invitation hit the 100-invite or invite-lifetime limit, the Remote access page told the owner to remove people or devices, which would not help.
- What the fix does: Changed the limit_reached copy on the OpenClaw ID Remote access page to a generic 'exceeds a limit, review the error details' message.

- Reasoning: people-error.ts was created in e29577b7d7df with the members/devices-only wording, and at that same commit packages/openclaw-id-protocol/src/authority/apply.ts already refused invite count and lifetime with the same `limit_reached` code, so the message was wrong for invitations from the day it shipped. The only later touch (4ff4f33e0cf) did not change this line per blame.
