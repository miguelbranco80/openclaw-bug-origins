- Fix: fix(process): ease agent exec IO throttling on solid-state disks (#188894)
- What the user saw: Disk-intensive agent commands ran slowly on Linux SSDs when delegated exec isolation was enabled.
- What the fix does: Gateway startup now caps agent exec I/O at 160 MiB/s and 40,960 IOPS per direction on each non-rotational device, subject to inherited limits.
- What in the causing PR was wrong: The original startup code set `const bytesPerSecond = Math.max(1, Math.floor(memoryHigh / 600 / devices.length));` and applied that rate to every backing device, including SSDs.
- Reasoning: The first-parent history and introducing diff show that #188379 added the cgroup startup code and wired it into Linux Gateway startup in the same commit. Its original formula capped a single SSD at about 6.8 MiB/s per direction with a 4 GiB exec memory allowance, so the excessive throttling shipped with the isolation feature.
