- What the fix does: CLI sessions now load bootstrap files from the configured or explicitly overridden workspace and append only the execution folder's AGENTS.md while keeping that folder as the working directory.

- Reasoning: PR #125675 introduced and documented separate bootstrap and execution workspaces, and its runtime layering covered the embedded paths. The parent commit already passed the execution workspace to CLI bootstrap loading, and the later CLI override still fell back to that same directory when the reply path supplied no override. The CLI reply path therefore lacked the new behavior from the start.
