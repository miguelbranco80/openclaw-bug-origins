## How this fits together

After a Gateway restart, main-session recovery reads saved session and transcript state to decide whether to resume an interrupted agent turn. That decision can start a new turn and ultimately deliver a final reply.

```mermaid
flowchart LR
  A[Gateway restart] --> B[Saved session and pending delivery]
  B --> C{Queue owner still active?}
  C -->|Yes| D[Queue settles delivery]
  C -->|No| E[Read transcript and completion custody]
  E --> F{Source authorized?}
  F -->|Yes| G[Resume agent and deliver reply]
  F -->|No| H[Retain or close recovery with notice]
```
