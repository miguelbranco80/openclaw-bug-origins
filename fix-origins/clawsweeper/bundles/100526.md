- Reasoning: The A2A launch wired the outbound sender into durable delivery and introduced the plain missing-URL error in the same commit. The queue code at launch already retried errors that matched neither a typed permanent rejection nor its text patterns, and the new error matched neither. PR #165021 later added the unresolved-token guard with the same classification mistake.
