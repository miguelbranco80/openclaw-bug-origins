## The bug (from the fix-origins reader)
- Origin: regression (confidence medium)
- Fix: fix(anthropic): bind cache carriers to replay policy (#157662)
- What the user saw: Provider plugin authors could see Anthropic requests put a cache checkpoint on transient runtime context or skip a checkpoint on retained context.
- What the fix does: The fix records the provider's carrier-retention decision at the session boundary, preserves it through media projection, and uses it to place Anthropic cache checkpoints.
- What in the causing PR was wrong: The diff added `const retainRuntimeContext = bindsClaudeThinkingPrefix(model)` and used `if (msg.runtimeContextCarrier && !retainRuntimeContext)` to exclude carriers from cache checkpoints even when the plugin retained them.
- Reasoning: I checked that the parent of #140621 already accepted provider retention overrides and left retained carriers eligible for cache checkpoints. The new model-based filter made a retained carrier ineligible when a plugin opted into retention for a model the predicate rejected, a case covered by the fix's fixture. The transient Copilot case had an earlier history because #136990 made its carriers transient while they were still eligible for checkpoints.
