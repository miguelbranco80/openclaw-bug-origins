# Rank 100372: fix #178215 <- cause #134351

## The bug (from the fix-origins reader)
- Origin: regression (confidence high)
- Fix: fix: quote typographic apostrophes in PowerShell launch paths (#178215)
- What the user saw: A managed GitHub command could exit before running if its profile path contained a typographic apostrophe, and the same quoting error could prevent Windows from verifying a Gateway restart.
- What the fix does: The fix uses the shared PowerShell quoting helper for managed GitHub launches and Windows Gateway restart verification.
- What in the causing PR was wrong: The new PowerShell bootstrap passed the profile path through `launcher.map(quotePowerShellLiteral)`, whose `value.replaceAll("'", "''")` left typographic apostrophes unescaped.
- Reasoning: I checked the parent of #134351 and confirmed that gateway exec already supported managed GitHub profiles and passed the profile path in the child environment as `GH_CONFIG_DIR`, where PowerShell did not parse it as source. #134351 introduced a launch-time credential resolver that embedded the path in PowerShell source with ASCII-only escaping, causing the reproduced launch failure. The restart observer had a separate origin in #147437, which introduced the executable and entrypoint checks using the same incomplete escaping.
