- Fix: fix(ui): stop flashing a provisional session row in the agent roster (#178061)
- What the user saw: When creating a session in Show all agents mode, users saw a temporary session row flash in the sidebar and disappear once the session was created.
- What the fix does: The fix limits provisional new-session rows to the session list and removes them from the agent roster and pinned-agent gallery.
- What in the causing PR was wrong: The diff removed the roster’s `<SessionSection ... />` rendering and left `{renderPendingSessionCreateRow(roster.host, card().id)}` directly under the agent header, so the provisional row had no permanent row to hand off to.
- Reasoning: I checked the parent revision and confirmed that expanded agent groups rendered both the provisional row and the ordinary session sections, giving the handoff introduced in #174888 a destination. The #174984 redesign removed those session sections, kept the provisional row under unpinned agents, and added it below the new pinned gallery, so the row disappeared on successful creation.
