## Fix PR #164161 description (by GoldArowana, opened 2026-10-03T08:03:42Z)

```text
## What Problem This Solves

`config patch --file` and `config set --batch-file` hang when their input is a FIFO with no writer.

## User Impact

Unsupported FIFOs now promptly return the existing regular-file error without changing the config. Regular files, symlinks to regular files, UTF-8 contents, and the 8 MiB limit retain their behavior. Windows retains its existing read mode.

## Why This Change Was Made

Open explicit input files with nonblocking read flags on POSIX so the existing descriptor check can reject a FIFO before waiting for a writer. Descriptor cleanup and bounded reads are unchanged. Original fix and regression coverage by @GoldArowana, whose commits are preserved.

No overlap with Pash/Sarah changes.

## Evidence

Linux arm64 / Node 24.21.0, secretless Docker, isolated home/state/config paths; built CLI at `d68eb9cefb93eebc7f8df3377affe96155e88da5` compared with the unchanged input owner from main `38d10371c5f2bf52eb3611860a73571affd03043`:

- Real `openclaw.mjs --profile … config patch --file <fifo>` and `config set --batch-file <fifo>` both hit the 12-second watchdog on base. Candidate exits 1 with the existing regular-file error in 940 ms and 832 ms respectively. Config bytes remain unchanged.
- For both commands, regular files and symlinks apply the requested port value on base and candidate; 8 MiB + 1 byte inputs reject without changing config.
- FIFOs with a waiting writer reject with the same regular-file error on both base and candidate; base only hangs without a writer.
- The two FIFO regressions fail on the base owner; all 22 input tests pass on candidate. `node scripts/run-vitest.mjs src/cli/config-set-input.test.ts --maxWorkers=1`: 1.81 seconds wall time (Vitest 1.05 seconds). Hosted CI timings remain in the checks.
- CLI proof disables startup respawn using the existing process-test environment so the watchdog owns the whole command. No input-reader behavior is mocked in CLI proof.
- Windows/WSL runtime behavior was not exercised.
- Exact-head live smoke: one real `gpt-5-mini` Responses call through a passive proxy, reasoning `low`, output budget 4096, HTTP 200; the local agent returned a text response. Task credentials were deleted afterward.
```
