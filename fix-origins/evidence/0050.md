## What Problem This Solves

Fixes: Deep Research report text in the side panel renders thin on macOS.

## User Impact

User impact: long-form Deep Research reports keep normal macOS text rendering and read crisper; the pane's controls, tabs, status and source list are unchanged.

## Why This Change Was Made

The app body uses antialiased font smoothing, which turns off macOS stem darkening for everything below it. The plugin's own report rule now uses `auto` smoothing, matching what #197458 does for chat message text. The body default stays as is, so pane chrome keeps its current look. Inline citation buttons inside the report prose inherit the report's smoothing.
