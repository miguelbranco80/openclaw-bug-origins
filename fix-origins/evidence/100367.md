## Fix PR #172546 description (by roboclaw-bot, opened 2026-10-14T21:04:33Z)

```text
## What Problem This Solves

Fixes: Side chat shows a plain "Answering from this session…" text line while it waits for an answer, instead of the working indicator every normal chat session uses.

## User Impact

User impact: a pending Side chat answer now shows the same working claw (or the theme's dots/brand mark) and elapsed time as the main transcript. Failure hints and Retry are unchanged.

## Why This Change Was Made

The rail now renders pending turns through the shared `renderChatWorkingIndicator` instead of its own pulsing text hint. The companion owner records when each pending turn started so the elapsed timer survives the panel remounting. The unused `chat.rail.askPending` string and its pulse animation are removed.
```
