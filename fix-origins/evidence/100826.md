## Fix PR #168294 description (by steipete, opened 2026-10-10T07:00:25Z)

```text
## What Problem This Solves

Hidden model reasoning could leak into visible replies. A Chat Completions stream sends `<think>` content, then a native tool-call delta, and then ends with `length` or `content_filter`. Both the managed and direct adapters then emitted the unfinished reasoning text as if it were part of the answer.

The early flush at the native-tool boundary in `packages/ai/src/transports/openai-completions-stream.ts` recovered text from unfinished `<think>` tags before it knew how the stream would end. That boundary flush came in with `78b8f8cf664`.

## Why This Change Was Made

Unfinished-tag recovery is now disabled at the native-tool boundary. Recovery on a normal terminal stop is unchanged, so legitimately unterminated answer text is still recovered when the stream really finishes. Production is +3/−2: a boundary flag.

## User Impact

Reasoning the model never finished stays private. It no longer shows up in replies that hit a token limit or a content filter after a tool call.

## Evidence

- Four HTTP stub cases fail before the fix and pass after it: managed and direct adapters, each with `length` and with `content_filter` after a native tool delta. Before the fix, all four exposed the synthetic reasoning.
- Four focused and sibling transport suites pass (54 tests). They cover normal-stop recovery, truncation, abort/refusal, tool streams, and streaming and non-streaming requests.
- The CI-selected `pnpm test:changed` set passes (32 tests). Formatting, targeted lint and core typecheck also pass.
- `node scripts/check-changed.mjs` was blocked by the env-name budget (456 > 455). That failure was inherited from main and is now fixed there in `060b20e595f`.

Report only, not changed here: in `src/agents/isolated-completion.ts`, output validation runs before usage emission. A content-filtered background completion may therefore drop provider-reported usage. This is source evidence only and has not been reproduced.
```
