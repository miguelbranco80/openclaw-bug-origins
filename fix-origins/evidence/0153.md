## What Problem This Solves

A conversation continuing an existing PR can report that its base is current even after the target branch advances. GitHub PR details may retain an older base SHA while the branch-ref endpoint already names the new tip. Using that PR-detail SHA leaves newer target files out of the workspace. After integrating a newer base, repeated preparation must also avoid resetting the review comparison to that older metadata.

## User Impact

A fresh `refresh_base` integrates the current tip of the verified target repository and branch for both imported PRs and PRs originally published by the conversation. Repeating `prepare_pr` afterward preserves the correct review comparison, so integrated upstream files do not appear as PR changes merely because GitHub's PR details lag.

The accepted PR head and identity remain intact for subsequent publication. A pending conflict continues against its accepted commit; a later fresh refresh picks up further target changes. There are no configuration, schema, dependency, or permission changes.

## Why This Change Was Made

The preparation owner already verifies the PR destination and distinguishes new selection from pending integration. It now uses the existing guarded branch-ref reader for a fresh refresh, and when preparation sees disagreement between the accepted base and the metadata for the same destination. Reading the live ref distinguishes stale metadata from a target that actually moved, without adding a cache or another integration mechanism.

The registered-action regression keeps PR metadata unchanged while the same Git branch advances, then repeats preparation and checks the saved comparison and cached diff. The existing conflict/publication scenario advances the target during a pending conflict and verifies that resolution finishes the earlier target before a fresh refresh imports the new tip. An existing preparation fixture now creates the actual branch it retargets to. The 50-line test-budget allocation covers those missing conditions and that required fixture adaptation.
