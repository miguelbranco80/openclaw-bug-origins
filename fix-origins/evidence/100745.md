## What Problem This Solves

Snapshot-backed cloud sessions wait for redundant remote commands, and a busy Gateway startup can replace a healthy configured Crabbox CLI with an older managed fallback.

## User Impact

Project preparation and initial snapshot capture each save a remote command round trip. This improves cold preparation and changed-commit starts; same-commit reuse keeps its existing verification path.

## Why This Change Was Made

Seed installation completes the prepared checkout in the same command when the admitted project has no executable setup recipe or setup was explicitly skipped. Executable recipes keep their separate authority check before execution.

Runtime preparation and credential scrubbing also share one command. The shell clears forwarded credentials before scrubbing, and native capture still waits for successful cleanup and a current owner. A cleanup failure now stops the incomplete project worker and reports the error before enrollment. Teardown captures retain their existing warning and cleanup behavior.

The configured CLI version probe now allows 30 seconds. A live startup trace showed the healthy probe finishing after 6.9 seconds, beyond the previous five-second budget, and triggering an unnecessary managed fallback. The fake-clock regression verifies that a seven-second successful probe keeps the configured CLI without downloading or writing managed state.
