## What Problem This Solves

PowerShell treats typographic apostrophes as quote delimiters too. Two private helpers escaped only ASCII apostrophes, so a valid managed GitHub profile containing typographic quotes could fail credential lookup before launching the command. The Windows restart observer used the same incomplete quoting for its entrypoint and executable paths.

## User Impact

Managed GitHub commands and Windows restart observation correctly quote paths containing typographic apostrophes. No configuration or migration is required.

## Why This Change Was Made

Both owners now use the existing `quotePowerShellArg`, which already handles ASCII and U+2018–U+201B apostrophes. Delete the two private copies and the test's duplicate setup formatter. Extend the existing profile, target, literal-argv, and restart-observer fixtures; no new test cases or subprocess launches are added.

Credential-host selection, private token handling, missing/insecure-profile refusal, PowerShell command ownership, and scheduled-task restart verification remain unchanged. No configuration, protocol, schema, dependency, SDK, or permission change.

Production: **+9/-16, seven net lines removed**. This is a reproduced-bug exception, not a LARGE cleanup PR. Tests: **+19/-5**.

## Best-effort tradeoffs accepted

None: no defensive guard or supported behavior is removed. This consolidates literal escaping through its already-maintained owner. Real PowerShell parsing is verified on macOS; it is not a native Windows Task Scheduler or live GitHub network claim.

## Evidence

- Before production edits, the restart regression failed at the malformed generated-literal assertion; seven existing restart cases passed. The first real-PowerShell GitHub regression also failed as intended: a valid synthetic profile returned exit 1 instead of the target's exit 7. The remaining known-broken baseline cases were deliberately stopped, so no complete baseline-suite verdict is claimed.
- The fixed actual source launcher passes with Microsoft PowerShell 7.6.7 and Node 26.12.0: typographic profile/target paths, all four typographic apostrophes in literal argv, literal dollar/substitution arguments, selected synthetic credential, exit 7, and empty stderr. No token value was printed and no external network call was needed. Command wall: 54.79 seconds on the shared host.
- Final focused proof: 47 tests passed across the two affected owners, canonical quoting helper, lint-suppressions, and PR-wrapper source closure. All eight GitHub launcher cases ran, including real PowerShell with public/enterprise hosts and available/missing credentials. Source inputs were unchanged throughout. Wrapper wall: 946.42 seconds; all selected Vitest shards: 938.81 seconds; GitHub shard: 776.18 seconds; Windows restart shard: 8.12 seconds on the shared host.
- Independent isolated review completed scoped-clean at P0–P2. Targeted graph types and scoped lint/format passed. Both runtime and static/Madge scans report zero cycles. The changed-check planner classified the four files as core/core-test changes; its broad plan was inspected in dry-run mode, not executed locally.
