## What Problem This Solves

Opening a saved `/settings/model-setup` or `/model-setup` link from New Session briefly retires and rebuilds the unchanged page before opening Models. This repeats the redirect/remount failure fixed for General in #194624.

## User Impact

Model-account setup opens faster without the intermediate New Session rebuild. Explicit first-run setup (`firstRun=1` / `firstRun=explicit`), consent, the account picker, and navigation history retain their existing behavior.

## Why This Change Was Made

Canonicalize the legacy settings destination before route matching, using the same policy in the loader. The outlet can retain its current page while the actual destination loads. No cache, scheduling state, component lifetime override, or new eager dependency is introduced.

The accompanying harness measures all ordered route pairs, legacy aliases and moved-section links, plus Agent tabs, history/bookmarks, reconnect, split/detail panes and drawers. Its external DOM probe distinguishes retained identity, moves, identical-content replacements and transient subtrees. Physical attachment evidence is explicitly distinct from Solid owner disposal; detailed evidence is bounded and marked when truncated. CPU is collected in a separate probe-disabled pass.
