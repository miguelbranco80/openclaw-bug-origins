## What Problem This Solves

Fixes the bundled-plugin category check failing because DeepSeek declares two primary purpose categories.

## User Impact

DeepSeek remains a Models plugin. Its web search provider registration, configuration, and implementation are unchanged; no migration or user action is required.

## Why This Change Was Made

Bundled plugins must declare exactly one primary purpose category. This restores `models` as DeepSeek's sole category while preserving `contracts.webSearchProviders`.

- Simplification leaves one changed line; independent review found no actionable issues through P2.
- Exact-head selected CI tests passed: [41 config/loader tests](https://github.com/openclaw/openclaw/actions/runs/39094465858/job/117578184161), [134 boundary tests](https://github.com/openclaw/openclaw/actions/runs/39094465858/job/117578184154), and [44 DeepSeek provider tests](https://github.com/openclaw/openclaw/actions/runs/39094465858/job/117578184208). Remaining required checks are tracked by the [same CI run](https://github.com/openclaw/openclaw/actions/runs/39094465858).
