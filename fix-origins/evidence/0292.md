## What Problem This Solves

Old plaintext archive read caches remain indefinitely after upgrading past #193548, which removed both the cache writer and its age-based sweep.

## User Impact

`openclaw doctor --lint` reports leftover cache size without creating or repairing temp directories. `openclaw doctor --fix` removes recognized old cache files and their directory if empty; the normal update path already runs Doctor with repair enabled. Unrelated entries remain, and refused cleanup is reported without failing Doctor or update.

## Why This Change Was Made

The existing core Doctor/legacy-state contribution owns this one-time cleanup; read-only inspection reuses the temp-path owner with creation and permission repair disabled. It uses the preferred temp-directory resolver and refuses symlink or foreign-owned directories. Files must be regular files with the retired writer's name shape, including interrupted temporary writes. The reader-identity prefix remains unchanged.

Cleanup is best effort. Open POSIX handles remain usable after unlink; Windows may leave locked files for a later run. Native Windows behavior and a full package upgrade have not been exercised locally.
