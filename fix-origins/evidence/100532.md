## What Problem This Solves

Fixes: screen readers can miss a failed agent-file save or workspace conflict while the editable draft remains on screen.

## User Impact

User impact: the existing failure and conflict messages are exposed as alerts, including their existing Reload and Overwrite recovery controls. Normal file information stays nonassertive. No file permissions, write ordering, draft handling, focus behavior, or visual layout changes.

## Why This Change Was Made

The file outcome owner already records and displays the failure, but its danger callouts lacked alert semantics. Add the semantics at those existing presentation slots; keep the authoritative owner and recovery paths unchanged.

Whole-diff simplification: no new state, abstraction, listener, or request. Production +6/-2 lines; bundled regression +64 lines reusing the existing fixture. The two new cases protect ordinary failure and the separate retained-conflict branch.

## Evidence
