## What Problem This Solves

Backup scratch repair can report a false preservation warning when an active SQLite snapshot commits between directory enumeration and file inspection, removing its rollback journal.

## User Impact

Doctor classifies live scratch as active before inspecting a payload that its current owner is still changing. Abandoned scratch keeps the existing guarded reclamation path.

Move token-backed repair inspection behind the existing exclusive lifetime admission. Dry-run and tokenless legacy inspection retain their behavior. Root identity, ownership, symlink, retirement and release checks remain authoritative; no new lock, schema, retry or timeout is introduced.
