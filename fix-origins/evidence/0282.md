## Fix PR #192694 description (by hannesrudolph, opened 2026-11-04T09:50:06Z)

```text
Closes #192642

## What Problem This Solves

Offline queued input can disappear when the macOS app reconnects to the same Gateway and replaces its embedded dashboard document.

## User Impact

The dashboard keeps its page state when only the native socket reconnects. Actual endpoint, configured credential, TLS and browser-account changes still isolate documents; no configuration or migration is required.

**Live native verification completed:** the exact candidate app passes the real-Gateway offline-queue recovery flow below. The exact-head native proof is complete; this PR is being evaluated for landing. No deployment is included.

## Why This Change Was Made

Socket-owned startup credentials retire before the next authenticated connection arrives. Treating that temporary projection as a new document owner discards the WebView containing the queue. The fix separates document identity from socket authority across the existing lifetime decisions and refreshes the retained document's future-load credentials, without weakening native challenge checks or changing global auth equality.

## Evidence

Tested source: `2430b2ec27cf81f90b9beba2c4928bb5d132d4da`.

- Extended the existing real-native-auth/WebKit regression to cover retirement both before and after reconnect. The unchanged production base fails the retirement-first case on controller/WebView retention and native challenge availability (3 failures, 3.72 seconds); the existing opposite ordering passes.
- The fixed candidate passes **33 native tests across four suites in the retained disposable macOS guest**, including both retirement orders, retained draft/sessionStorage, fresh challenge scopes, startup credentials after manual reload, route/credential replacement, and untrusted-source rejection (14.40 seconds). These use simulated Gateway sockets; the separate live real-Gateway outage proof is below.
- Native build, pinned SwiftFormat and diff checks pass. Pinned SwiftLint reports inherited file-length errors in `DashboardManager.swift` (base 1513, candidate 1514) and unchanged `GatewayConnection.swift` (1505); no rule was suppressed.
- Completed pinned local ClawSweeper review of this exact committed candidate: no actionable correctness or security findings. At review time, it identified the live candidate-app recovery proof as missing; that separate proof is now completed below.

No production deployment is included.
```
