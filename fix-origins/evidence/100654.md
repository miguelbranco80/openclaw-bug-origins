## What Problem This Solves

Doctor rejects the newly added Levanto catalog with `Manifest modelCatalog row levanto-sage is missing contextWindow`.

#157433 introduced Sage as a native decision-only provider. Its registration tests and documentation deliberately leave chat API, context/output limits, and fixed prices absent: these are not known chat-model defaults. The manifest omitted discovery mode, so the static-provider validation path tried to convert that native decision declaration into a complete conversational provider configuration.

Declare Levanto's discovery as runtime-backed at the owning manifest. The native decision provider retains its catalog row and owns registration. No catalog rows, capability declarations, limits, validation checks, or assertions are removed or weakened. The authored manifest is the source consumed by catalog publication; no generated output is hand-edited.
