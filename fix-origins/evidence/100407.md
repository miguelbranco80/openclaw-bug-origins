## What Problem This Solves

State lease failures can report only "lease expired or ownership lost", hiding which heartbeat operation first observed the loss during maintenance.

## User Impact

Operators can distinguish automatic renewal, activation, explicit verification, and explicit renewal failures in the existing error diagnostic. This is diagnostic enablement, not a fix for the underlying lease loss. No configuration or migration is required.

## Why This Change Was Made

Retain the first static loss path and already-observed outcome through the existing worker-to-parent error flow. Missing ownership is reported as no current owned, unexpired row, without claiming whether a lease expired, was deleted, or was replaced. Existing error causes and codes remain intact; authority checks, TTLs, retries, and shutdown behavior are unchanged.
