## Fix PR #148471 description (by steipete, opened 2026-09-14T19:01:11Z)

```text
## What Problem This Solves

Fixes agents creating a Browser dashboard when asked to open the browser sidebar or side panel.

## User Impact

Panel requests now receive explicit guidance to open the existing Browser panel. The session-list sidebar stays distinct, and explicitly requested Browser dashboards remain supported. No configuration changes or migrations are required.

## Why This Change Was Made

The browser tool supplied a dashboard-creation recipe while the presentation prompt omitted the existing screen command. The shared prompt now maps browser-panel requests to `screen(action="browser_show")` in both standard and Codex runtimes, including deferred and namespaced tools. Tool guidance distinguishes panel controls from dashboard authoring and remains gated on available capabilities.

This changes prompts and tool descriptions only; renderer layout, command execution, and authorization are unchanged.

## Evidence

- Added regression assertions failed before the fix for standard, Code Mode, and Codex direct/deferred/namespaced prompt assembly, then passed after the fix.
- All 486 focused tests passed across system prompt, screen tool, browser tool, and Codex thread prompt suites.
- The changed-file gate passed, including production/test type checks, formatting, lint, and structural guards.
- Documentation link audit: 13,772 internal links checked, zero broken links.
- Independent review: no actionable P0–P2 findings.

The first CI run failed during manifest generation because main registered a database-worker test twice. That upstream issue was fixed by #148425; this PR was rebased onto the repair with a patch-identical range diff. On the rebased head, only the plugin runtime-inspection lane failed, with the same intermittent invalid-config reply independently recorded in #147993. All 32 tests in that file pass locally. A single failed-job retry passed on the unchanged head; no assertions or product code were changed for it. [Required CI is green](https://github.com/openclaw/openclaw/actions/runs/34885152617) on attempt 2.

Validation covers prompt assembly and the existing screen-command mapping. Live model routing and a browser UI replay were not exercised.
```
