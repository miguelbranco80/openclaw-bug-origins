## Fix message body

```text
The schema-tracking generator delegated to native SQLite iterators without
closing the delegate when next() threw. Callers could close only the already
closed outer generator, leaving a cached statement to report the old error
on a later valid write. Close the native delegate at that producer boundary
while preserving the original error and schema/transaction bookkeeping.

The node-turn retry failure reproduces on unchanged main with Node 24.19;
newer Kysely all() calls do not exercise the faulty iterator path. A direct
tracked-iterator regression also reproduces on newer Node. The regression
fails before this fix and passes after it; 188 tests pass across the owner,
Kysely, schema-contract, and node-turn files (two existing capability skips,
286.80s wrapper wall). Production/test types, focused lint, line limits, and
P2 review pass. No signature, schema, dependency, or configuration change.

Found while investigating CI for #164805.
```
