## Summary

- synthesize missing native `tool.result` rows before transcript checkpoint closure
- preserve unknown outcomes through normal settlement, timeout recovery, and exceptional cleanup
- keep the attempt failure authoritative while making restart-safe evidence durable

## Evidence

The maintainer retrospective records unmatched native results terminating release work and watchdog expiries being perceived as stopped sessions. A fresh reproduction also had three native delegated children receive `OpenClaw did not register a handler for this app-server tool call` for app-server filesystem/GitHub tools while Codex-owned collaboration messaging continued to work.

PR #179690 fixed async scheduled-run ordering and is already merged; it does not cover this native projection path. PR #111646 only raises a retired idle timeout and does not provide checkpoint semantics.
