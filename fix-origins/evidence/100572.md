## What Problem This Solves

Fixes worker provisioning becoming stuck with `Worker environment inventory has closed` after an independent database-open attempt is refused.

## User Impact

An admitted inventory stays usable through ordinary open refusals, including transient contention. Explicit closure, terminal failures, and durable quarantine still revoke it. No configuration or migration is required.

A diagnostic open error does not retire the inventory's independent admission. Inventory now follows authoritative lifecycle events. Fresh-open quarantine discovery publishes terminal retirement from the database owner; the obsolete quarantine admission helper is removed.
