## Fix PR #200623 description (by steipete, opened 2026-11-17T14:03:26Z)

## What Problem This Solves

Reconciling a large managed workspace serializes its entire rollback pack on the Gateway thread before sending it to SQLite. A single operation can contain more than 120 MB of old file contents, delaying connected clients.

## User Impact

Large workspace reconciliations stop copying rollback packs through Gateway-thread serialization. Recovery, conflict handling, atomic acceptance, and journal correlation retain their existing behavior. No configuration, database schema, projection, or stored-format changes are required.

## Why This Change Was Made

The Git worker prepares a publication copy, and the SQLite broker transfers its ArrayBuffer outside the serialized command envelope. The original pack remains available for rollback and lost-reply recovery. Oversized-mutation diagnostic parsing and hashing run in the SQLite worker.

The journal is already cleared atomically when the accepted baseline is published. It contains one operation's rollback snapshot, not accumulated history: one synthetic reconciliation of 15,813 files produces a 120.8 MB pack. Dropping those old bytes before acceptance would break rollback, so no compaction or persistence change is justified.

Production growth is 93 lines for explicit transferable ownership through the existing worker transport and worker-side diagnostics; tests have no net growth. The replaced main-thread diagnostic implementation is removed. No cache or new owner is introduced. Lease and quiescence code is unchanged. Main's later #200643 changes the outer lease wrapper, preserves its callback contract, and does not overlap this mutation transport change.

## Evidence

The mutation target passes on head `872e422382dfc123aceadbe53b139021fd5e6b77`: every candidate's maximum active segment is below 50 ms and below both A/A controls. All twelve runs pass content/freshness checks. Exact-head [CI 44114615303](https://github.com/openclaw/openclaw/actions/runs/44114615303) and [security/dependency/CI gates](https://github.com/openclaw/openclaw/actions/runs/44119217771) pass. [ClawSweeper's final-head source review](https://github.com/openclaw/openclaw/pull/200623#issuecomment-6951451433) has zero findings; completed performance evidence is now published below.
