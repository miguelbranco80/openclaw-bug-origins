## Fix message body

```text
Closes #155397

## What Problem This Solves

Doctor flags a session as using a retired model route again after a Claude CLI turn because the result records `claude-cli` as its model provider instead of the already-selected `anthropic` provider.

## User Impact

CLI turns retain the canonical model provider in session metadata instead of undoing Doctor's repair. The execution backend and native session bindings remain `claude-cli`; existing Doctor migration behavior and configurations are unchanged.

## Why This Change Was Made

The CLI runner already receives the logical model provider separately from the backend ID. Its completed, blocked, delivered-failure, and hook-handled result paths now use that prepared model provider, matching the existing transcript runtime-context rule. Callers without a logical model provider keep the existing fallback.

## Evidence

### Focused verification and unchanged-source reuse

- On the unchanged production source, all four result paths failed the canonical-provider regression: expected `anthropic`, received `claude-cli`. The other 18 cases passed, including absent-provider and native continuity controls.
- After the four assignment changes, **22/22 tests passed** in the existing settlement suite: 30.10 seconds command wall, 2.716 seconds total test-body execution. The eight provider cases cover supplied/absent model providers across all four writers and took 2.683 seconds. Backend execution traces and backend-keyed native binding retention, replacement, and clearing remain covered.
- The actual `agents-other` test-type project, targeted type-aware lint, formatting, line-cap, max-lines, assertion-safety, and scoped diff checks passed.

- The branch now includes upstream `80b9608a25e1`, which supplies the missing tooling declaration behind the earlier TS7016 failure. The actual affected UI typecheck passed in 9.55 seconds; declaration/importer formatting also passed. The three CLI files are unchanged from `21289db70600`, so the earlier focused checks and explicitly author-reported native evidence are reused without a runtime replay.

### Contributor-reported native evidence, retained without replay

- After: local-agent turns on a repaired session and Gateway `chat.send` turns on repaired and fresh sessions retained raw `modelProvider: "anthropic"`; Doctor reported no legacy-route finding, while native bindings remained keyed by `claude-cli`.
```
