## Fix PR #171879 description (by steipete, opened 2026-10-14T06:54:58Z)

```text
## What Problem This Solves

Fixes: picking one of 35 bundled models fails every turn because the provider has retired it (404 / 410 "end of life" / "archived"), and new Cerebras setups default to an archived model.

## User Impact

User impact: model pickers, onboarding defaults, and media defaults stop offering models the provider no longer serves. New Cerebras setups default to `cerebras/gpt-oss-120b` instead of the archived `gemma-4-31b`; Together defaults to GLM 5.2; DeepInfra image understanding falls back to Kimi K2.6; OpenCode image understanding defaults to MiniMax M3. Configs that pin a removed id are not rewritten (no Doctor rewrites); those turns already fail at the provider today.

## Why This Change Was Made

Each removed row was proven retired live with a real API key on 2026-10-13: the id is absent from the provider's `GET /models` listing **and** a 1-token completion against the catalog `baseUrl` failed. Rows that were merely unlisted but still served (aliases, access-gated models, region-dependent `qwen` rows) were left alone. Doctor name-table rewrites were deliberately not added (see #169473). This complements #167855, which marks dead rows `deprecated` only in the hosted catalog bundle and only for providers with a keyless `/models`; this PR prunes the bundled manifests themselves, including key-gated providers (Cerebras, Groq, Fireworks, Together, Qwen Token Plan) that #167855 cannot see.
```
