## Fix PR #201207 description (by roboclaw-bot, opened 2026-11-18T13:04:23Z)

```text
Related: #199621 and #194814.

## What Problem This Solves

Selecting Roboclaw and My sessions can show conversations from another agent. Changing to All owners then unexpectedly narrows the agent scope, and saved sidebar pins can remain outside the selected agent.

## User Impact

The agent picker sets the sidebar scope: My sessions and other owner filters stay within the selected agent. Sidebar pins and personal sections follow that scope without deleting saved references. Show all remains cross-agent; explicit rail shortcuts remain global.

An agent without a loaded matching session window uses the existing Home fallback when selected. This patch does not add an independent cross-agent inventory for unread badges or latest-conversation selection. The broader picker work in #194814 remains separate.

## Why This Change Was Made

Vyctor explicitly chose agent scope first, then owner filtering. The change removes the owner-filter exception from the existing query and applies the same agent scope to saved sidebar references. Gateway authorization, owner defaults, and stored preferences are unchanged.

## Evidence

- The new browser regression fails on current main `392506102468cb92aeb66a6a39ef7b3130583070`: an X front door session is visible with Roboclaw selected. It passes with this fix.
- 2 browser scenarios and 17 focused component tests passed. Coverage includes My sessions, All owners, named owners, empty scoped results, switching agents, personal pins/sections, and Show all. Production UI typecheck, targeted lint, formatting, and diff checks passed.
- Independent local autoreview (Codex, GPT-6.1 Sol, P0–P2) reviewed the complete local change against `6691acaed56357d2210d380d577c0430ca0ee782`: scoped-clean, no actionable findings. The reviewer assessed source; it did not execute tests.
- Proof uses the real production Control UI in Chromium, a 1280×800 emulated viewport, and synthetic Gateway data. Session titles deliberately identify the agent. No live Gateway or provider proof; no full CI run yet.
```
