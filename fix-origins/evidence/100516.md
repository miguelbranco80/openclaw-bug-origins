## Fix PR #171687 description (by steipete, opened 2026-10-14T04:03:19Z)

```text
## What Problem This Solves

`openclaw update --no-restart` drops the plugin activation guidance when the core version also changed. After a successful update that changes plugins, the final next action should tell the operator to restart the Gateway so the new plugins load. When core changed in the same run, the report instead suggested previewing migration cleanup, while the old Gateway was still running the previous code and plugins. Nothing told the operator that the update had not taken effect.

Root cause: `recordUpdateResultNextAction` in `src/cli/update-cli/update-command-result.ts` passed `restart` to `resolveUpdateResultNextAction` only when core was already current. That condition was scoped to the plugin-convergence path added in #143174, which was the only route producing this message at the time. It stayed in place when core-changing updates began reaching the same resolver (#140339).

## Why This Change Was Made

The caller's restart choice is now always forwarded. The resolver already decides from `restart === false && plugins.changed`, so the guidance shows for both core-current and core-changed runs. One restart activates both the new core and the changed plugins. Production: +1/−1. No change to restart or update policy.

## User Impact

After `openclaw update --no-restart` with plugin changes, the CLI output, the JSON result, the stored update history and the rendered report all show `Plugins updated; Gateway restart skipped (--no-restart). Run openclaw gateway restart to activate them in the running Gateway.` (profile-aware). Before, they showed cleanup advice instead.

## Evidence

- A new table-driven regression in `update-recovery-guidance.test.ts` covers both the core-current and core-changed cases. It checks the stored `nextAction`, the JSON output and the rendered Markdown report. The core-changed case fails before the fix; all 20 reporting tests pass after it.
- `docs/cli/update.md` now describes the reminder.
- Codex autoreview: clean.
```
