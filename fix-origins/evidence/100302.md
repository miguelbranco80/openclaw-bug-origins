## What Problem This Solves

Restart-intent consumption could block the Gateway signal thread behind a SQLite writer, then return an intent whose separate deletion failed. A later signal could consume it again. Update-report receipts also used main-thread SQLite and needed accepted work to settle before their transport and storage owners closed.

Runtime intent consumption, handoff writes, report receipt transitions, and cleanup now use their existing workers. Intent consumption is atomic `DELETE … RETURNING`; duplicate suppression, current publication authority, and accepted-work settlement remain intact.

The schema-cache parent #167001 merged and its branch was deleted, so this PR targets `main`. ## Ownership and restart readiness

The shared-state writer owns runtime intent consumption and handoff persistence. The sentinel writer owns receipt reservation, transitions, finalization, and cleanup; its read worker supplies receipt reads. Callers capture physical database identity before yielding. Authoritative rereads and writes remain synchronous inside worker transactions, with live authority checked again at transaction, commit, and publication boundaries. Commit receipts reconcile lost replies without replaying accepted writes. Reservation-bound artifact paths prevent delayed cleanup from deleting a successor's report.

The signal owner preserves FIFO and joins accepted intent work before close. The report RPC uses its existing execution join so connection retirement waits for receipt and cleanup settlement. Supervisor handoff persistence remains **after canonical writer drain and the final restart decision**.

Real restart proof showed that cold worker code loading was on the readiness critical path. +/** Own code-only warming separately from accepted database work during shutdown. */
+export function createGatewayRestartRuntimePreparation(
+  runtime: Runtime,
+  logger: Pick<SubsystemLogger, "warn">,
+) {
+  let current: ReturnType<Runtime["prepareGatewayRestartHandoffRuntime"]>;
+  let pending: Promise<void> | undefined;
+  return {
+    get current() {
+      return current;
+    },
+    get pending() {
+      return Boolean(current || pending);
+    },
+    prepare(request: GatewayRunSignalRequest, decision: GatewayRestartDecision) {
+      if (
+        request.action !== "restart" ||
+        decision.mode !== "supervised" ||
+        request.restartIntent?.successorOwner
+      ) {
+        return undefined;
+      }
+      try {
+        current = runtime.prepareGatewayRestartHandoffRuntime();
+        return current;
+      } catch (error) {
+        logger.warn(`restart runtime preparation unavailable: ${formatErrorMessage(error)}`);
+        return undefined;
+      }
+    },
+    async settle(operation: Promise<void>, prepared: typeof current): Promise<void> {
+      try {
+        await operation;
+      } finally {
+        if (prepared) {
+          await this.release(prepared);
+        }
+      }
+    },
+    release(prepared = current) {
+      if (prepared) {
+        if (current === prepared) {
+          current = undefined;
+        }
+        const cleanup = Promise.all([pending, prepared.release()]).then(() => undefined);
+        pending = cleanup;
+        void cleanup.then(
+          () => {
+            if (pending === cleanup) {
+              pending = undefined;
+            }
+          },
+          () => undefined,
+        );
+      }
+      return pending;
+    },
+  };
