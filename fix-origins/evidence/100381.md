## Fix PR #153984 description (by steipete, opened 2026-09-20T19:24:55Z)

```text
## What Problem This Solves

Fixes `openclaw health` timing out while a local Gateway is already serving through a wildcard listener on macOS.

## User Impact

Local health and restart readiness recognize a serving wildcard Gateway, including when native process diagnostics are unavailable. Authentication, plugin checks, and restart deadlines remain unchanged.

## Why This Change Was Made

A scoped loopback bind can succeed alongside a wildcard listener on macOS. The shared port probe now confirms endpoint availability through a bounded TCP connection after a successful bind. SSH readiness reuses the same socket-close owner instead of maintaining a duplicate probe.

Scoped socket probing remains authoritative. The earlier listener-record shortcut was removed after review demonstrated that `lsof` renders both IPv4 and IPv6 wildcards as `*`. An IPv6-only listener must not make a free IPv4 endpoint appear busy. Native process records remain diagnostic enrichment through the existing inspection path.

Production code grows by nine net lines to add TCP confirmation while removing the separate SSH socket implementation. No configuration, schema, or migration change is required.

## Evidence

- Native Darwin/Node 26.8.2 before/after: the original wildcard Gateway was incorrectly reported free by scoped inspection; repaired single and batch inspection both report busy. Low-level probing also detects the listener without native process diagnostics.
- The review finding was reproduced with an owned IPv6-only wildcard: its IPv4 endpoint was free while the initial shortcut reported busy. Removing the shortcut restores free status and empty scoped listener diagnostics. The new single/batch regression failed before correction and passed afterward.
- Blacksmith Testbox: six focused files pass (109 tests, one platform skip), covering port inspection, probing, SSH cancellation/socket settlement, real wildcard WebSocket readiness, and diagnostic deadlines. Focused type-aware lint passes with no warnings or errors.
- Native Windows/Node 26.8.2 sibling proof: free loopback and wildcard destinations return `ECONNREFUSED`; an IPv6-only listener permits a same-port IPv4 bind and refuses IPv4 connections while accepting IPv6. All owned sockets and listeners were closed.

Fresh independent review is scoped-clean at P0–P2. The final portable regression and type-aware lint both pass. The regression takes 1.92 s wall in its standalone one-worker run (28 ms test body in the six-file run). Prior one-worker Blacksmith cost: `ports.test.ts` 2.02 s wall; `restart-health-client.test.ts` 15.53 s wall including module startup (6 tests passed). Exact corrected-head [CI35542436592](https://github.com/openclaw/openclaw/actions/runs/35542436592) passed.
```
