```text
Related: #162839

The remaining note-only catalog case is completed by https://github.com/openclaw/openclaw/pull/162963.

## What Problem This Solves

Fixes misleading skill-discovery instructions when installed skills are available but their directory is omitted from the prompt.

## User Impact

Agents receive an explicit search path for file work and specialized workflows instead of being told to scan a nonexistent list. Known skills can be read directly; simple conversation does not require a search. Existing capability denials still control availability.

## Why This Change Was Made

Distinguish listed and omitted directories and explain when to discover a skill before implementing a workflow. Apply the same guidance to direct tools and Code Mode without changing tool permissions, catalog size, or configuration.

This is the first change in an installed-skill discovery follow-up stack. It fixes a deterministic prompt defect. The maintainer-side cross-model evaluation compares the first three stacked changes together, so it does not isolate this PR's effect.

## Evidence

- The two empty-directory regression cases failed against the original prompt because it referenced `<available_skills>`.
- All 7 focused prompt and cache-prefix tests pass after the change, including direct-tool, Code Mode, and capability-denial coverage.
- Focused run cost: 46.96 seconds wall time and 5,614,240 KiB peak RSS; the cases themselves take 1-12 ms, with cold compilation/imports dominating the run.
- Independent scoped review found no actionable P0-P2 findings.
- Formatting, core typechecking, agent-root/other/tools test typechecking, config-doc checks, plugin boundaries, and the completed changed-file guards passed.
- The broad changed-check command was intentionally stopped (exit 143) when it expanded into all 27 core test graphs; its gateway-root graph was interrupted. The full command and remaining unrelated graphs are not claimed passed.
- Targeted lint passed; full merge CI is not claimed.
- The two-task, three-model evaluation attempted all 24 conditions: 21 produced grader results, two had confirmed execution errors, and the final diagnostic exited nonzero without recoverable detailed evidence. All twelve ordinary before/after trials were captured.
- GPT used skill discovery in both candidate runs and passed both tasks. Qwen and DeepSeek skipped discovery in ordinary runs. All eight observed searches ranked the intended skill first. These single trials do not establish causal uplift or rank retrieval backends.
```
