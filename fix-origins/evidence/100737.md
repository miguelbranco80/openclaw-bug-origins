## Fix message body

```text
## What Problem This Solves

Fixes #159080. LINE messages in an actively session-bound conversation can fail with `AgentSelectionRequiredError` when multiple agents are configured without a channel-wide route. Group mention admission also selected an ordinary agent before the context builder could consult the binding.

## Why This Change Was Made

Use the existing shared binding inspection and route projection contract, following #123159. LINE inspects the binding once, lets group mention admission use the bound owner, and carries that captured decision into message-context construction.

For groups, the shared ingress owner first evaluates sender and group policy without consulting bindings. Only admitted group messages prepare a route; the same ingress owner then evaluates activation with the selected owner's mention facts. Explicitly disabled groups, disabled group policy, and denied senders therefore still settle during a binding-owner outage. Binding activity writes and configured ACP readiness remain after admission. No configuration, schema, SDK, or iMessage changes.

## User Impact

Bound direct and group conversations reach their existing agent without requiring a channel-wide route. Ambiguous unbound conversations still fail closed; single-agent and explicit channel routes keep working. Policy-rejected messages do not become retries because binding storage is unavailable.

Message (truncated):

```text
* fix(line): let a quote of the bot address it in a group

* fix(line): bound the sent-message record per account

A single process-wide 500-entry map held every account's sent ids, so a busy
account's traffic evicted a quiet account's ids and a later quote of the quiet
bot silently stopped counting as addressing it. LINE runs several configured
accounts in one process, so that pressure is real rather than theoretical.

Give each account its own bounded record, built on the plugin-sdk dedupe cache
the other channels already use for this, and cover the cross-account pressure
case so one account can no longer evict another's.

* docs(line): bound the quote-recognition window and use American spelling
```
