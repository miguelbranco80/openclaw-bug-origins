Closes #127562

## What Problem This Solves

Fixes: Bedrock prompt cache misses when the same tools are registered in a different order.

## User Impact

User impact: the same tool set now sends the same Bedrock request, so cache reuse holds.

## Why This Change Was Made

Sorts tools by name with the shared sorter the other providers already use.

## Evidence

Real `streamSimpleBedrock` and AWS SDK against a local HTTP endpoint that records the wire body. Same three tools, registered in two orders:

```
before: sha256=95aa7ede0ee5a88e tools=lookup,calculate,browse
        sha256=de2f34c09dbf15f5 tools=browse,calculate,lookup   identical: false
after:  sha256=de2f34c09dbf15f5 tools=browse,calculate,lookup
        sha256=de2f34c09dbf15f5 tools=browse,calculate,lookup   identical: true
```

No AWS account here, so a live cache hit is not shown, only the request bytes.
