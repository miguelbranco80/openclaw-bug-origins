```text
The parent holding-screen change (#191935) has landed. This PR now targets `main` and contains only its fallback layer; land it after #193874.

## What Problem This Solves

When the Control UI bundle fails to start, the static recovery page looks disconnected from the rest of the app.

## User Impact

The fallback uses the approved placeholder app shell, OpenClaw mascot, and responsive wordmark. Once automatic recovery stops, it shows “Control UI didn’t start,” a Reload button, and a Troubleshooting link. “Keep waiting” is removed; a late first render still retires the fallback automatically. Reduced motion stops the body, claws, shadow, and lids while slowing the eye movement to 12 seconds.

## Why This Change Was Made

The static page stays self-contained so it can explain and recover from a failed app bundle. Bounded recovery navigations, unsupported-browser retirement, native background dragging, and reloading the current URL are preserved.
```
