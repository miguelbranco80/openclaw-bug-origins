## Fix PR #191358 description (by vyctorbrzezowski, opened 2026-11-02T17:53:56Z)

```text
## What Problem This Solves

Settings joins a sentence and the value after it with no space, so the page reads "UI budget.Telegram probe timed out", "permissions.65/65 enabled." and "Session:agent:main:main".

## User Impact

Those lines now read as written, with a space between the sentence and the value. The same fix applies to the Agents Skills count, the plugin consent "Previously accepted" date, and the session storage error.

## Why This Change Was Made

Each site renders two values on consecutive JSX lines, and JSX drops the line break. This adds the missing space at each site and changes no copy or layout.

## Evidence

Control UI mock, real navigation. The partial channel snapshot comes from the mock's `channels.status` response. The plugin consent and session storage fixes follow the same pattern and have no image.
```
