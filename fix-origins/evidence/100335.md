## Fix message body

fix(hooks): stop a hook run at its configured timeout

An HTTP hook with a configured timeout could run far past it. Each provider attempt timed out on its own, but a malformed zero overall budget let the run keep retrying, so a 5-second hook returned only after about 40 seconds. The run now inherits the hook's deadline and stops when it is reached. Fast replies, an omitted timeout and valid fractional timeouts are unchanged, and retry policy is unchanged.

Evidence: real authenticated HTTP hooks on built, isolated Gateways, with a 5-second timeout and an 8-second provider delay. Main overran twice (43.2 s and 38.3 s, five attempts each). With this change the run stopped at 5.3 s and 5.4 s with one attempt each. The control cases passed on both refs. Details: https://github.com/openclaw/openclaw/pull/176089#issuecomment-6534514306.

Thanks @superdiaodiao.

## Fix PR #176089 description (by superdiaodiao, opened 2026-10-18T05:28:40Z)

```text
## What Problem This Solves
A sub-second numeric `timeoutSeconds` on `/hooks/agent` passes positive-number validation but floors to zero, selecting the internal unlimited overall budget rather than inheriting the configured timeout. Individual provider attempts may still time out, while retries extend the hook well beyond its intended budget.

Closes #176027. Original report and fix by @superdiaodiao. Related: #181185.

## Change
Require a finite override of at least one second before flooring. Invalid subsecond overrides inherit the configured timeout. Valid fractional overrides still floor; the shared internal zero sentinel, retry policy, authentication and token resolution are unchanged. Contributor commits are preserved.

## Evidence
[Built Gateway HTTP proof and focused check results](https://github.com/openclaw/openclaw/pull/176089#issuecomment-6534514306).

Against a local streaming provider with an 8s response delay and configured 5s default, main exceeded the overall budget twice (43.166s / 38.342s, five attempts each); the candidate stopped twice at 5.300s / 5.429s with one attempt. Fast normal replies, omitted timeout, and valid fractional-floor controls retain their behavior. 54 selected existing tests passed; the regression fails on main. Test line delta is zero.

## Merge danger
Two-way door: revert restores prior normalization. Only newly admitted hook requests with subsecond numeric overrides change behavior; already admitted runs retain their budgets. No migration or stored-format change. If wrong, hook callers relying on subsecond overrides are affected; other channels and the internal zero timeout contract are unchanged.
```
