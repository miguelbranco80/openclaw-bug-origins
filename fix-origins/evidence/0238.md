## Fix PR #190101 description (by vincentkoc, opened 2026-11-01T05:50:07Z)

```text
## What Problem This Solves

Fixes: the OpenShell plugin and Docker E2E fixture still use CLI contracts removed by the already-pinned OpenShell v0.1.3. Legacy sandbox adoption uses unsupported inventory flags, cleanup expects the old list format, and the custom-image fixture passes a Dockerfile directly to `--from`.

## User Impact

Registered legacy sandboxes use JSON detail output for the existing Ready admission check. Missing, malformed, or non-Ready lifecycle data still refuses execution without recreating the sandbox.

## Why This Change Was Made

Reuse the existing detail parser and remove the obsolete inventory scan. Follow opaque pagination tokens and validate the complete owned inventory before cleanup. Build a unique Docker image tag before sandbox creation and remove it after sandbox cleanup.

The real Docker run also exposed two fixture contract mismatches: the host-network supervisor needs a loopback gateway endpoint, and unauthorized binaries are denied at TCP admission before an HTTP response exists. Preserve TLS and pair the successful allowed request with the pinned release's exit7/no-response denial.

## Evidence

- [Unchanged pinned baseline](https://github.com/openclaw/openclaw/actions/runs/41275826232):2 failed,3 passed; reproduced rejected Dockerfile `--from` and unsupported `--limit`.
- Five focused lifecycle/pagination regressions fail on baseline; all146 OpenShell unit and boundary cases pass with the fix on pinned Bun.
- [Final exact-head Docker E2E](https://github.com/openclaw/openclaw/actions/runs/41281313350) at `965b7c62e8d`:5 passed,0 failed. Covers network allow/deny, mirrored and remote workspace stress, and owned cleanup.
- Targeted compiler, type-aware lint, formatting and whitespace checks pass. Workflow passes pinned actionlint and zizmor.
- Fresh local exact-range review found no actionable correctness or security findings; security cleared. Runtime proof was run separately.

Pinned contracts: [v0.1.3 TCP admission denial](https://github.com/NVIDIA/OpenShell/blob/e1f3c82caa3ed3b65de22889ae7ef32a774878ef/crates/openshell-supervisor-network/src/proxy.rs#L713), [Docker supervisor host networking and alias mapping](https://github.com/NVIDIA/OpenShell/blob/e1f3c82caa3ed3b65de22889ae7ef32a774878ef/crates/openshell-driver-docker/src/lib.rs#L4984).
```
