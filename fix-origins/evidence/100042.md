## Fix PR #159755 description (by Shenrui-Ma, opened 2026-09-27T15:36:58Z)

```text
## What Problem This Solves

Tools that accept presets such as `"compact"` or `"wide"` alongside custom strings can reject `"customer-layout"` before execution because schema normalization retains only the presets.

## User Impact

Custom names reach the tool instead of failing local validation. Root unions remain flattened, so this does not enforce per-branch combinations.

## Why This Change Was Made

Keep a plain string alternative when all of that property's normalized alternatives are string presets or plain strings. Root properties and other combinations keep the existing merge rules.

## Evidence

Live ChatGPT verification with a registered local stdio MCP server: all six model-issued tool calls reached execution and were saved/read back unchanged. This covers root `anyOf` and `oneOf` in both branch orders, plus preset and overlapping-value controls. Model responses and MCP transport were not mocked.
