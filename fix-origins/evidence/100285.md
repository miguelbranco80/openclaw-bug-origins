```text
## What Problem This Solves

A prediction can remain visible when its reactive eligibility changes without a general composer props refresh. The effect tracked the outer predictions object, then read its current fields only in the untracked apply phase.

## User Impact

Changing prediction eligibility now retires the suggestion and event subscription immediately. Acceptance, cancellation, visibility, and late-result checks still use current owner facts.

## Why This Change Was Made

Prepare the complete prediction source in the effect's tracked compute phase and pass it to the existing `sync(next)` operation. Native event callbacks still read live input at the point of use. No new owner, cache, option, import, or lazy boundary is introduced.

This completes the prediction-input finding from the survivor audit in #178593. The effect remains because it synchronizes real dictation, catalog, and prediction resources; menu resets also retire real resources and are not replaced by speculative rendering state.
```
