## Fix PR #190892 description (by shakkernerd, opened 2026-11-02T05:40:47Z)

```text
Fixes #190886

## What Problem This Solves

Creating a session with an initial thinking choice can overlap a directive and an automatic title update while an older session-list response is still in flight. Under equal snapshot clocks, the title update is rejected to preserve the active row, but its thinking metadata could still clear the newer thinking choice. That leaves the older row available as the picker’s fallback until the next canonical response arrives.

## User Impact

The newer thinking choice stays available through a rejected session update and retires when accepted session facts catch up. Canonical reads, accepted events, removals, explicit settings patches, and connection replacement retain their existing reconciliation paths. This changes no configuration, stored data, or wire protocol.

## Why This Change Was Made

The row reducer already distinguishes an applied event from an admitted row. A rejected snapshot can be marked applied while returning the previous row, so that status alone cannot establish convergence. Thinking-claim retirement now requires the existing admitted-row fact.

The integration fixture adds a fourth ordering case alongside its three existing modes. It holds only the return of a real title transcript read, then lets the actual title task and publisher settle after the older row has arrived. The case preserves the original equal clocks, held responses, no-model checks, assertions, and cleanup. Its test-line allocation covers this distinct asynchronous producer regression without changing the shared baseline.

## Evidence

- A controlled real Gateway/title publication reproduced the failure before the correction: the inactive title snapshot was rejected as `stale-active`, the active High row remained, and the Low claim became undefined. The original three modes passed in that run.
- With the correction, all four real Gateway modes pass, including the title-order case before the held canonical Low response is released. The native file run took 90.02 seconds including preparation; reported case time was 19.33 seconds.
- Four related session-reconciliation test files pass all 51 cases. Changed-file formatting and Bun parity, source lint, i18n consistency, and affected compiler checks passed.

Hosted CI and independent engineering review passed on the published head. The same committed regression also failed on the baseline main revision shown below with the original guard: the original three modes pass and the title-order case loses Low.

The browser comparison below uses the production Control UI with explicitly labeled synthetic Gateway frames. Both builds receive the same held High row and inactive title snapshot: the baseline picker falls back to High, while the fixed picker stays Low. The separate real Gateway fixture proves the actual title producer and canonical Low convergence; the browser replay shows the picker consequence. The controlled reproduction does not attribute a particular historical intermittent failure.
```
