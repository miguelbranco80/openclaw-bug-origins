## Fix PR #191782 description (by steipete, opened 2026-11-03T08:45:40Z)

```text
## What Problem This Solves

`openclaw gateway status` reads the installed-plugin ledger to report version drift. That advisory read explicitly requested artifact preservation, so a live state database was copied into the read-only snapshot cache when owner verification was unavailable. If the CLI was killed during the copy, the staged directory and partial file could outlive it.

`gateway health` does not read this ledger, but it is commonly called beside status and should remain purely observational too.

## Solution

Use the existing native read-only state connection for status plugin-ledger discovery. Keep artifact-preserving snapshots on offline startup, update, Doctor, and rollback custody paths, and leave the SQLite hot-journal recovery exception unchanged.

Production LOC is net -1. The 54-line test allocation covers the real status-to-persisted-ledger boundary and rejects any return to snapshot preparation.

## Evidence

- Regression: restoring the old option makes the focused test fail because snapshot preparation is called; the candidate passes 53 status tests and reports the expected drift.
- Built CLI against a live isolated Gateway with a 12.9 GB synthetic state database, retained 35 GiB synthetic agent database, and 62k-file workspace: baseline status staged two snapshots; the candidate status and health staged zero.
- Killing the baseline status process and its copy workers left a 6,892,224,512-byte partial snapshot with no open file descriptors. The candidate has no copy process or staged directory to orphan.
- Five counterbalanced owner runs: status elapsed median/p95 27.037/52.302 s to 4.057/6.950 s; CPU 4.230/4.871 s to 3.395/4.679 s; sampled allocation 317.85/328.86 MB to 319.03/320.80 MB.
- Fresh maintenance and rollback code paths are unchanged. Five-run CPU/allocation distributions overlap; wall-time variance was also present in A/A controls, while rollback median improved.
- Existing lease-read suite: 50/50, including native-read and SQLite read-only rollback exception 776 coverage.
- `pnpm check:changed` and `git diff --check` pass. Codex local autoreview is scoped-clean at P0-P2.

No state schema or config change.
```

* fix(gateway): keep service-derived status targets off the explicit-URL credential path

gateway status --require-rpc forwards the service-derived probe URL as url
to callGateway, which bootstrap classifies as a CLI --url override and
rejects with GatewayExplicitAuthRequiredError for auth-none local Gateway.

Only forward url to callGateway when the caller supplies an explicit CLI
--url override (probeUrlOverride). Service-derived targets omit url so
bootstrap resolves via localPortOverride and the guard never fires.

* fix(gateway): isolate service status target credentials

* fix(gateway): retain scoped edge auth in status probes

* fix(gateway): preserve state artifacts during status reads

* fix(gateway): retain endpoint-scoped status TLS pins
