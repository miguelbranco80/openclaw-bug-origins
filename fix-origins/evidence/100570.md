## Fix PR #187572 description (by shakkernerd, opened 2026-10-29T10:15:04Z)

```text
## What Problem This Solves

Fixes #187559. Long replacement lines in Review's split diff paint across the divider and over the other side's text. Desktop Wrap lines does not recover the comparison because the text columns retain their intrinsic unwrapped width.

The failure was reproduced through Review → All Changes with a real Git-backed replacement file. In a 1,130px Review panel, an old usage line extended 7,224.56px past its divider. Enabling wrapping left that text track 7,731.56px wide and only 22px high.

## User Impact

Old and new text remain in separate, aligned columns. With wrapping enabled, spaced and unbroken lines fit their respective sides and the existing vertical reader reaches the complete content. With wrapping disabled, the existing horizontal scroll area exposes the complete old/new text.

The diff bytes, line numbers, syntax/word highlighting, selection, unified view and existing controls are unchanged. Native mobile wrapping remains supported; no setting, default, dependency, protocol or permission changes are introduced.

## Why This Change Was Made

The split scroll container now owns the column widths, and paired rows share those tracks. Unwrapped columns size to their content, keeping a consistent divider across long, short and one-sided rows. Wrapped tracks instead allow text to fit the available width. The existing renderer and scrolling owner are retained, with no per-row scrollbars or hidden code.

The production change is limited to the owning stylesheet. The browser regression adds scoped test-line credit for the distinct containment and reachability cases; it leaves the shared test ceiling and checks intact.

## Evidence

The new Chromium cases fail on the original stylesheet at the intended text-boundary assertion in desktop and mobile split mode, while all five existing tests in the file pass. The original run took 4.20s in Vitest, with a 6.40s native test command.

Remote formatting/lint and selected type checks passed on the committed tree. All seven browser tests passed in 3.76s; the eight existing session-diff E2E cases passed in 33.34s. These existing E2E cases protect replacement alignment, token highlighting, unified view and panel interactions. The joined native test invocation took 36.04s; hosted CI remains responsible for the broader suites.

Live Review also confirmed complete selection and horizontal access to all four old/new line endings, plus vertical access to the final unchanged line after wrapping. The comparisons and recording below bind to this exact head. The recording demonstrates keyboard activation, both scrolling directions and the final line; 120 sampled transition frames had zero text overflow. Hosted CI passed all selected jobs.
```
