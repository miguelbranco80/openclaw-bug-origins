## What Problem This Solves

Fixes retained Quick Chat widgets using a replacement Gateway's access and slow widget updates accumulating obsolete pending state.

## User Impact

Widgets stay bound to their owning Gateway. Reconnecting to that same owner can refresh access; replacing the Gateway cannot transfer access to old previews. Slow synchronization converges on the latest layout without an unbounded backlog.

## Why This Change Was Made

Move Canvas generation and observed-URL ownership through native commands and renderer callers together. Recheck that authority when creating or showing a child on the native UI thread. Keep one active widget update and only the latest pending update.

The replay retains the landed socket configuration/generation guards, independent desktop requests and sleep ownership. Existing window chrome and publication documentation remain unchanged.
