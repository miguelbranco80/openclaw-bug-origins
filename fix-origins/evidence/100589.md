## Fix PR #146412 description (by steipete, opened 2026-09-12T20:38:58Z)

```text
Related: #146275, #146267

## What Problem This Solves

Concurrent changes left TLS renewal using the old array-based Gateway sidecar registration call after the stop owner switched to variadic handles. The merged source fails core typechecking because the array has no `stop()` method. A TLS-enabled Gateway would register the array itself and fail to stop its renewal watcher through the lifetime owner during shutdown.

## Why This Change Was Made

Pass the TLS renewal handle directly to the existing sidecar stop owner. This is a one-line caller correction; TLS enablement, certificate renewal, and shutdown ownership remain unchanged.

## User Impact

TLS renewal participates in normal Gateway shutdown cleanup. No configuration, schema, stored-format, dependency, or public API change; no migration is needed.
```
