## Fix PR #148816 description (by steipete, opened 2026-09-15T05:46:41Z)

```text
Related: #130741

## What Problem This Solves

Standing-intent tools and hooks can write while transcript or reclamation work holds the same agent database's writer reservation.

## User Impact

Standing-intent updates wait their turn, and expired prompt hooks still cannot spend a fire budget.

## Why This Change Was Made

Use the existing database writer instead of only awaiting database opening. Preserve the authority checks before waiting and immediately before schema or row changes. No schema, configuration, retention, or queue policy changes are required.

## Evidence

The registered tool and hook queue cases fail on the original code. All 29 focused tests and canonical changed checks pass after the repair; fresh P2 review found no actionable issues. The tests preserve expiry, rollback, concurrent matching, and the original database path. This component does not establish the broader live Swarm latency target.
```
