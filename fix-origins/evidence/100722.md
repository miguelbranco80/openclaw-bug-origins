## What Problem This Solves

Use named imports and an explicit, module-local runtime surface for those same five function references. The existing lazy import, pairing state, access checks, completion handling, countdowns, and cleanup stay at their current owners. This follows the explicit runtime-surface approach used by `session-organizer-operations.runtime.ts` without adding an entry, ignore, or allowlist rule.

Also remove `mountActivityPage`, the uncalled test helper left by #174059. The Activity tests already read `page.container` directly.
