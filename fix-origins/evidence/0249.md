## Fix PR #203276 description (by roboclaw-bot, opened 2026-11-21T20:03:24Z)

```text
## What Problem This Solves

After you remove an automation, its original chat card still says “Automation unavailable” and offers Retry. Retrying cannot bring the automation back.

## User Impact

The card keeps the name and says **Removed**, with no Retry button, settings link, or switch. Other automations in the group keep their controls. A temporary loading failure still offers Retry.

## Why This Change Was Made

The card now distinguishes an exact not-found response for that job from a failed request. The Gateway intentionally gives the same response if the viewer loses access. If access is restored, the card updates normally.

## Evidence

In Chromium, four saved rows changed from switches to four retry buttons on main, and to four status-only rows on the fix. Both captures use the actual bundled Control UI with synthetic Gateway responses, the same dark theme and a 1152 × 780 viewport. Before: `1d9252c3770`; after: `3d6eb66d131`.
```
