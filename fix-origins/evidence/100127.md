```text
## What Problem This Solves

Normal Gateway journals cannot attribute successful ephemeral connections: CLI/backend client metadata was verbose-only, while authenticated-user and webchat connection records overlapped.

## User Impact

Operators get one `client connected` record per admitted operator/node connection, including client ID/name, mode, role, authentication method, version/platform/build, remote address, and an authenticated user when present. Request content and credentials are excluded. Log consumers matching the old `authenticated user connected` or `webchat connected` messages should use the new record.

## Why This Change Was Made

This consolidates the existing three connection-log paths into one at the same admission boundary. No new registry, timer, cache, configuration, transport, authentication, or pairing path is introduced. Gateway-hosted node services and plugin requests already use in-process dispatch; their transport should not be rewritten without caller evidence. The docs explain persistent external polling and the existing plugin runtime APIs. The bundled node-connect skill now recognizes the unified admission record, including its distinction from hello delivery, and retains guidance for older deployed builds.

## Evidence

A read-only 30-minute diagnostic sample measured approximately 1,855 connects (61.85/min; 5.714 seconds of total handler time), 1,898 `chat.history` requests, and only 22 authenticated-user / 20 webchat connects (overlapping categories). Five-minute bursts closely tracked history requests; successful non-user client metadata was absent, so that correlation does not identify the caller. Four CPU profiles totaling about 20 seconds provided no sampled outgoing Gateway-client handshake and did contain existing in-process dispatch.

Before/after connection rate: unchanged by design; this fixes the missing attribution needed to select a transport change. No production deployment or same-services before/after load test was performed, and no connection-rate or latency improvement is claimed.
```
