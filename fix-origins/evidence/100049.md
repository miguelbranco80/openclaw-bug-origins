## What Problem This Solves

Fixes: ClawHub-installed plugins keep an old OpenClaw host link after copying or upgrading a source-backed environment, so plugin validation can fail even after Doctor runs.

## User Impact

`openclaw doctor --fix` now repairs the host link for registered ClawHub plugins using the same ownership checks as npm plugins. Read-only Doctor reports the problem; developer-owned installations and paths outside the authoritative plugin root remain untouched.

## Why This Change Was Made

The shared registry repair accepted only npm records, although both registries install through the same host-link owner. Include ClawHub records in that existing flow and use accurate operator-facing wording. Existing serialized health/action identifiers stay unchanged. Production change: 19 additions and 19 deletions; tests: 43 additions and 14 deletions.
