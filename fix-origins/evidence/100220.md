## Fix PR #144685 description (by harjothkhara, opened 2026-09-11T05:09:43Z)

```text
Closes #142553

## What Problem This Solves

On macOS, an approval panel could remain visible after another client resolved the same request at the Gateway. A queued obsolete request could also surface later.

## Why This Change Was Made

The Gateway prompter consumes approval events without blocking on the native panel. It cancels only the presentation owned by the matching approval kind, request ID, and Gateway lease. It preserves session eligibility, reconnect ownership, replacement requests, and locally submitted decisions. The existing approval-panel and computer-input protections remain in place.

## User Impact

A Mac operator no longer has to dismiss an approval that another client already resolved. A queued approval that is obsolete should be skipped while later live requests continue to appear. Local decisions and the existing approval protections remain available.
```
