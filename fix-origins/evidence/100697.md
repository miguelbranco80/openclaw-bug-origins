```text
## What Problem This Solves

Fixes: reloading a dashboard with Side chat or Files selected switches the side panel back to Chat.

## User Impact

User impact: dashboard reloads retain the selected side tab when the saved layout already matches the effective dashboard view. Explicit dashboard presentation actions and changed shared defaults still reveal the requested view.

## Why This Change Was Made

Passive dashboard activation replayed the operation that opens Chat, overwriting the restored active tab in memory. The board now restores the saved arrangement when its presentation already matches. The existing presentation owner still handles intentional changes. The dashboard documentation now describes this reload behavior.
```
