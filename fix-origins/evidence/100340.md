```text
## What Problem This Solves

Fixes: reasoning content leaks into partial chat replies when a model streams reasoning tag aliases such as `<reasoning>`, `<internal>`, or namespaced reasoning tags.

## User Impact

With reasoning disabled, streamed replies now withhold recognized reasoning blocks before partial or block delivery, including tags split across chunks and nested tags, while literal Markdown code and explicit reasoning controls behave as before.

## Why This Change Was Made

Raw stream rendering kept its own tag grammar that was narrower than the canonical Markdown reasoning parser, so aliases and split quoted attributes slipped through to partial delivery. Stream rendering now uses the canonical parser for tag recognition and incomplete quoted attributes, checks code ownership before parsing attributes so literal quoted tags cannot swallow later real tags, and tracks one nesting depth through lifecycle transitions until the outer block closes. The duplicate raw-delivery grammar and its obsolete exported scanner are removed; final-tag handling and the separate opt-in reasoning extraction path are unchanged, with no new config, dependency, public API, protocol, or storage surface.

Production LOC +76/-43; tests +120/-0.

Two nested-tag regressions added after review also failed before the depth tracking landed.
- Green: `embedded-agent-subscribe.reply-tags`, `final-answer-delivery`, and `subscribeembeddedagentsession` tests passed 72/72 across 3 files, covering each interim partial callback, terminal block delivery, nested aliases, literal code and fences, self-closing tags, final-answer delivery, and reasoning on/off/native controls.
- Scoped typecheck, oxlint, oxfmt, and `git diff --check` passed. No model-facing prompt or tool text changed.
- Independent review: an early pass found that an inner closing tag could release text before the outer block closed; after the depth fix, a fresh review was clean with no actionable findings.
- Gap: no live Discord or Gateway round trip; the callback and consumer tests drive the owning delivery boundary, so PR CI remains the broad proof. Follow-up: audit alias semantics in the separate opt-in tagged-reasoning projection against the canonical formatter, which this change leaves as is.
```
