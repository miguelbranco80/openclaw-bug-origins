## What Problem This Solves

Fixes: the agent silently runs a different model when a wildcard model visibility policy excludes the configured default.

## User Impact

Operators now get a warning that names the requested model, the model selected instead, and the policy to repair, while automatic selection and explicit override rejection behave as before.

The selector now emits the diagnostic at the point of that choice, using sanitized model refs. The existing warning and sanitization helpers moved into a sibling module because the original owner was over the repository line cap, so the selector itself gets smaller.
