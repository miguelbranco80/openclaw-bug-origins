```text
Related: #122622. Related investigation: #156601 by @YangManBOBO.

## What Problem This Solves

WhatsApp media uploads fail before any proxy request because Baileys receives an Undici dispatcher where its Node uploader requires an HTTP(S) agent.

## User Impact

Media uses the configured HTTP/HTTPS proxy and evaluates `NO_PROXY` for each actual upload or redirect host, independently of the WebSocket connection. Direct uploads, lowercase variable precedence, and managed proxy CA trust remain supported. Invalid selected proxy routes reject media without silently sending it directly or blocking login/text session creation; intentional bypasses still work.

## Why This Change Was Made

The canonical Node adapter supports library-selected destinations and retains each protocol route's initialization error. One Proxyline Node agent owns dual-protocol/default-port handling and direct-agent cleanup; OpenClaw retains its existing proxy selection, bypass, and proxy-only CA policy. Fixed-destination callers keep their contract. WhatsApp supplies that typed agent to Baileys and destroys connection agents on close; obsolete dispatcher probing and mock-only transport tests are removed.

The approved temporary `@openclaw/proxyline@0.3.12` patch exports its **existing** `ProxylineNodeProxyAgent` class. There is no version bump or proxy implementation change. pnpm generated and registered the patch; only the source entrypoint and regenerated JS/declaration/map change. The root bundles the patched dependency for npm installs. The patch README records its removal gate.
```
