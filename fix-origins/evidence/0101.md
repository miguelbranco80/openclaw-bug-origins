## Fix PR #194310 description (by LinzeShi, opened 2026-11-06T20:25:59Z)

```text
## What Problem This Solves

Workspace paths with repeated spaces display incorrectly in the `openclaw configure` summary: `two  spaces` becomes `two spaces`, even though the stored path and workspace prompt are correct.

## User Impact

Paths and other note text retain repeated ordinary spaces when the words fit on the same output line. Existing word wrapping, tab normalization, bullet indentation, Unicode width, and long-path protection remain in place. This is display-only; no config or workspace path is rewritten.

## Why This Change Was Made

The shared terminal note wrapper split on whitespace and rejoined words with one space. It now tracks source offsets and keeps ordinary-space separators between words, dropping them only at a line break. Tabs and other whitespace retain their previous normalization. This replaces the split/filter array and adds four net production lines. The original contributor commit from Linze Shi is preserved without source edits.

## Evidence

[Built Linux CLI / real PTY before-and-after capture and controls](https://github.com/openclaw/openclaw/pull/194310#issuecomment-6695751985).

- Frozen main `ba3392580165f2593b9d061aa90607517694ba53` and exact candidate `fba0a7ec448696a86b63c75d8a3280f3ad8397dc` were built in secretless Docker on Node 24.22.1 using the supported CLI runtime build profile.
- Shipped `openclaw.mjs --profile <task-profile> configure --section workspace` ran in real Linux PTYs, 120×40, using isolated task-owned homes, configs, state and database paths.
- Main displays `Workspace: $OPENCLAW_HOME/two spaces`; candidate displays `Workspace: $OPENCLAW_HOME/two  spaces`. Both prompt initial values contain the exact double-space path.
- Real Ctrl-C at the workspace prompt cancels before any answer is submitted. Both exit 1 naturally and each config's before/after bytes and SHA-256 are identical.
- Built-package controls render byte-identical raw PTY streams for ordinary long-line wrapping, spaces at a wrap boundary, tabs, and bullets. Explicit-width checks also retain bullet continuation indentation.
- The changed tests fail on main for exactly three repeated-space cases (six pass); all nine pass on candidate, 924 ms wall time / 153 ms Vitest duration. Typed lint reports zero warnings/errors; formatting passes.
- Whole-PR production +8/-4, net +4; tests +31/-31, net 0. No allocation file, config/schema/auth changes, or new model-facing text. Existing rendered-note setup is shared rather than duplicated.

The contributor's original Windows ConPTY proof remains available in this PR's history; the linked Linux run independently exercises the requested shipped CLI path on the exact unchanged head.

## Merge Risk

Two-way door: reverting restores the prior display normalization without changing config or file bytes. Blast radius is ordinary-space preservation in shared terminal notes; wrapping boundaries and non-space normalization retain their existing behavior.
```
