## What Problem This Solves

Fixes subagent completion failing when overlapping completion callbacks or a newer run take browser-cleanup ownership while an older callback waits to persist its cleanup claim.

## User Impact

Completed subagent work can finish without a spurious cleanup failure. The current owner retains browser cleanup; genuine persistence and authority failures remain visible. No configuration change is required.

## Why This Change Was Made

Retire only the original callback's positively identified pre-commit ownership rejection. A superseded session uses the existing run-retirement path. Committed or uncertain writes and unrelated errors still propagate.

Related: https://github.com/openclaw/openclaw/pull/163725. The failure also reproduced without that PR's authority change.
