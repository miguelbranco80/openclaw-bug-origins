## Fix PR #158124 description (by Oldrich333, opened 2026-09-25T13:01:00Z)

```text
## What Problem This Solves

Fixes: pen drags in the Control UI Browser panel click the remote page instead of scrolling it.

## User Impact

Pen drags scroll; pen taps still click. Touch and mouse behavior stays unchanged.

## Why This Change Was Made

Pen input now uses the existing touch gesture owner, including its movement threshold, click suppression, scroll batching, and capture reset.

## Evidence

Contributor's Chromium proof, using a mocked Gateway:

| Gesture | Main | This PR |
| --- | --- | --- |
| Pen drag up | Click, no scroll | `scrollBy(0, 37)`, no click |
| Pen tap | Click | Click |
| Touch drag up/down | `scrollBy(0, 37)` / `scrollBy(0, -37)` | Unchanged |
| Desktop wheel/click | Scroll / click | Unchanged |

Physical stylus hardware remains unverified. Appearance is unchanged.
```
