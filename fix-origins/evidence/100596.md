## Fix PR #173948 description (by steipete, opened 2026-10-16T07:06:45Z)

```text
## What Problem This Solves

Revert [#173901](https://github.com/openclaw/openclaw/pull/173901). Its upstream batching reduced embedded stream-handler work, but the full-Gateway fixture showed chat frames rising from 28.9 to 39.8 per turn per subscriber (+37.6%) with neutral main-thread CPU (464 to 470 ms/turn). More downstream frames impose work on every connected client. The requested fallback is to revert unless a forward fix demonstrates frames at or below baseline while retaining the upstream savings.

A fixed downstream cadence was investigated, but it has no valid full-Gateway comparison. The isolated fixture repeatedly crashed with native SIGBUS before any primary provider request on both supported Node 26.8 and Node 24.19. SQLite shared-memory mappings and truncation were observed, but the offending operation/root cause is unresolved. Those failures are not performance samples. The downstream candidate is removed from this PR.

## User Impact

Withdraw the increase in chat traffic introduced by model-stream batching. Restore the previous delivery path, deliberately giving up the upstream batching savings until a forward fix has complete Gateway and browser evidence. No user action is required.

## Why This Change Was Made

Restore direct consumption of provider events and remove the 32 ms coalescer, its batching-specific tests, and its documentation. The production module and original partial-aliasing tests match the pre-#173901 versions byte for byte. The final diff touches only the original three files; all experimental Gateway cadence changes are removed. No configuration, schema, dependencies, or public contracts are added.

Production LOC: -153 net (1 added, 154 removed); total diff: 3 insertions, 367 deletions. This intentionally gives up the measured upstream batching savings to withdraw the demonstrated frame regression.

## Evidence

- Prior same-fixture measurements: 5,000 sessions, 6,000 retained runs, 24 concurrent 300-delta streams paced at 10 ms, 24 WebSocket subscribers. Median chat frames/turn/subscriber 28.9167 before vs39.7917 after; Gateway main-thread CPU 464.15 vs470.31 ms/turn. These are retained measurements from the original change, not a fresh measurement of this rollback.
- Previous controlled embedded-renderer text busy time was75.88 to46.30 ms/turn; that improvement is deliberately removed. This is Gateway embedded-handler time, not browser renderer time.
- New full-Gateway before/after and browser-renderer comparisons could not be completed because of the native pre-stream crash. A production Control UI replay harness passed its synthetic smoke, but no smoke result is presented as a comparative measurement.
- Focused partial-aliasing test passes (1 test; 3.77 s wrapper). Changed-file format/lint and diff whitespace checks pass. Independent autoreview is scoped-clean with no actionable P0–P2 findings. Exact-head PR CI: [run 38868334502](https://github.com/openclaw/openclaw/actions/runs/38868334502), rollback head `9da59901084df386ce795145f5bdadcd4fb80539`. No Testbox/Crabbox lease or production Gateway was used.

Release-note context: withdraw model-stream batching after the end-to-end fixture exposed increased downstream chat traffic.
```
