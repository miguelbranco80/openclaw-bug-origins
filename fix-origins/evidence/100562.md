## Fix PR #172885 description (by steipete, opened 2026-10-15T07:15:03Z)

```text
Related: #172507

## What Problem This Solves

Fixes: the Control UI Logs page slows down and stalls the Gateway as the day's log file grows. Every 2-second poll rescanned the whole log file and re-redacted the tail without its fast path. On a 79 MB log, each poll took about 350–475 ms of Gateway main-thread time.

## User Impact

User impact: leaving the Logs page open costs a few milliseconds per poll no matter how large the daily log is. Gateway responsiveness no longer gets worse over the day. Redaction output is unchanged.

## Why This Change Was Made

- **PEM context scan.** Finding out whether a PEM block was open at the window start meant scanning backwards until a BEGIN/END delimiter turned up. Normal logs have none, so each call read the file back to byte 0. `logs.tail` now caches one anchor: the last complete-record cursor plus whether a PEM block is open there, keyed by file, device and inode. The backward scan stops at the anchor, and the state is carried forward across the window with the existing delimiter scanner. Incremental polls therefore read only new bytes.
  - The anchor is dropped on rotation, on truncation below the anchor, on a file switch, and on an inode change between `stat` and `open`.
  - The interface stays generic, so `log-tail` does not special-case PEM.
- **`redactSensitiveLines` regression.** Since the 10.3 redaction rewrite this was about 3x slower than v2026.10.1. Normalizing the PEM pattern built a new pattern array. The transport redactor only uses its built-in prefilter when it gets the exact default array, so the copy turned the prefilter off. The default array is now passed back when the patterns match it one for one.
- **Accepted tradeoffs (also noted in a code comment):**
  - The first call per file per process still scans back once.
  - An in-place rewrite that keeps the same inode and a size at or above the anchor offset would reuse stale state. Logs only append and rotate by file, so this is accepted.
```
