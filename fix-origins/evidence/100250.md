## What Problem This Solves

Environment hides local edits after a pull request is published and can show Retry beside a pull request that already exists for the current branch.

## User Impact

Local change counts remain visible and open the Uncommitted review. Existing pull requests keep their usual row without a duplicate publication offer.

## Why This Change Was Made

The existing Gateway owner already identifies the current checkout's pull requests, including forks, and omits unpublished branch facts when it finds a live pull request. Environment now respects that result independently of an old publication failure, while preserving recovery for an unresolved publication and actions for another unpublished branch. A publication receipt no longer suppresses separately received Uncommitted changes; an authoritative clean working tree still clears the counts.
