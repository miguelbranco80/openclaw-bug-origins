## Fix PR #190571 description (by vincentkoc, opened 2026-11-01T18:00:09Z)

```text
## What Problem This Solves

An update can delete another unfinished handoff's temporary directory solely because it is more than 24 hours old.

## User Impact

Updates preserve other handoffs' runtime and recovery inputs. Unrelated updates no longer prune old handoff directories, so completed logs and abandoned staging may remain longer.

## Why This Change Was Made

Remove the global age-based sweeper from mutable update preparation. An installation fence does not own other installations' handoffs, and a preparing helper can have no `handoff.json` yet. Helpers retain their existing sensitive-file and failed-launch cleanup; legacy cleanup eligibility and repair discovery remain unchanged.

Production: **−42 lines**. Tests: **−22 lines**, including one new public-command regression and removal of the obsolete sweep test/mock. One test-worker registration added. No configuration, schema, migration, or public API changes.

## Evidence

- Traced directory creation, awaited preparation, helper settlement, failed-launch cleanup and repair discovery.
- The regression runs a successful package update with isolated `TMPDIR`, `TMP` and `TEMP`; an aged foreign preparation directory must remain untouched.
- Independent P0–P2 review found no actionable issues. Qualified formatting, Node syntax checks and `git diff --check` passed.
- [Exact-head CI](https://github.com/openclaw/openclaw/actions/runs/41334387656) executed seven relevant updater files: **160 passed, 5 skipped**. This includes the new public-command regression (1 test, 10.63s), existing helper lifecycle (65 passed, 5 skipped), pending recovery (20), admission ledger (9), package lifecycle (9), target/schema (24), and main CLI (32).
- CI completed successfully, including all three PostgreSQL conformance shards, types, lint, architecture, security and Node suites. No reruns or gate exceptions were used.
- No compatible full local dependency install was available. Pre-fix deletion is source-verified; no executed baseline or red/green result is claimed.
```
