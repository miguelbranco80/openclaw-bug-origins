## Fix message body

```text
fix(ui): keep the highlighted slash-command argument during keyboard text selection

In the chat composer's slash-command argument menu, selecting text with the keyboard reset the highlighted argument to the first entry. Pressing Tab then completed the default instead of the argument the user had highlighted (for example `/think ultra` sent no thinking level). The highlighted argument is now kept. Mouse selection, Enter on the default and Escape are unchanged.

Evidence: built Gateway and built Control UI in Chromium and Linux WebKit, twice per ref and engine. Main completed `default` and sent `thinkingLevel: null`; with this change `ultra` stays highlighted and is sent. Gateway replies succeed, and the controls are unchanged. Size: +304 B combined on real served gzip. Screenshots: https://github.com/openclaw/openclaw/pull/194087#issuecomment-6685064869.

Thanks @ly85206559.

Co-authored-by: Ayaan Zaidi <hi@obviy.us>
```
