## Fix message body

```text
fix(hooks): keep linked hook discovery roots literal

Hook discovery trimmed the extra hook directories it was given, so a root whose path started or ended with a space resolved to a different, trimmed sibling, and the hooks from that wrong directory ran. Discovery now uses each configured root exactly as written; a root that doesn't exist is reported as missing. The global path resolver, installer, containment and schema are unchanged.

Evidence: built CLI and Gateway running real linked hooks. With literal absolute, relative and home roots, main ran hooks from the trimmed sibling decoys (twice); with this change each correct hook ran exactly once and no decoy ran (twice). A missing root now exits 1 instead of finding the decoy. Ordinary hooks ran in every run, and configured roots and the SQLite install records are unchanged. Details: https://github.com/openclaw/openclaw/pull/187554#issuecomment-6494009126.

Thanks @Alix-007.

Co-authored-by: Ayaan Zaidi <hi@obviy.us>
```
