## Fix PR #155201 description (by roboclaw-bot, opened 2026-09-21T21:14:58Z)

```text
## What Problem This Solves

Fixes overlapping bullet dots in chat lists on Safari, including the mobile Web UI.

## User Impact

Unordered lists show one bullet per item. Numbered lists, task checkboxes, nested-list indentation, and chat/thinking text keep their existing presentation. No configuration changes or migrations.

## Why This Change Was Made

Chat draws a custom `::before` bullet but relied on `::marker { content: "" }` to hide the native one. [Safari has incomplete support for styling marker content](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors/::marker#browser_compatibility). Suppress the native list style on ordinary unordered items instead of relying on that property.
```
