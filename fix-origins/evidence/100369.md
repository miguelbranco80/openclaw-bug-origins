## What Problem This Solves

Fixes stale Skills content after a watched directory is replaced while another watcher still holds the old filesystem identity.

## User Impact

On Node Linux and Windows, later edits to the replacement directory refresh Skills without restarting OpenClaw. No configuration change is required. macOS, Bun and polling retain the stock Chokidar route.

## Why This Change Was Made

Skills now owns shallow native directory registrations on Linux and Windows. It acquires observation before scanning, carries the identity proven by native admission, fences invalidated scan work, and joins scans and registration retirement during close. Existing path admission and event stability policy remain in use. Chokidar stays unmodified; this change adds no dependency patch, fork or upgrade.

The shared watcher contract lives in a type-only leaf, so the transport and native implementation do not form a static import cycle. Windows fixtures account for the retired generation's required missing-root error and verify replacement discovery followed by an edit to the same cached skill.

Production net increase: 780 lines; tests counted separately. This owns the registration, scan and retirement lifecycle previously delegated to shared dependency state.
