```text
The '(multiple)' combined-store sentinel could be resolved into a real '(multiple).sqlite' agent database registration; preflight admitted it by agent id while deferred startup required an exact path, so configured agents failed deferred startup inspection and /readyz returned 503. ## What Problem This Solves
```

```text
Configured agents can remain degraded after deferred startup when the database registry contains a physical path derived from the `(multiple)` session-store marker.

Fixes #169764.

## User Impact

Gateway startup warns and skips unrelated registrations while inspecting configured database candidates and preparing admitted agents. Unreadable configured paths retain their inspection refusal, allowing isolatable failures to leave healthy agents running. Standalone `openclaw doctor --fix` removes bogus sentinel registrations on every platform, deletes only empty files, and reports retained data-bearing or unreadable files. Active and candidate update passes preserve the updater's captured rollback inventory; rerun standalone Doctor after the update for cleanup.

## Why This Change Was Made

Reject sentinel and unresolved template selectors before path normalization. The concrete-path helper lives in the lightweight SQLite target-path module, so resolver consumers do not acquire the broader `paths.ts` dependency. Preflight uses captured candidate paths and explicit ownership claims without opening runtime stores merely to filter registry rows. Physical alias checks treat missing and non-directory paths as non-concrete while preserving exact configured claims for inspection.

The collision owner supplies already-resolved physical targets to the canonical-target resolver, removing duplicate ownership resolution. Doctor shares registration removal with Windows alias repair; empty sentinel files are deleted and other files are retained with their path reported. The unused internal repair-report export and redundant ownership/removal scans are removed. Total production diff: **+163 / -123, net +40**. Test diff: **+147 / -11, net +136**.
```
