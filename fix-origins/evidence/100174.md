## Fix PR #174902 description (by steipete, opened 2026-10-17T00:55:17Z)

```text
## What Problem This Solves

Deprecated synchronous SQLite SDK calls share warning budgets across whole capability families, so one call can hide another method's migration warning. Several entrypoints omit warnings, and some migration advice names methods that do not exist.

## User Impact

Each deprecated SQLite method now warns once per plugin per process, including across plugin reloads. Missing diagnostics cover the runtime session getter, extension binding, model-provider unregister, ACP resolution, native binding preparation, transcript compatibility callbacks, and legacy state/conversation-binding factories. Prepared-query helpers warn at preparation without wrapping later executions. Awaited/prepared paths stay quiet.

JSDoc and the plugin migration guide use the existing policy: final compatibility day **2026-12-31**, with removal in the **first January 2027 stable release**, only after the deprecation and working replacement ship together in an earlier stable. The guide maps methods to replacements and includes migration examples. No shipped method is removed and no SDK major is introduced.

## Design and Scope

Synchronous completion and authority semantics remain unchanged. Shared private implementations avoid misleading nested warnings for native authority and model-registry adapters. This changes warnings and documentation, with no SQL, schema, credential, approval, or lifecycle policy change. No defensive authority checks are removed and no new race window is accepted.

Reserved memory diagnostics and effect-boundary callers remain explicit follow-ups. The separate Discord change migrates a bundled caller; Telegram and prepared-authority owner work remain outside this PR. A lower-bound ClawHub scan found 15 plugins referencing the runtime session getter (14 runtime, one type reference; 2,027 complete, 380 partial, one failed scan among 2,408 eligible releases). This is not evidence that the API can be removed now.
```
