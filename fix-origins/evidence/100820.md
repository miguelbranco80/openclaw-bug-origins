## Fix PR #175230 description (by steipete, opened 2026-10-17T06:18:41Z)

```text
## What Problem This Solves

An in-process Web Push subscription request can commit after its caller is revoked or its Gateway resolver retires.

## User Impact

Reject revoked in-process mutations at the worker commit boundary. Accepted work still survives transport retirement while its original caller and Gateway authority remain valid.

## Why This Change Was Made

#174610 made in-process requests worker-capable, but the worker guard retained only the transport check. Web Push and approval writers consume that guard, so they could omit the composed caller/resolver checks.

Bind the worker commit guard to the existing complete lifetime assertion. Keep preparation transport-only and preserve worker execution. This follows #174610's stated contract: final commit checks the complete authority. No schema, configuration, public API or WebSocket authority change.

The three existing regression cases remain unchanged, including the successful transport-retirement case. Every assertion remains; no retries or timeouts changed.

## Evidence

- Current-main baseline `053cf12a7a0e`: all three original cases fail (65.50s command wall).
- The unchanged original file passes all 3 cases after the fix: 161.22s Vitest / 188.36s command wall (3.16s test body; compilation dominates).
- Eight sibling files pass all 115 cases: 224.57s command wall. These cover push routing/profile guards, retained authority, real worker persistence, and opaque/prepared in-process commit guards.
- Targeted Gateway-method test types, typed lint with the matching core config, boundary lint, formatting, whitespace checks and independent P2 autoreview all pass.

The original failure is [main hourly 39006528379, job 117320109664](https://github.com/openclaw/openclaw/actions/runs/39006528379/job/117320109664). Local proof uses the native test wrapper with `--maxWorkers=1`, Node 24, and an isolated compilation cache. PR CI provides broad proof; no workflow dispatch, rerun or unchanged re-push.
```
