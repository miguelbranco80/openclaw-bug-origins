## Fix PR #154922 description (by shakkernerd, opened 2026-09-21T14:36:12Z)

```text
## What Problem This Solves

Native Gateway tools derive the minimum scopes required by a method. Treating that generated minimum as an explicit restriction can discard a staff caller's existing broader authority when the method accepts session-only access. Conversely, an explicitly narrowed native request can regain an administrator grant from its surrounding invocation, including when it transfers work to an accepted delayed continuation.

## User Impact

Native tools retain existing broad read, write, or administrator authority for implicit method requirements. Explicit scope arrays, including an empty array, remain exact restrictions. Guest and scoped System callers cannot gain broader permissions from a method minimum or a surrounding invocation.

The restriction also survives nested requests, native autonomous-agent admission, and delayed continuations. An unidentified scoped caller retains its declared read-only or empty vector during a continuation transfer. Explicit transport calls and unmarked plugin dispatch keep their existing contracts; this change adds no public option, protocol field, or persisted state.

## Why This Change Was Made

The native bridge preserves whether scopes were explicitly supplied. The existing dispatcher distinguishes a method minimum from an explicit or retained caller ceiling, qualifies the original admitted authority, and intersects it with the current caller's restriction. A generated session scope retains its broad counterpart only when the source already permits it; explicit restrictions do not regain inherited ADMIN.

Accepted continuations obtain their complete effective ceiling from that same dispatcher. This removes their separate selection of an invocation's original scope vector and preserves the existing rules for source identity, caller narrowing, revocation, and lifetime. Host-owned agent admission still removes human profile attribution without losing the originating permission ceiling. The scope-provenance flag remains internal to the native adapter.
```

```diff
+  method: string;
+  requestParams: unknown;
```
