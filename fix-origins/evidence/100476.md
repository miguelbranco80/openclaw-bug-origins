## Fix PR #178219 description (by RomneyDa, opened 2026-10-20T07:19:13Z)

```text
Related: #170956

## What Problem This Solves

Fixes: a Windows update reports generic Scheduled Task recovery failure instead of elevation guidance when a Dutch-language task ACL denies disabling the Gateway task.

## User Impact

The updater reports `windows-task-elevation-required` with the existing manual update steps and does not attempt an unnecessary task re-enable. It still refuses to swap files without safely stopping the managed Gateway. This does not fix the report's separate startup latency or orphaned-child observations.

## Why This Change Was Made

The existing access-denied classifier recognizes English text and HRESULT `0x80070005` but missed the report's exact `ERROR: Toegang geweigerd.` diagnostic. Extend that classifier and its existing boundary-test table; no new config, dependency, schema, permission, or service behavior is introduced.

Update behavior: the installed updater owns this stop step, so a newer candidate cannot repair an already-running older updater. Existing affected installations still need the documented elevated/manual first hop; releases containing this fix improve subsequent updates.

## Evidence

- The exact Dutch case failed before the repair through the real Windows update-maintenance and task-control owners, with only native `execSchtasks` mocked. English/HRESULT controls passed. Baseline wrapper wall time: 38.59 s.
- `pnpm test src/cli/update-cli/update-command-service-maintenance.windows-recovery.test.ts --maxWorkers=1`: 11/11 passed, 30.16 s wrapper wall time (test bodies under 1 s; transform dominates).
- Production core and CLI-update test type graphs, changed-file typed lint, formatting, and `git diff --check`: passed.
- Independent Codex autoreview through P2: scoped-clean.
- Native Dutch Task Scheduler and an installed older-driver update were not exercised by this two-line fix. The native API response in this test is synthetic, using the exact reported diagnostic.
- PR CI provides broad proof and is pending at handoff; local wall times are recorded above.

The missing original elevation-guidance repair #171109 and this follow-up are both needed on the 2026.10.6 release branch.
```
