## Fix message body

```text
fix(ui): show full-store totals in the Workboard board picker

The Workboard board picker discarded the full-store board summaries and recounted only the first 100-card page, so boards showed wrong totals (for example 100/100 and 0/0 instead of 149/150 and 25/25) until every card was loaded. The picker now uses the store's summaries.

Evidence: built Gateway and Control UI in real Chromium with 175 cards created through real RPCs. Before loading more, main showed Default 100/100 and Operations 0/0; with this change it showed 149/150 and 25/25, unchanged after loading the remaining page. Re-proven after merging current main: https://github.com/openclaw/openclaw/pull/181164#issuecomment-6514712715.

Thanks @AmelioMansour.

Co-authored-by: Ayaan Zaidi <hi@obviy.us>
```
