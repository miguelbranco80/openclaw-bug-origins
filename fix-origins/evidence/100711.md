```text
## What Problem This Solves

Fixes: Side chat disables its question box while answering, preventing users from drafting a follow-up.

## User Impact

Users can keep editing the next question during an answer. Sending still waits for the active answer; disconnected controls remain disabled. Drafts survive answer completion and errors.

## Why This Change Was Made

The textarea incorrectly shared the send button's busy guard. Keep its normal placeholder and let the existing thread status show that an answer is pending. Focus tests now wait for the pending exchange and explicitly establish the foreground input they intend to protect.

The failing cron recovery test compared process-wide work counts before and after an asynchronous operation. An unrelated root finishing changed 1 to 0 despite correct recovery. Recovery tests now borrow each timer's exact admission scope and verify it becomes unusable when that tick settles. This also detects a leaked tick even if unrelated work finishes. Startup, durable repair, events, reservations, and error-settlement assertions remain covered. Cron production code is unchanged.
```
