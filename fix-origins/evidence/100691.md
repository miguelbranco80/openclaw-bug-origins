## Fix PR #182485 description (by anmol0b, opened 2026-10-24T09:39:30Z)

```text
## What Problem This Solves

Fixes: MCP Apps show a blank panel and time out in Safari and macOS WebKit when their sandbox iframe is attached before navigation.

## User Impact

MCP Apps initialize despite WebKit omitting the iframe referrer. Parent-message authorization and the Control UI's no-referrer privacy policy remain intact.

## Why This Change Was Made

The shared sandbox binds its parent from the browser-reported nearest ancestor origin, retaining the referrer fallback for browsers without that API. It still requires an HTTP(S) origin, rejects opaque parents, checks message source and origin, and sends replies only to the bound origin. This repairs the existing shared owner without adding a setting or changing the bridge protocol.

Thanks to @anmol0b for the fix and browser reproduction.

**Before landing:** this security-sensitive path requires maintainer security approval for the final head.
```
