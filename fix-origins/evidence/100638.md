## Fix PR #167358 description (by RomneyDa, opened 2026-10-08T17:35:41Z)

```text
## What Problem This Solves

Fixes updates being blocked by completed recovery history from an older reader format or by unfinished cleanup of an obsolete package.

## User Impact

Completed history no longer prevents the next update. Unfinished restoration, unknown or corrupt records, and active mutations still require recovery; retained evidence is not deleted or rewritten.

This changes the installed updater. It cannot run inside an unchanged older updater that refuses before fetching the candidate.

## Why This Change Was Made

Admission needs to determine whether recovery is pending, not execute every historical record. Use the existing validated inspection codec for history and strict execution decoding only for the operation being acted on. Typed terminal package retirement is cleanup; unfinished restore progress remains blocking. Preserve the matching operation’s finalizer and prevent CLI fallback from completing over unrelated unfinished recovery.

This is complementary to [Scott’s package-publication repair](https://github.com/openclaw/openclaw/pull/167302) and [package receipt/cleanup repair](https://github.com/openclaw/openclaw/pull/167330), not a replacement for either.
```
