## Fix PR #146712 description (by steipete, opened 2026-09-13T03:35:45Z)

```text
Related: #130741

## What Problem This Solves

Fixes: stale task notifications can close a replacement task's terminal, and a failed broadcast can suppress later task updates.

## User Impact

Task updates reach the current requester, and terminal cleanup applies only while the task and its execution still own that cleanup.

## Why This Change Was Made

The Gateway task observer now rechecks task, execution, and observer ownership around synchronous publication. Failed broadcasts roll back only their own deduplication entry, preserving nested updates. A deletion observed during publication cancels the pending terminal close even if the host recreates the same task ID. Ordinary execution retirement, metadata updates, and registry reloads remain supported.

This is a focused correctness split from the broader Swarm work. It preserves synchronous notification and cleanup, with no public API, schema, configuration, or retention changes.

## Evidence

- Registered-entry regressions fail on the original implementation; all 49 tests across the Gateway subscription and terminal task-lifecycle suites pass with the repair.
- Coverage includes requester changes, replacement execution, nested broadcast failure, deletion and recreation through host APIs, and positive controls for normal retirement and reload.
- Targeted lint, canonical changed checks, and the normal build pass. A fresh independent P0/P1 review found no actionable findings in scope.

Full CI exposed a test fixture importing task lifecycle mutations directly. The fixture now reuses the existing task creation and executor interfaces without changing its assertions or either production file. All 54 architecture and owner tests, the final changed gate, and focused P1 review pass.

Local proof matches the committed source files. Exact-head CI is tracked separately. This leaf does not establish live-provider behavior or the broader 500 ms responsiveness target; that work remains in #130741.
```
