## Fix PR #192931 description (by obviyus, opened 2026-11-04T17:57:59Z)

```text
## What Problem This Solves

A UX audit of the Skill Workshop off state from #192766 found five problems:

- The off panel never got its intended layout. `.settings-group.oc-settings-group { display: block }` overrode `.sw-empty { display: grid }`. The wand icon sat beside "Skill Workshop is off" instead of above it, and an error banner touched the bottom of the button.
- A failed enable showed raw Gateway text. On a real Gateway with plugins globally disabled it reads `plugin "skill-workshop" could not be enabled (plugins disabled)`. A plugin that fails to load shows `Plugin operation failed during activate: plugin load failed: … Gateway generation 3: replacement not applied.`
- A failed plugin check said "Couldn’t load the Workshop. Try again." plus the raw message, describing the wrong failure.
- Keyboard focus fell to `<body>` as soon as the button turned busy (`disabled`), and stayed there after the Workshop loaded.
- The page relies on the Gateway's `plugins.changed` broadcast (sent `dropIfSlow`) to load the Workshop. If a successful enable is never published to this client, the button stayed disabled on "Turning on…" with no way forward.

## User Impact

- The off, missing and failed panels stack icon, title, text, action and error with consistent spacing. The library's own empty state uses the same rule and gains its intended spacing.
- Enable failures read "Couldn’t turn on Skill Workshop. Try again." Check failures read "Couldn’t check whether Skill Workshop is on." with Retry. The raw, redacted Gateway text sits under "Show details", using the existing `ErrorDetails` from #192057.
- While the plugin turns on, the button is `aria-disabled`/`aria-busy` but keeps focus. When the Workshop loads in place, focus moves to the Workshop panel.
- If the Workshop hasn't arrived 15 s after a successful enable, the page rechecks `plugins.list` once. If the plugin is on, it says "Skill Workshop is on. Reload to open it." with a Reload button. If it's still off, the button comes back.
```
