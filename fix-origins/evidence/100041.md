```text
Related: #149612

## What Problem This Solves

Fixes canceled agent turns waiting through an unnecessary idle timeout when cancellation arrives during cleanup.

## User Impact

Canceled turns stop optional idle waits promptly while required transcript writes and runtime disposal still finish. This does not reset session lanes, replay completed actions, or change provider-generation authority.

This fixes the demonstrated cleanup races; the full provider-reload stall and high memory usage remain unverified.

## Why This Change Was Made

Cleanup now rereads cancellation after draining transcript writes and forwards the cancellation signal into the optional idle wait, including preparation-failure and compaction cleanup. The signal interrupts only that wait; persistence and resource settlement retain their existing ownership and ordering.
