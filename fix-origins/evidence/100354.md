## Fix message body

```text
After an interrupted package activation, a leftover package publication journal that no longer matched the installed package made every later update fail with update-recovery-pending ('Package publication journal does not match its installation'), as on a 2026.10.5 -> 2026.10.8 macOS update. The activation settlement owner now retires such a journal with a visible warning, preserving its diagnostics, when neither the recorded package generations nor its published launchers are installed, so the next update proceeds; a journal whose completion or rollback still matters stays armed. Node-floor rejection already happens before any journal is written.

Fixes #186314.
```

## What Problem This Solves

Fixes #186314. A manual npm install or copied installation after an interrupted update can leave a package publication journal that blocks every later CLI or Control UI update with `update-recovery-pending`.

## User Impact

The next update can retire obsolete recovery custody with a warning and continue. The current package and launchers remain untouched, and the journal, helper, and retained package trees are preserved for diagnostics. No schema, dependency, or configuration changes.

## Why This Change Was Made

Package activation settlement already owns recovery admission. It now recognizes an external installation only when neither recorded package generation nor any recorded published launcher remains installed. Inode comparisons exclude the old generations even across a remount. Changed journal bindings permit settlement only; they never grant publication or restoration authority. Live executor authority and the replacement observation are checked again before settlement. Dry-run uses the same eligibility decision without changing state.

Still-installed candidates continue through verification and settlement; incomplete publication and live launcher custody still require recovery. The existing selected-Node compatibility check already runs before journal creation. Coverage now includes the reported Node 26.4.0 runtime.
