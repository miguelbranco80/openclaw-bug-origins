## What Problem This Solves

Long code blocks can keep syntax-highlighting workers and Markdown observers active after their browser tab becomes hidden.

## User Impact

Hidden tabs release pending syntax workers and foreground observers across transcripts, Markdown attachments, and Custodian. Returning resumes unfinished highlighting for presented panes, preserving complete code text and controls.

## Why This Change Was Made

The shared `MarkdownBlocks` owner composes document visibility with caller presentation intent using the existing shared subscription. A tab reveal cannot reactivate a pane the caller parked. Disposal releases the subscription. Worker cancellation and source retention remain with their existing owners.

ClawSweeper identified that the first ref-level gate missed attachment and Custodian owners. This revision moves the gate into the shared owner and removes the adapter policy.
