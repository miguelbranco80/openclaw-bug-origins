## Fix PR #149863 description (by fuller-stack-dev, opened 2026-09-16T07:45:54Z)

```text
## What Problem This Solves

Fixes a main conversation showing "This turn ended before a reply: subagent source lifecycle changed before completion delivery" when a completed subagent reports the same result twice or its queued notification becomes obsolete.

## User Impact

Unchanged completion results remain deliverable. Obsolete notifications are cancelled without adding a failed-reply message to the conversation or replaying stale work after restart. Genuine execution failures remain visible.

## Why This Change Was Made

Both lifecycle events and `agent.wait` can report completion. Replacing an unchanged outcome invalidated the authority captured by an already prepared notification. Preserve that outcome when its facts have not changed, and route actual ownership loss through the existing Gateway cancellation mechanism. Stale-result checks and private-completion observation deadlines remain enforced.

## Evidence

- Reproduced both failures on unmodified upstream code. Identical and older equivalent completion reports invalidated prepared results; the real Gateway saved source revocation as a failed session and appended a `run-failed-before-reply` notice.
- 569 focused tests pass with the fix, including the real Gateway/SQLite cancellation receipt and replay after restart, changed-result rejection, requester reset/replacement, genuine provider failure, required receipt-write failure, and delayed private admission.
- The Gateway proof uses a controlled agent command with real admission, lifecycle persistence and SQLite. It does not invoke an external model or modify a live deployment.
- Production and test type checks, targeted lint, database guards and import-cycle checks passed. Independent autoreview reported no actionable P0-P2 findings; a source-blind operator probe passed all six observable Gateway/history/receipt clauses.
- The seven producer/Gateway regression probes also pass on publication head `f2f3deeea602a795c5ab8df349658e438b58aacc`. [Raw red/green results, Gateway observations and artifact manifest](https://gist.github.com/fuller-stack-dev/ace582f72cf0a89ef7bda0db90c7fff8).
```
