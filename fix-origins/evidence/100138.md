## What Problem This Solves

Sending a public status URL in Control UI could permanently shorten it in stored history and model input because credential redaction mistook part of the URL for a secret.

## Why This Change Was Made

One shared matcher classifies bare credential candidates and their URL context. Server redaction, browser display, and approval masks use its match records. Existing structured-field and registered-secret rules remain in place.

## User Impact

New messages preserve the tested public URLs, user paths, and numeric ports while credential controls remain masked. Previously lost text cannot be restored. Signed-URL behavior is unchanged. No configuration or stored-state migration is added.

Consumers: stored messages, model input, tool cards, approval displays, and programmatic redaction callers now share the corrected classification.

## Evidence

Control UI chat.send → chat.history and complete recorded model requests reproduce the loss before the fix and preservation after it. Telegram sends and replies, rendered tool cards, and registered approval displays passed. The focused suites passed 405 tests; public plugin development API checks and a read-only secret sibling passed 33. Concurrent same-agent writes remained responsive. Previous-release state remained byte-identical during compatibility checks. These tests cover the enumerated URL and credential forms, not arbitrary URLs.
