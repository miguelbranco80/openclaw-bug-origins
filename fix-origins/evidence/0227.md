## Fix PR #196300 description (by roboclaw-bot, opened 2026-11-09T23:04:05Z)

```text
## What Problem This Solves

Taps near the edge of a sidebar section or the Pages pencil can activate the neighboring control instead.

## User Impact

Sidebar section headers and the Pages pencil get separate 48dp touch areas. No configuration or migration is needed.

## Why This Change Was Made

Reserve space where Compose’s automatic touch expansion overlaps another control. Keep the compact catalog plus and Pages label unchanged: their expanded targets fit once their containing rows have enough room.

## Evidence

- **Native pencil-edge routing:** the real app collapses Pages and opens no menu on main snapshot `dab086c0d82b`. With this PR composed onto the same snapshot, the same 23dp-left-of-center gesture opens the pencil menu and leaves Pages expanded. Native input coordinates came from accessibility bounds; both installed APK hashes matched the build outputs.
- **Regression controls:** local runs on published head `f6521508c67418beaeb96b669a75a2a694601727` passed all 5 Play and 5 third-party sidebar cases without skips. Keeping the test bytes unchanged, restoring both baseline production files fails the Pinned edge assertion; reverting only the pencil size fails the popup assertion. Restoring the fix passes all 5 Play cases again. These are production Compose/Robolectric checks, not physical-device tests.
- **Build and CI:** both full Play debug APKs built with normal asset generation. Existing exact-head [Play](https://github.com/openclaw/openclaw/actions/runs/42721097686/job/129515724886), [third-party](https://github.com/openclaw/openclaw/actions/runs/42721097686/job/129515724826), [Android lint](https://github.com/openclaw/openclaw/actions/runs/42721097686/job/129515724803), native [4KB](https://github.com/openclaw/openclaw/actions/runs/42721097686/job/129515724813) / [16KB](https://github.com/openclaw/openclaw/actions/runs/42721097686/job/129515724921), and [CI gate](https://github.com/openclaw/openclaw/actions/runs/42721097686/job/129523635501) passed; they were not rerun for this landing.
- **Review:** independent review of the main-plus-patch composition was scoped-clean with no code findings; relevant owner and fixture inputs were unchanged at the capture baseline. [ClawSweeper](https://github.com/openclaw/openclaw/pull/196300#issuecomment-6754279766) also reported no code findings. The change remains two production-line replacements and one focused regression, with no new state, dependencies, or test-budget changes.
- **Limits:** the new native comparison exercises the Pages pencil, not a new native header-edge test. Header routing is covered by the matched Compose controls above. No physical phone, live Gateway, or model-provider behavior is claimed.
- [Landing review and fresh validation](https://team.openclaw.ai/chat/roboclaw/~key/dashboard/0cce2a1a-7ea4-4074-ba4b-bf92de66e1d0) (team reference; not public).
```
