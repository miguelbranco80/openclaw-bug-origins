## Fix message body

```text
Revalidate the originating state context before a delayed completion retry
starts another wait. Closing or replacing that database retires the retry
even while its run and agent lifecycle remain resident.

fd1467d4669 introduced captured state admission into completion waits without
carrying its validity check across the retry timer. The real-registry
regression holds native database cleanup open and advances the existing
25 ms timer after the original wait releases its continuation. Main fails
with an unhandled STATE_DATABASE_READ_ADMISSION_INVALIDATED rejection; the
same case now passes without another wait request or changed assertions.

Validation: all 32 restart-integration cases and the combined 443-case
regression/sibling packet passed on Testbox. Remaining static gates must
complete before publication after the interrupted Testbox typecheck run.
```
