## What Problem This Solves
SDK API comparisons installed and rendered revisions even when different refs resolved to the same commit. That redundant work could fail an unchanged comparison.

Identical revisions now produce the normal empty API diff without creating render worktrees or installing dependencies. Runtime and published plugin SDK behavior are unchanged.

Resolve and validate every ref first, then render only unequal comparisons. Both paths use the same ordered payload and digest constructor, preserving JSON, reports, release evidence, and acknowledgement handling.
