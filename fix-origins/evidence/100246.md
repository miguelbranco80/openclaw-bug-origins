## Fix PR #167507 description (by steipete, opened 2026-10-08T22:39:48Z)

```text
## What Problem This Solves

Fixes sent prompts and image attachments reappearing on New session when a tab is closed immediately after the confirmed conversation URL appears.

## User Impact

Closing the newly opened conversation no longer brings back its sent prompt or attachments when New session is reopened. The immediate conversation preview still opens before admission, and saved worktree-name preferences still clear asynchronously.

## Why This Change Was Made

Related: #167384.

The in-memory retirement fence is synchronous, but clearing the saved draft still awaits IndexedDB reads and a compare-and-set write. Publishing the URL before that operation finishes lets tab teardown interrupt it. Await the existing durable retirement before confirmed navigation, preserving the lifecycle check after the await. Confirmed navigation now waits for draft storage to settle through its existing owner.

## Evidence

Both reported browser failures reproduced on Linux with finite IndexedDB contention, keeping the original submit → confirmed URL → close → reopen assertions. The fix passed 20 pressured runs per case, and three replays of each original failing shard. The deferred-cleanup unit assertions fail on the original code and pass with this repair.

The mocked UI E2E configuration passed all 674 files and 3,190 tests, with no inventory gaps. The full UI unit configuration passed 1,441 files and 20,260 tests, with five existing configured skips. After integration, the focused browser cases passed 23/23; the changed submission owner passed 33/33 in 6 seconds with one worker on Linux, and all 26 worktree-preference cases passed. No test cases or CI jobs were added.

Formatting, typed lint, boundary lint, UI types, docs, and P2 review passed. All selected changed-check lanes are covered; its old-base unused-export finding was already fixed on main, and the integrated script, production, and full-tree export scans each report zero entries. Rebases preserved all five reviewed file hashes; full-config proof precedes the final rebase.

The separate suspended-Gateway fixture repair landed as 9d606a28e0d5. This PR contains only the production retirement repair, its existing regression assertions, and the documentation update.
```
