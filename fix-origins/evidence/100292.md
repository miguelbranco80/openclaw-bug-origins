CLI backend descriptor and ID lookups accepted an explicit environment but dropped it when evaluating installed-plugin activation. A lookup prepared for a custom state directory could therefore use the process directory’s bundled-discovery policy and incorrectly hide an available backend.

## What Changed

Forward the existing environment to the existing activation predicate in both lookup paths. Policy, cache lifetime, public signatures, and persisted state stay unchanged.

Complete the related test-routing cutover for six remaining consumers that perform real worker-backed model preparation. They use the existing forked database-worker project; media routing remains exclusive, and the simple-completion fixture retains its existing compiled-runtime prerequisite. The already-landed CLI validation and TTS selection entries are preserved. No test bodies, admission guard, or assertions are weakened.

- The unchanged config-validation case reproduced the host-broker refusal on its old CLI thread route. The maintained fork route passes the whole 23-case file; six related files pass 82 cases, and the compiled simple-completion file passes seven more after a clean normal runtime build.
