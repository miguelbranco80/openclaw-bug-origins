## Fix PR #171734 description (by steipete, opened 2026-10-14T04:44:46Z)

```text
Fixes #171367

## What Problem This Solves

Fixes a Telegram hot restart failing on a disabled account's unresolved SecretRef and requesting an unnecessary Gateway recovery restart.

## User Impact

Operators can reload channel settings with disabled accounts whose credentials are unavailable. Enabled accounts still report unresolved credentials, and accounts disabled while running still receive cleanup. No configuration changes or migrations are required.

## Why This Change Was Made

Startup already skips disabled accounts before resolving credentials. Whole-channel stop also enumerates configured idle accounts, but its fallback cleanup previously resolved their credentials regardless of enablement. The shared channel lifecycle owner now skips that preparation for disabled idle accounts while retaining captured teardown for admitted lifetimes and joining any already-admitted idle cleanup. This applies to all channel plugins rather than weakening Telegram's strict token resolution.

Cleanup retains the selected config, plugin/account identity, credential values and paths, and admitted lifetime because it must stop the original runtime rather than redirect teardown to a replacement; the existing stop capability lease fences the effect and the five-second cleanup bound is unchanged. Idle fallback uses the stop operation’s selected config/registration, with disablement checked before credential preparation. This change introduces no new session binding or deferred authority.

## Evidence

- Source/history confirmation: `server-channels.ts` whole-channel stop → `runChannelAccountStop` fallback resolution → `restartGatewayChannels` recovery callback. The inactive-surface contract and startup guard already exclude disabled accounts; teardown was the gap.
- Regression: `server-reload-channel-restart.inactive-accounts.test.ts`, `preserves lifecycle and credential policy for a $name account`, covers **disabled idle**, **newly disabled running**, and **enabled unresolved** through the production hot-restart entry point and channel manager with a healthy sibling, strict file SecretRef handling, and synthetic transport hooks. It checks no recovery escalation, preserved admitted cleanup, and visible enabled-account failure.
```
