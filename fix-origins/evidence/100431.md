```text
AI-assisted.

Supersedes #146988 by @Alix-007. The three contributor commits are retained with their authorship; this branch adds one test-ordering commit.

## What Problem This Solves

A configured directory or non-executable file was reported available, so iMessage setup skipped the command-path correction. Explicit paths now use the shared executable-file predicate without lexical normalization or a new cache.

## User Impact

Directories and mode-0644 files now show the CLI-path guidance and `imsg CLI path` field. Executable files and valid symlink-parent paths retain `iMessage next steps`; trailing `/` still requests correction. No config key, schema, protocol, dependency, or stored format changes.

Saved paths remain intact until the user completes setup. Cancelling leaves configuration unchanged; the next setup or preflight checks the path again. The existing input validator is unchanged, so this repair offers correction rather than guaranteeing that an entered replacement can launch.

## Test correction

Local validation found that the contributor's positive controls warm native macOS execute-access lookup before the invalid-traversal assertion. The takeover preserves all contributor commits and every assertion, checking rejection before those controls. It changes no production code. A standalone C probe reproduces the native lookup transition after successful execute access; its internal cause was not traced. Checking fresh invalid fixtures first preserves every assertion and still fails an intentionally incorrect lexical-normalization variant. The traversal tests do not claim order-independent rejection after earlier native checks.
