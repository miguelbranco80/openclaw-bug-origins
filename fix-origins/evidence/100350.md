```text
Closes #186736

## What Problem This Solves

Avatars, names, action icons, and session counts are misaligned in the Online people list on touch devices. Names also touch the avatars because the fixed avatar column does not accommodate the row's padding.

## User Impact

Mobile rows have aligned content and an 8px gap between each avatar and name. Quiet action buttons, touch targets, long-name truncation, and trailing counts are preserved. Desktop layout is unchanged.

## Why This Change Was Made

Use the avatar's intrinsic column size and center the content within the existing touch row. Render the menu SVG as a block to remove its inline baseline offset. All changes stay in the existing touch CSS rules.

## Evidence

- Inspected the actual Control UI at 390 × 844 and 320 × 844 with identical synthetic people, mixed counts, and a long name. The avatar-to-name gap is 8px and their vertical centers match.
- Desktop row geometry at 1280 × 800 matches the previous implementation.
- All 3 existing production-bundle people-panel E2Es passed, including menu actions, pinning, navigation, and filtering. No permanent tests added.
- Targeted stylesheet lint, formatting, and diff checks passed. Independent Codex review found no actionable P0–P2 findings.

### Before / after

Actual Control UI with a synthetic Gateway fixture, dark theme, touch viewport 390 × 844. Normal sidebar navigation and passive measurements; screenshots retain live animations and caret state. Crops come from the captured viewport frames.
```
