## What Problem This Solves

Fixes Talk agent requests silently aborting immediately after voice connects, even while the Talk session stays open.

## User Impact

Later spoken requests can reach the agent instead of inheriting a cancelled voice-setup lifetime. Ordinary authentication, permissions, explicit cancellation, and restart/suspension admission remain in force. No configuration or database migration is required.

## Why This Change Was Made

The sideband callback can retain the completed HTTP offer's async work scope. Giving each consultation its own existing detached work scope keeps its work and cleanup tracked independently of setup, while still refusing new work during suspension or restart. The existing independent admission API keeps its current behavior by default; Talk explicitly selects detached work.

## Evidence
