## Fix PR #178724 description (by steipete, opened 2026-10-20T19:38:59Z)

```text
Fixes #178589
Supersedes #178643, thanks @pattty847.

## What Problem This Solves

Doctor run from the home directory can report an official installed Codex plugin as unverified and recommend an unnecessary reinstall or repair.

## User Impact

Installed plugins keep their global provenance when the workspace's extensions directory resolves to the same directory. Doctor can inspect the official installation regardless of whether it runs from home or the state directory. No configuration change or migration is required.

## Why This Change Was Made

The workspace scan ran before the global scan and claimed the same physical plugin entry. Discovery now leaves the overlapping root to its existing global/install-record owner, using the existing physical-directory comparison. Explicit load paths, ordinary workspace discovery, and official-install verification keep their existing behavior.

Production: +6/-9 (net -3); tests: +40/-0; docs: +1/-0. The existing identical UID return guards were combined, and the regression lives in the smaller discovery-provenance sibling suite. No baseline or suppression changed; the line-cap ratchet passes.
```
