## Fix PR #180734 description (by roboclaw-bot, opened 2026-10-22T15:37:56Z)

```text
## What Problem This Solves

Fixes: download and copy icons remain permanently visible over chat images on mobile.

## User Impact

Mobile image previews are unobstructed. Tapping an image still opens the existing lightbox, including its download control. Desktop controls retain hover and keyboard-focus behavior. No configuration or migration is required.

## Why This Change Was Made

The existing non-hover/coarse-pointer media rule forced the overlay on. Hide that overlay instead, without changing the image or lightbox components. This follows input capability rather than viewport width, so touch-first tablets are covered too.

Contributor credit: Hannes supplied the request and UX direction.

## Work sessions
```
