## What Problem This Solves

Fixes repeated filesystem preparation that occupies the Gateway main thread when a configured fleet exceeds 256 agent directories.

## User Impact

Large registered fleets reuse prepared directories across repeated walks, leaving the Gateway more time to serve requests. Native invalidation, cleanup, and the existing 30-second authority/degraded and five-minute healthy recovery bounds remain intact. No configuration, protocol, schema, dependency, or migration changes.

## Why This Change Was Made

The prepared-path capacity now grows with registered directories while keeping extra aliases bounded. The directory-observation owner examines only the changed directory when advancing its timer; closing a subscription does not scan the observation set.
