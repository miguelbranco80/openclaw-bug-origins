## What Problem This Solves

Updates can abort with `candidate-snapshot-failed` / `SQLite worker queue capacity reached` when advisory snapshot progress outruns the history database.

## User Impact

Snapshot progress stays bounded, and a certified queue refusal for optional history produces a warning while validation continues. Required recovery and terminal receipts, cancellation, revoked authority, and uncertain cleanup remain failures.

The installed updater owns the progress writer. A running 2026.10.4 updater cannot gain this repair by staging a newer candidate. After a verified backup, affected operators must stop their Gateway through its actual owner and use the documented manual package-manager procedure to install a release containing the fix, then run Doctor and verify startup with the same account, prefix, profile, and state paths.

## Why This Change Was Made

The snapshot parent started a ledger mutation for every notification and joined them without limiting concurrent admission. The existing three-attempt policy only covered worker commit-admission timeouts; canonical broker overload rejected before that policy could run. The snapshot owner now keeps one write in flight and coalesces pending observations to the latest one. The asynchronous ledger owner recognizes certified pre-dispatch overload only for optional steps and uses its existing bookkeeping-skipped outcome. The obsolete concurrent-failure aggregation is removed.

The reported cause of slow storage and the reporter's local updater modification are not independently attributed here. Controlled broker saturation proves the current source failure boundary.

For #177482, current candidate acquisition already processes database families sequentially through consistent online backup. Both the reported target and current source exclude recognized rehearsal-private state from ordinary artifact-preserving copies. The ten-attempt error identifies the artifact-preserving path, but the report omits its final source-change condition and the reduced rehearsal passes. This change does not establish that candidate-startup root cause or bypass consistency checks.
