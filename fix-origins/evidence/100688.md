## Fix message body

```text
A worker cold preflight could record a missing database path, then mistake
another writer creating that database for source replacement. Return from
cold restoration when the store is confirmed absent and leave creation to
the canonical writer.

Use synchronous filesystem metadata inspection to avoid adding another
completion-order race before writer admission. Existing stores retain
worker metadata reads, physical source checks, and caller/owner authority;
transaction checks still protect cold data and writer claims.

Restore the SDK locking regression removed in #162634 with an event gate
and joined writers, preserving its exact ordering and single-message
assertions. Give existing-store preflight fixtures the file they describe.
No storage format, schema, retention, or update migration changes.

The restored case fails against the original #162521 owner and passes
20 pressured whole-file runs (240 test cases). The final SDK file took
11.70 s in Vitest / 26.322 s wrapper on Linux; the new case took 390 ms.
```
