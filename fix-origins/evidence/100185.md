## Fix PR #159717 description (by steipete, opened 2026-09-27T15:03:33Z)

```text
## What Problem This Solves

Ordinary, successful CLI commands printed a maintenance-lock warning telling the operator to stop their Gateway whenever that Gateway was healthy and running. Examples are `openclaw system heartbeat disable --json` (exit 0, `{"ok":true,"enabled":false}`) and `openclaw hooks enable command-logger`. Following that advice would take down a working Gateway for no reason. Found by live QA on `main` (`244d4419723`).

## Why This Change Was Made

Startup cleanup of plugin source captures (`src/commands/startup-plugin-source-captures.ts`) intentionally tries exclusive maintenance ownership to reclaim retired native captures. It is opportunistic and advisory by design: see `f3a2a91cb4c6` and `docs/plugins/architecture.md`. When the operator's live Gateway holds state ownership, failing to get that lock is the expected case, not a problem. The cleanup forwarded the lock helper's generic "stop the Gateway" guidance anyway.

The fix treats exactly one typed case as a silent skip: `DoctorSqliteMaintenanceLockUnavailableError` whose cause satisfies `isGatewayLifecycleContentionError`. Everything else is unchanged:

- maintenance lock acquisition, current-authority checks, receipts, and pruning;
- every other warning, including permission errors, other lock failures, and cleanup warnings.

Pruning never runs without ownership, so lifecycle ownership is not weakened. The architecture doc describes the skip.

## User Impact

Routine commands no longer tell operators to stop a healthy Gateway.

## Evidence

- `src/commands/startup-plugin-source-captures.test.ts`: the contention case failed on `main` because the unwanted warning was emitted. It passes now, along with 10 controls covering permission failures, other lock failures, and authority ordering (11/11).
- Blacksmith Testbox run https://github.com/openclaw/openclaw/actions/runs/36322123304: oxfmt and `node scripts/check-changed.mjs` pass.
- Independent Codex autoreview through P2 is clean (0.94). It confirmed the typed predicate is exact and that no real failure is hidden.
- LOC: production +18/−6, tests +35/−3, docs +4/−2.
```
