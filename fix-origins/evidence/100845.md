## Fix PR #151432 description (by steipete, opened 2026-09-18T05:46:15Z)

```text
Related: #150153

## What Problem This Solves

macOS Gateway discovery can miss binary service definitions or read a nested environment label as the service's identity.

## User Impact

Discovery, command inspection, and system-service ownership use the actual top-level plist fields from the same captured definition. Valid date/data metadata is accepted; invalid command fields remain rejected.

## Why This Change Was Made

Use one native plist decoder and remove the duplicate regular-expression and path-based readers. This focused extraction from #150153 reduces production source by 99 lines and changes no service restart policy.

## Evidence

Native XML/binary regressions fail before the repair. Final focused validation passes 575 cases, including four real native macOS plist cases, with nine Linux-only skips. Native cases use macOS plutil on synthetic scratch definitions; no operator service was changed. Runtime build/import checks, changed checks, production/test types, lint, and independent P0–P2 autoreview pass.

An initial CI run exposed 14 fixture failures: three callers did not model the two-stage native plist conversion. The repaired fixtures reproduce all 14 original failures and pass afterward, with unchanged production code. A later run hit the upstream messaging test-shard size limit, fixed on main by #151564. Both reviewed patches were refreshed unchanged onto that fix; current-head CI is required before landing.

The refreshed hosted run failed one Gateway activation assertion. The exact original 72-file order subsequently passed 2,102 tests on both candidate and parent on Linux Node 24.19.0, and on the candidate on macOS. The activation/config/runtime/runner owners are unchanged by this PR. No source, assertion, or timeout was changed; the underlying intermittent failure remains unexplained. The paired Testbox was stopped and verified absent, and only the failed hosted jobs were rerun. Exact-head CI run35322038980 is now green.
```
