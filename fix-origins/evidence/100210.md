The existing attachment admission directive observes the actual text chip and the identities in a comment group. Authorization and source resolution stay with the existing renderer; bounded body reads stay with the preview components.

History pasted-text and grouped comment chips load their details near the viewport or when focused. Keyboard focus stays on the same chip while metadata loads. Comment bodies still load only when the preview is revealed; composer attachments keep their current behavior.
