## What Problem This Solves

Long-running subagents can disappear from activity counts and stop blocking another spawn or parent settlement even while their current execution owner or exact queued reservation remains active. Recent ownerless routing records can also be reported as live executors.

## User Impact

Subagent lists, status counts, spawn-capacity checks and unfrozen parent settlement retain work that this process can prove is still owned. Saved routing metadata alone no longer proves an executor is running. Quiet workers were already preserved by the sweepers; this patch does not claim to fix workers being killed.

## Why This Change Was Made

Reuse the existing live-context and exact collector-reservation predicates for retained accounting, and correlate compact read projections with the matching raw generation without granting those projections mutation authority. Recent unowned rows retain the existing bounded grace period. Terminal and suspended-delivery rules remain unchanged.

This is separate from #122849's ACP lifecycle ownership and #126924's wait-expiry classification. Both exact-head overlaps were assessed and the narrow shared-file boundary posted on those PRs. No ACP task, spawn, stop, cleanup, wait-result or persistence implementation is added here. No existing contributor patch is replaced.
