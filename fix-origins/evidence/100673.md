## What Problem This Solves

Fixes conflicting widget instructions after gateway restart recovery: an agent could be told to keep a visualization inline even when the current turn only supported a pinned dashboard widget, then deliver a temporary browser link instead of the intended widget.

## User Impact

Agents receive consistent guidance for the current widget surface and a direct next step for opening a pinned widget's dashboard tab. Existing tool arguments, capability checks, and normal success receipts stay unchanged.

## Why This Change Was Made

Show Widget now describes the same resolved presentation route that execution uses, including channel presenters. Dashboard defers to that placement decision. The shared embedded/Codex prompt, Visualize skill, and docs direct agents to the widget's chat or dashboard surface rather than its internal hosting URL.
