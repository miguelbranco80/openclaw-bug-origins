## What Problem This Solves

Fixes: collapsed work summaries show failures without the total, making a mostly successful run look unsuccessful.

## User Impact

Users see **Worked · 200 tool calls · 20 failed**. Runs without failures still show the total; narration-only turns omit it. Duration labels and expandable details remain unchanged.

## Why This Change Was Made

The denominator gives failures context without asking users to add succeeded and failed counts. Prepared activity remains authoritative for its messages, while raw-only calls contribute without collapsing anonymous calls or double-counting identified call/result pairs.

Current main’s canonical skipped outcome now supplies the skipped count. The generic outcome list excludes both failed and skipped labels, so each appears once. Superseded local skip normalization and visibility handling were removed.
