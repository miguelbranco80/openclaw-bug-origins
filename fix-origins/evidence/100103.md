```text
## What Problem This Solves

Fixes: QA Lab chat debug endpoints fail or advance their cursor when AIMock records a non-chat request in the shared journal.

## User Impact

User impact: QA scenarios can inspect chat request snapshots after image or other non-chat AIMock traffic without receiving an internal error or a misleading chat cursor.

## Why This Change Was Made

The QA journal wrapper now records debug observations only for chat-completion bodies while leaving all AIMock journal entries available to their owning endpoints. The bridge remains compatible with AIMock 1.42.1 and forwards the optional fixture argument so the subsequent 1.43.0 update can preserve upstream journal behavior.

## Evidence

- Regression reproduced before the fix: a non-chat image entry advanced the chat debug cursor from `1` to `2`.
- Focused AIMock server suite: 14/14 passed on AIMock 1.42.1.
- Extension typecheck and repository-selected changed checks passed.
- Independent P0/P1 autoreview: scoped clean.
- `pnpm test:extension qa-lab` was blocked before Vitest by the managed-Gateway artifact isolation preflight.
- The all-extension package-boundary runner completed all 127 child compiles without a reported compile failure, then hung during final aggregation and was stopped after bounded process/lock inspection.
```
