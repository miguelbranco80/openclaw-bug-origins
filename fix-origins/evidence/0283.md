```text
Related: https://github.com/openclaw/openclaw/issues/119720

## What Problem This Solves

Session accounting can keep loading and decoding up to 512 transcript bodies after finding the latest usage and current-turn taint boundary. Large payloads turn that unnecessary work into synchronous database and decompression overhead.

## User Impact

Accounting stops reading bodies once all requested facts settle. Native SQLite regressions demonstrate three required body reads instead of 512 for the covered tail, while preserving usage, taint, branch selection and the conservative candidate limit. Required-body or navigation corruption still fails conservatively; unrelated older body corruption does not invalidate settled accounting.

## Why This Change Was Made

Select the bounded path from compact navigation before lazily reading bodies. The shared reducer stops iteration when finished; resident and durable readers share the selection/reduction policy. Only imported duplicate-ID paths whose logical order differs from physical order buffer their bounded selected set.

History and accounting now share exact navigation parsing, retaining only selected navigation fields. Missing parent fields stay distinct from explicit invalid parents. Escaped Unicode and deep SQLite inputs retain their bounded raw parsing path; literal NUL corruption fails conservatively. This repairs the initial plaintext-retention finding without retaining complete candidate bodies.

No schema, configuration, cache, retention or authorization changes. Production delta: +116 lines; tests: +329. The production growth establishes lazy payload ownership and consolidates navigation handling across the two readers.
```

```diff
+import { sql, type Expression } from "kysely";

+const navigationFields = {
+  type: true,
+  id: true,
+  parentId: true,
+  targetId: true,
+  appendParentId: true,
+  appendMode: true,
+  firstKeptEntryId: true,
+  customType: true,
+  display: true,
+} as const;
+
+export function readTranscriptNavigation(eventJson: string): Record<string, unknown> | undefined {
+  const selected = Object.keys(navigationFields);
+  const fields = scanJsonObjectFields(eventJson, selected);
+  if (!fields.valid || fields.maximumDepth > 1000 || !eventJson.trimStart().startsWith("{")) {
+    const parsed: unknown = JSON.parse(eventJson);
+    if (!isRecord(parsed)) {
+      return undefined;
+    }
+    // Invalid and SQLite-overdepth rows retain the original JSON.parse fallback.
+    return Object.fromEntries(
+      selected.filter((key) => Object.hasOwn(parsed, key)).map((key) => [key, parsed[key]]),
+    );
+  }
+  const navigation: Record<string, unknown> = {};
+  for (const key of selected) {
+    const token = fields.last.get(key);
+    // Parentless entries are distinct from malformed explicit parents in the tree owner.
+    if (token) {
+      navigation[key] = JSON.parse(token.text);
+    }
+  }
+  return navigation;
+}
+
+/** Keep tree/reset facts compact without changing exceptional raw-JSON handling. */
+export function projectTranscriptNavigationForReadSql(
+  database: EngineConnection,
+  event: Expression<string>,
+) {
+  const projected = jsonObjectFieldsForScan(database, event, navigationFields);
+  // SQLite can transcode escaped lone surrogates in native string aggregation.
+  // Keep those bytes for the lexical reader, which retains only navigation fields.
+  return isPostgresSqlConnection(database)

+    : /* kysely-allow-raw: preserve escaped Unicode before SQLite aggregates decoded strings. */ sql<string>`CASE WHEN instr(${event}, ${String.raw`\u`}) > 0 THEN ${event} ELSE ${projected} END`;
```
