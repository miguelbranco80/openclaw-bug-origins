## User Impact

Operators get an explicit stop/build/start recovery path before source builds replace serving artifacts. Failed source builds restore prior output; native recovery refuses to mutate a reassigned service.

## Why This Change Was Made

The installed-definition inventory feeds the real build, tsdown, and run-node entrypoints. Private profile and command facts bind each discovered service; public extra-service output retains its existing shape. A pre-build observation does not lock every sibling against starting during compilation, and unavailable inspection does not establish absence. The current-main carry removes a retired forwarding helper and invokes the same retained recovery object directly; it adds no replacement owner or alias.
