## Fix PR #147458 description (by steipete, opened 2026-09-13T21:44:13Z)

```text
## What Problem This Solves

Subagent activity rows lead with a generic label, making concurrent child tasks difficult to distinguish in web and macOS chat.

## User Impact

Activity rows now lead with the child task's display title, including its configured label, and show its status separately. Blank or missing titles retain the existing generic labels.

## Why This Change Was Made

Both clients use the canonical title already supplied by the Gateway. Progress remains a separate preview, and existing task ownership, expiry, and detail actions remain unchanged.

## Evidence

- 16 focused web regressions passed, including named and unnamed tasks, status changes, accessible detail actions, and terminal activity.
- Production UI typecheck passed with a frozen physical dependency install.
- Mock-Gateway browser flow, stylesheet lint, localization verification, and native target compilation passed.
- Independent review found no actionable P0–P2 findings.
- Real provider turn on an isolated Gateway completed a file read, named child task, yield, and final response. The web client displayed **Check mobile layout** with **Completed** status; seven real task events covered its lifecycle. A second turn sent through the signed native composer also completed read/spawn/yield/final; its child appeared as **Check button spacing** with **Finished** status. The original native client showed **Subagent finished** for the same task.
```
