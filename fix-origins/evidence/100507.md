## Fix PR #188146 description (by shakkernerd, opened 2026-10-30T06:31:19Z)

```text
Fixes #188131

## What Problem This Solves

A scheduled review can finish inside its existing Control UI conversation, save its work, and display the answer, while the automation still reports failed completion and “Not delivered.” This happens when announce delivery has no external messaging route: the shared-session runner treats missing channel coordinates as a delivery failure even after the existing conversation writer commits the answer.

## User Impact

A persistent same-conversation announcement now records successful delivery when its settled answer is actually committed to that destination. Users can rely on the completion state without configuring an unrelated messaging channel or sending the review elsewhere. The answer remains a single conversation result; this does not fabricate a transport or message-tool send.

Explicit external destinations, remembered external routes, unavailable creating conversations, and different source/execution destinations remain outside the internal fallback. Native-only payloads that cannot produce a conversation entry remain undelivered. Supported main-session aliases use the existing Cron key resolver. Quiet runs, deliberate silence, cancellation, and current session/operator authority retain their existing owners and behavior. There is no configuration, schema, or public protocol change.

## Why This Change Was Made

The existing session-event settlement path already owns the useful conversation write. It now preserves the writer’s committed-versus-skipped result and returns the fact that a write committed, which the scheduled runner consumes only when the internal destination is the same session. The runner rechecks the current delivery route before that commit and preserves its existing occurrence and authority fences.

This keeps result persistence and delivery policy with their current owners. It avoids another dispatcher, duplicate result writes, error-text matching, or treating successful computation alone as delivery evidence. The focused regression extends the existing integration fixture, with a small test-line allocation for internal delivery, deliberate silence, and a genuinely unavailable external destination.
```
