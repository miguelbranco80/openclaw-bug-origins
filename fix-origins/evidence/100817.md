## What Problem This Solves

Nested menus lost the vertical end alignment of a side-opening parent. In the compact sidebar identity menu, a long Gateway submenu consequently used the smaller space below its trigger and clipped Gateway settings despite enough room above.

## User Impact

Users can reach Gateway settings from the compact sidebar even when the submenu opens near the bottom of the window. Existing mobile menu behavior stays the same.

## Why This Change Was Made

Forward side-end placement to each nested Menu, choosing the side from its text direction. A plain accessor keeps the compiler from allocating a conditional memo when the anchor reads the placement in `onSettled`. Keep top/bottom placement behavior, CSS anchor flipping, height limits, existing classes, and the shared menu lifecycle unchanged.
