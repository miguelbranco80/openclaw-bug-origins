## What Problem This Solves

Fixes excessive throttling of agent commands on non-rotational Linux storage when delegated exec isolation derives disk bandwidth from RAM. A 4 GiB exec memory allowance currently permits only 6.8 MiB/s, regardless of the backing device.

## User Impact

Non-rotational state devices get an aggregate agent-exec ceiling of 160 MiB/s in each direction and 40,960 IOPS per direction, applied at Gateway startup. Gateway IO remains outside the exec ceiling. Rotational or unidentified devices retain the existing conservative policy, and finite ancestor limits still reserve half of each corresponding rate for peers. No new configuration or deployment action is introduced.

## Why This Change Was Made

Choose the budget at the existing startup owner using the logical device's kernel rotational attribute. Keep md/dm at their existing accounting boundary without traversing or separately charging member devices. This removes RAM/device-count coupling for solid-state storage without adding startup disk benchmarks, caches, or an unmeasured latency-controller target.

Related: #188379.

+### Agent exec resource isolation
+
+On systemd 254+ with cgroup v2, managed Gateway units use `Delegate=yes` and
+`DelegateSubgroup=gateway`. systemd places the launcher and Gateway in the
+`gateway` leaf before they spawn children. This leaves the service cgroup empty,
+as required before enabling controllers for sibling cgroups.
+
+Runtime detection reads the process's own `/proc/self/cgroup` membership and
+checks the delegated subtree's writable controls and available controllers.
+Exec helpers discover the same kernel-owned policy; no environment setting
+enables isolation. Without writable delegation, OpenClaw leaves the cgroup
+layout unchanged and reports the missing prerequisite once at startup.
+
+OpenClaw places host agent-exec process trees in the sibling `agent-exec` cgroup.
+Its CPU weight is `10`, compared with the Gateway leaf's default `100`; these are
+relative shares during contention, not a fixed CPU cap. Aggregate `memory.high`
+reuses the host exec memory allowance: the smaller of one quarter of available
+host/container memory and half that memory remaining after Gateway RSS.
+Existing per-exec memory limits and child-first OOM policy still apply.
+`memory.high` applies reclaim pressure; it is not a hard memory limit.
+
+An aggregate `io.max` ceiling budgets a memory-sized IO backlog over five
+minutes, split equally between reads and writes and across devices backing the
+Gateway state directory. Each direction receives `memory.high / 600 / deviceCount`
+bytes per second and that rate divided by `4096` operations per second. Half of
+any finite ancestor IO limit further caps the corresponding rate. This is a
+deliberate pressure budget, not measured disk bandwidth: a 4 GiB memory allowance
+on one device gives about 6.8 MiB/s in each direction. Gateway IO remains outside
+the exec ceiling.

+`openclaw doctor --fix` or `openclaw gateway install --force`. Normal updates
+preserve the existing delegation policy, including units without delegation;
+shutdown-policy refreshes do not opt the unit in. For a custom unit,

+const cgroupMount = "/sys/fs/cgroup";
+const budgetKeys = ["rbps", "wbps", "riops", "wiops"] as const;
+type IoBudget = Record<(typeof budgetKeys)[number], number>;
+
+function readOptional(file: string): string {
+  try {
+    return fs.readFileSync(file, "utf8").trim();
+  } catch (error) {
+    if (hasErrnoCode(error, "ENOENT")) {
+      return "";
+    }
+    throw error;
+  }
+}
+
+function ioBudget(root: string, device: string, bytesPerSecond: number): IoBudget {
+  const budget = {
+    rbps: bytesPerSecond,
+    wbps: bytesPerSecond,
+    riops: Math.max(1, Math.floor(bytesPerSecond / 4096)),
+    wiops: Math.max(1, Math.floor(bytesPerSecond / 4096)),
+  };
+  for (let ancestor = root; ancestor !== cgroupMount; ancestor = path.dirname(ancestor)) {
+    const line = readOptional(path.join(ancestor, "io.max"))
+      .split("\n")
+      .find((entry) => entry.startsWith(`${device} `));
+    for (const field of line?.split(/\s+/u).slice(1) ?? []) {
+      const [key, value] = field.split("=");
+      for (const dimension of budgetKeys) {
+        if (key === dimension && value !== "max" && Number(value) > 0) {
+          budget[dimension] = Math.min(
+            budget[dimension],
+            Math.max(1, Math.floor(Number(value) / 2)),
+          );
+        }
+      }
+    }
+  }
+  return budget;
+}

+    try {

+      fs.accessSync(path.join(leaf, "cgroup.procs"), fs.constants.W_OK);
+    } catch (error) {
+      if (!hasErrnoCode(error, "ENOENT")) {
+        throw error;
+      }

+    // An earlier successful startup must not remain discoverable after a failed refresh.
