## Fix message body

```text
fix(ui): give repeated session, worktree and MCP app buttons specific names

Several repeated buttons in the Control UI had the same generic accessible name on every row (for example each session menu, worktree action and MCP app settings button), so screen reader users navigating by button name could not tell which row a button belonged to. Each button name now includes its row's label, keeping the visible label as the prefix.

Evidence: built Gateway serving the built Control UI, Chromium accessibility tree. On main the catalog session rows, sessions table, worktree actions and MCP app settings buttons had generic names (twice); with this change each names its row, for example "Catalog Project A" and "Catalog Project B" (twice). Worktree create/delete/restore and MCP app settings navigation still work. Screenshots: https://github.com/openclaw/openclaw/pull/178140#issuecomment-6328147202. Production +4/-2.

Requested in Discord #clawtributors. Thanks @etzelm.

Co-authored-by: Ayaan Zaidi <hi@obviy.us>
```
