```text
Related: #201130, #201493

## What Problem This Solves

ChatGPT subscription model discovery sends OpenClaw's calendar version to a Codex-maintained API. The backend's client-version gates therefore receive a version from the wrong release stream.

## User Impact

Subscription discovery reports a stable Codex client version independently of OpenClaw releases. The first discovery after cache expiry can wait up to one second for npm; a registry failure still allows discovery using the bundled Codex version.

## Why This Change Was Made

Resolve npm's latest stable `@openai/codex` version, cache successful lookups for six hours, and use bundled Codex `0.169.0` as both the minimum and registry-failure fallback. Failed lookups are retried on the next discovery attempt. Responses attribution and Codex binary selection/update behavior remain independent.

This removes the calendar-version/`99.0.0` selection and reuses the existing guarded HTTP transport and catalog cache. A contract test keeps the floor aligned with the bundled dependency; test planning schedules that contract for pin changes. The existing Responses wrapper fixture moves into its existing support module to satisfy the line-cap ratchet, with its assertions preserved.
```
