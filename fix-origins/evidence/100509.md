## Fix PR #171765 description (by vincentkoc, opened 2026-10-14T05:08:33Z)

```text
## What Problem This Solves

The Mantis desktop browser smoke reserves the shared `beast` machine class for a single browser screenshot and short recording, without building or syncing the repository.

## User Impact

`desktop-browser-smoke` defaults to `tiny`. Explicit `--class`/`--machine-class` and environment overrides still win. Slack desktop and visual tasks retain `beast`; borrowed leases retain their existing lifecycle.

## Why This Change Was Made

The shared session resolver already accepts command-specific defaults. This adds the class to that existing boundary and supplies it only from the browser smoke command. Provider selection, native profiles and explicit server-type handling stay with Crabbox.

Release-note context: Mantis browser smoke uses a smaller default machine; no configuration migration or new option.

## Evidence

- Actual production browser smoke passed on Hetzner `ccx13` (2 vCPU, 7.56 GiB usable) and AWS Linux x86_64 `t3.small` (2 vCPU, 1.86 GiB usable). Both retrieved a 1920×1080 PNG and playable 10-second H.264 recording, passed full decode/frame checks, and completed exact-lease native cleanup. These cover an x86 Linux 2 GiB machine; they are not a full provider or ARM matrix.
- A production entry-point probe reproduced `beast` before this patch and passes `tiny`, environment, explicit and blank-value precedence after it, without allocating a machine.
- [Hosted regression job](https://github.com/openclaw/openclaw/actions/runs/38517199458/job/115698959606): 13 files / 106 tests passed, including those overrides, successful borrowed-lease reuse without warmup/stop, shared runner checks, and unchanged Slack/visual defaults. Local Vitest could not start because this code-only checkout has no dependency install; the hosted job supplies execution proof.
- Targeted formatting and `git diff --check` pass. Raw cloud media and private host metadata are not published.
```
