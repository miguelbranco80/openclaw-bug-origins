## What Problem This Solves

Fixes Ctrl+C leaving camera and location reads waiting for node lookup to respond or time out, including the legacy paired-node lookup.

## User Impact

Interrupted reads close their lookup connection and exit 130 without starting a node operation. Lookup uses the existing command cancellation owner; already-dispatched mutation RPCs retain their response custody.

## Why This Change Was Made

The shared node resolver now forwards the command's existing signal to both lookup methods. This closes the preparation gap without adding state, a lifecycle owner, or caller-specific cancellation plumbing.
