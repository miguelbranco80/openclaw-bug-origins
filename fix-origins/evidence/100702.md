```text
* fix(embedded-agent-runner): re-admit persisted user turn once on admission race

A persisted user turn whose replay admission raced a background delivery
mirror was dropped instead of replayed. Refresh admission once when the
work start changed or the transcript read fence moved between preparation
and consumption; select() still re-validates message equality and
interrupted-ness on every attempt, so newer-user, terminal, abort, and
authority changes still refuse admission.
```

## Fix PR #181473 description (by SunnyShu0925, opened 2026-10-23T07:46:10Z)

```text
Closes #179562

## What Problem This Solves

Fixes an interrupted persisted user turn failing replay admission when a background Workshop notice changes its transcript before dispatch.

## User Impact

The pending turn can resume once without asking the user to resend it or persisting a duplicate user message. Completed replies and replaced sessions remain replay barriers.

## Why This Change Was Made

Refresh replay selection once after a pre-admission transcript change, retaining the original user anchor, generation, and live writer checks. Preserve the existing Workshop notice marker through channel delivery so background notices cannot be mistaken for a completed foreground answer. The session-controller retry handles earlier custody and does not cover this admission boundary.

Thanks @SunnyShu0925 for the fix and original reproduction.

## Evidence

Two regressions append a real Workshop notice at the replay boundary: both fail on the base implementation and pass with this fix, asserting one provider call and exactly one persisted keyed user. The complete replay file passes 50 tests, including existing final-reply, reset, branch, writer, and lifecycle rejection coverage. Workshop notice tests pass 18 tests (27.72s including startup), and prompt-prefix stability passes all 11 tests. Focused proof ran on Linux through Testbox; the full replay file took 74.39s, with the two new cases taking 3.63s combined.

Targeted oxlint and oxfmt checks passed. Independent diff-scoped Codex review found no actionable P0–P2 findings. The patch is byte-identical to the reviewed change after merging current main. Production: +32 net lines; tests: +71 net lines against main. The bounded retry and marker propagation require the production growth; no extra retry state, lock, reservation, or schema was added.

Live Gateway/model timing reproduction was not independently rerun: reproducing this precise race would require another timing harness. The regression drives the real transcript and agent session loop with synthetic provider output. The contributor's earlier Gateway proof remains prior-head evidence.

Exact-head CI passed: [run 40081515016, attempt 1](https://github.com/openclaw/openclaw/actions/runs/40081515016) for `ad69b3e2317b5cd19aa326318280ab030c759dc9`; 38 jobs succeeded, 29 skipped, no failed or cancelled jobs.
```
