Fixes #200594

## What Problem This Solves

An update from 2026.11.4 to the 2026.11.5 candidate can roll back because rehearsal Doctor reports an intact cold transcript archive as missing. The copied agent database keeps its file-backed archive rows, but the snapshot omits their payloads.

## User Impact

Rehearsal now preserves the live representation: `storage='file'`, a null blob, and payload files at the copied store's resolved cold path. Missing referenced files stop capture; corrupt payloads retain the normal read-verification failure. No schema, config, or updater protocol change is required.

## Why This Change Was Made

The snapshot producer projects the files referenced by the copied rows, including chunk files. Regular immutable files use hard links; unsupported or cross-filesystem links fall back to a reflink or exclusive byte copy. Symlinks receive independent copies. The source database and archive bytes remain unchanged.

Link safety follows the existing cold writer: [`session-accessor.sqlite-archive-artifact.ts:203–225`](https://github.com/openclaw/openclaw/blob/f40dedc91a81ea1afd28ff43de15813dfae90f2b/src/config/sessions/session-accessor.sqlite-archive-artifact.ts#L203) verifies and reuses an existing file, or publishes a new inode exclusively. It never overwrites an existing cold payload. Reset only unlinks its selected name ([`session-accessor.sqlite-reset.ts:193`](https://github.com/openclaw/openclaw/blob/f40dedc91a81ea1afd28ff43de15813dfae90f2b/src/config/sessions/session-accessor.sqlite-reset.ts#L193)). The projector does not chmod shared inodes.

Inventory measures referenced payload sizes through a metadata-only read snapshot. Those bytes enter the historical `pluginBytes` wire allowance ([`update-candidate-state.ts:235`](https://github.com/openclaw/openclaw/blob/f40dedc91a81ea1afd28ff43de15813dfae90f2b/src/infra/update-candidate-state.ts#L235)), which released parents already include in their free-space and I/O-time estimates. This reserves the full copy fallback even when linking is cheap, excludes orphans, and avoids decoding payloads or embedding them into SQLite.
