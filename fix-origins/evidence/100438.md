## What Problem This Solves

Fixes: the macOS live updater indefinitely defers an update when a Gateway conversation remains active.

## User Impact

Updates can finish through a bounded, recovery-preserving interruption. Pending lifecycle writes still prevent the Gateway from stopping; older idle-only residents continue to defer safely.

## Why This Change Was Made

Reuse the existing maintenance-drain owner with the installation's trusted built control client and validated LaunchAgent binding. It closes admission, verifies write custody, and commits shutdown against the serving process before native bootout. The adapter revalidates the maintenance lock, checkout, service environment, and resident identity.

## Evidence

- New updater boundary cases failed against the previous helper and pass with this change: ordinary active work reaches committed shutdown before build; held write custody refuses stop/build and resumes the lease.
