```text
Related: #171385

## What Problem This Solves

Fixes Gateway startup refusing its own state ownership in a PRoot Ubuntu container with `GatewayLockNamespaceError`.

## User Impact

The Gateway can start when PRoot exposes the PID namespace link but cannot follow it with `stat()`. Unreadable or malformed namespace identities still refuse ownership; foreign-owner and heartbeat rules are unchanged. Thanks @caozhongbin for reporting this.

## Why This Change Was Made

Read the kernel namespace inode from `readlink("/proc/self/ns/pid")`, which returns `pid:[inode]`, instead of following PRoot's synthetic target. This preserves the existing identity format and admission policy without treating unknown identities as matching or adding a same-PID shortcut. No public API, dependency, or schema changes.

## Evidence

- Real before/after through `pnpm openclaw gateway run` on Linux arm64, Node 24.21.0, Ubuntu 22.04.5, using unmodified Termux PRoot source at `7f2fab0fb3a9e15f63ac47497ebc29d72281206e`. The baseline refused its own fresh owner; the patched Gateway reached `ready`, returned HTTP 200 from `/healthz`, and both `gateway health --json` and `gateway call health --json` returned `ok: true` with exit code 0. State and ports were isolated.
- Real main-thread and Worker probes both reproduced `stat()` failing with `ENOENT` while `readlink()` succeeded; the patched production namespace reader returned matching valid identities.
- Regression failed before the production fix. All 108 focused namespace, owner-lease, Gateway lock, and Doctor tests passed afterward. Core and affected test typechecks, scoped lint/format, runtime builds, and diff checks passed. Independent review found no actionable findings.
- An earlier generic upstream PRoot 5.4 run passed namespace admission but aborted in `readlink_proc` before readiness. The unmodified Termux fork completed the full proof above. Actual Android hardware, x64 PRoot, and Bun were not exercised locally; the reporter should retest on the next release.

The production change replaces one probe; test growth covers the readable-link/stat-failure regression and malformed-link refusal. Release-note context: restore Gateway startup in PRoot Ubuntu containers while preserving ownership checks.
```
