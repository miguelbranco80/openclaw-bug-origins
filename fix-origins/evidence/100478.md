Refs #144689 (the separate per-agent startup isolation design; this PR does not close it).

## What Problem This Solves

Fixes an issue where users updating an older multi-agent installation could remain stuck in Doctor when one agent directory contained a byte copy of another agent's database. Repeated `doctor --fix` runs refused the entire migration and left the Gateway unable to start. Context: Discord support report 2026-09-10.

## Why This Change Was Made

The accepted repair scope is strict duplicate recovery: before either database migrates, Doctor verifies the complete database file sets and archive dependencies, checkpoints under its existing maintenance lease, and rechecks byte equality. It preserves the misplaced copy through the existing `.corrupt-<timestamp>` recovery owner, clears the stale registration, and lets the agent acquire a fresh store. Startup preflight consumes this recovered state; it has no separate recovery path.

Divergent or unverified copies remain refused and preserved. Doctor gives the owning agent, exact path, and an explicit operator quarantine command, while continuing independent state migrations. Repairs depending on the refused database, including deferred session repairs, remain blocked. Gateway startup with an unavailable agent is deliberately left to #144689. No schema, configuration option, dependency, or new recovery filename convention is introduced.

## User Impact

Updates can complete automatically when the misplaced database is a verified duplicate. Operators retain the preserved copy and see its location in the warning. Divergent histories are kept intact, and unrelated state repairs are no longer stranded behind that refusal.

Release-note context: Doctor now recovers misplaced duplicate agent databases during upgrades; divergent ownership conflicts retain actionable diagnostics and permit independent state repairs to finish.

+function filesEqual(left: string, right: string): boolean {
+  const leftStat = fs.lstatSync(left, { bigint: true, throwIfNoEntry: false });
+  const rightStat = fs.lstatSync(right, { bigint: true, throwIfNoEntry: false });
+  if (!leftStat || !rightStat) {
+    return !leftStat && !rightStat;
+  }
+  if (
+    !leftStat.isFile() ||
+    !rightStat.isFile() ||
+    leftStat.nlink !== 1n ||
+    rightStat.nlink !== 1n ||
+    (leftStat.dev === rightStat.dev && leftStat.ino === rightStat.ino) ||
+    leftStat.size !== rightStat.size
+  ) {
+    return false;
+  }
+  const leftFd = fs.openSync(left, "r");
+  try {
+    const rightFd = fs.openSync(right, "r");
+    try {
+      const a = Buffer.allocUnsafe(1024 * 1024);
+      const b = Buffer.allocUnsafe(a.length);
+      for (let offset = 0; offset < leftStat.size;) {
+        const aRead = fs.readSync(leftFd, a, 0, a.length, offset);
+        const bRead = fs.readSync(rightFd, b, 0, b.length, offset);
+        if (aRead === 0 || aRead !== bRead || !a.subarray(0, aRead).equals(b.subarray(0, bRead))) {
+          return false;
+        }
+        offset += aRead;
+      }
+      return (
+        sameFileMutationFingerprint(leftStat, fs.fstatSync(leftFd, { bigint: true })) &&
+        sameFileMutationFingerprint(rightStat, fs.fstatSync(rightFd, { bigint: true })) &&
+        sameFileMutationFingerprint(leftStat, fs.lstatSync(left, { bigint: true })) &&
+        sameFileMutationFingerprint(rightStat, fs.lstatSync(right, { bigint: true }))
+      );
+    } finally {
+      fs.closeSync(rightFd);
+    }
+  } finally {
+    fs.closeSync(leftFd);
+  }
