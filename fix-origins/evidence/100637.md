## Fix message body

```text
The deferred lifecycle owner for CLI-backed runs (such as claude-cli) didn't record the logical turn start. `chat.history` therefore returned `inFlightRun` without `startedAt`, and the Control UI restarted the working timer every time the session was reopened during a turn. The owner now keeps the real turn start time.

Proof: built main and candidate Gateways with a slow stub `claude` CLI, with `chat.history` read twice during the turn. Main omitted `startedAt` in both reads. The candidate returned the same value both times, matching the traced lifecycle start. Embedded-provider runs are unchanged, and completed runs clear `inFlightRun`. The regression test fails on main and passes here.

Co-authored-by: Rogério Chaves <rogerio@langwatch.ai>
Co-authored-by: Ayaan Zaidi <hi@obviy.us>
```

```text
Related: #119728

## What Problem This Solves

Fixes: the Control UI "Working... Ns" timer restarts from about 1s every time you reopen or reload a session whose turn runs on the claude-cli runtime.

## User Impact

User impact: the working timer shows the real elapsed time of a long claude-cli turn after a session switch, reload or mobile page restore, instead of resetting to zero.

## Why This Change Was Made

#119729 added `startedAt` to the `chat.history` in-flight snapshot, taken from the active run owner. When a logical turn hands off to the CLI runtime, the deferred lifecycle manager registers a new owner handle without `startedAtMs`, so the snapshot has no `startedAt` and the UI falls back to now. This records the turn start when the lifecycle manager is created and puts it on the CLI owner. The time belongs to the whole turn, so retries and fallbacks before the handoff are counted too.

## Evidence

- Live check on a long claude-cli run: `chat.history` returned `inFlightRun` with `runId`, `text`, `sessionAbortable: true` and no `startedAt`.
- New regression test "keeps the logical turn start time on the CLI owner" (fake clock, 5 minutes between manager creation and CLI handoff, checks the owner `startedAtMs`). Fails before the fix (`undefined`), passes after.
- `pnpm test src/agents/embedded-agent-runner/run/deferred-lifecycle-owner.test.ts --maxWorkers=1`: 15 passed, about 46s on a shared box.
- No UI code changes; the UI already uses `startedAt` when the server sends it.
```
