## What Problem This Solves

Fixes missing or stale selected styling on plugin-contributed sidebar pages when navigating between pages, using browser history, or adding page filters.

## User Impact

Plugin pages such as Workboard now show the same active icon and full-width selected row as built-in pages, and lose that highlight when you leave them.

## Why This Change Was Made

Native plugin navigation did not subscribe to route changes and compared the entire URL string. It now uses the existing lifecycle-managed router subscription and matches the destination's path and explicit parameters, while allowing unrelated page filters. The shared sidebar sizing rule also reaches the link inside the plugin's layout-transparent wrapper.

## Evidence

Live before/after on an isolated Gateway with the bundled Workboard plugin, at 1440×900 and 390×844. Before: Workboard remains highlighted after opening Automations, and its row is too narrow. After: only the current page is highlighted, and Workboard fills the same row width as built-in pages. No browser errors in either run.
