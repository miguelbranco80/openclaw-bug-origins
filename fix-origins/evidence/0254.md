## What Problem This Solves

Fixes: a new chat request receives no agent reply when a teammate is copied with an incidental mention such as `Please make poster previews. cc @Bob`.

## User Impact

Requests with copied teammates now run the agent and still notify those teammates. Messages beginning with a selected person remain human-only unless the agent is also named. No configuration or migration is required.

## Why This Change Was Made

The human-addressing classifier treated every selected person as the addressee, even when the mention followed an agent request. Require the selected person to lead the message before suppressing the agent. Notification authorization, delivery, transcript persistence, and explicit agent-name overrides keep their existing owners.

This deliberately uses a simple positional rule rather than guessing intent from prose: greetings or other text before a person mention keep the agent turn.
