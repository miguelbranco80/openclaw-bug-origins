## What Problem This Solves

Fixes repeated Doctor warnings after a legacy Skill Workshop backup has a complete history-only archive and its original workspace is no longer configured.

## User Impact

Operators can retire the old workspace mapping without recurring backup-migration warnings. Original backups remain retained, and incomplete, changed, or aliased archives remain visible for review. No configuration, CLI, dependency, or stored-format change is required.

## Why This Change Was Made

The collection-backup migration owner now verifies completed archives across configured agent backup locations before resolving current workspace ownership. Verification covers the matching history-only manifest and the entire saved workspace, including metadata, empty directories, large files, and copied links. The archive root must be an independent directory; it cannot merely point back to the source. Pending backups still use the existing whole-root workspace-ambiguity and migration checks.
