## Fix PR #147374 description (by pheidon, opened 2026-09-13T20:13:56Z)

```text
Related: #142302.

## What Problem This Solves

Fixes empty discovered model lists for deferred provider plugins when a working API key is configured as a non-environment SecretRef.

## User Impact

Discovered models remain visible with file, exec, and store-backed credentials, without copying keys into plaintext config or adding manual model rows. Unresolved references and credentials retained in generated catalogs still do not admit inventory. No configuration or migration is required.

## Why This Change Was Made

Registry admission now recognizes the existing secrets owner's matching, already-materialized runtime credential. The check uses it only as availability evidence; it does not resolve the SecretRef again or put credential values into model rows. An adjacent validation simplification preserves empty-model behavior and error ordering while keeping production LOC neutral.

Original fix and regression coverage by @pheidon; the contributor commit is preserved. Main was merged into this branch without rebasing. Production: +8/-8. Tests: +101/-0. Documentation: +6/-0.
```
