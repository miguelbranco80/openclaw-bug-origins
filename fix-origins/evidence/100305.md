## Fix PR #153040 description (by steipete, opened 2026-09-19T16:43:25Z)

```text
## What Problem This Solves

Opening a chat downloads full automation definitions just to populate the sidebar Inbox badge, including prompts and commands the badge never uses.

## User Impact

Inbox transfers substantially less data while preserving failed, overdue, running, and automatically disabled job handling. Automation editing, access checks, pagination, and dismissal behavior stay intact. No configuration changes or production data migration are required.

## Why This Change Was Made

Inbox now uses the existing compact automation inventory, with the four facts its alerts need: agent identity, update time, active-run time, and automatic-disable status. Full and compact readers share pagination and snapshot recovery; the automation editor retains complete definitions. The automation tool output schema accepts these facts while preserving older compact and full inventory responses.

The browser fixtures return the correct inventory shape. The plugin settings test verifies that Save submits the current hash and edited configuration; the mock configuration regression preserves acknowledged snapshots across immediate reload, including distinct applied hashes and continued revisions. The mention-flow test waits for its own filtered refresh instead of inspecting the last session-list request across independent consumers. SQLite test teardown now awaits database shutdown.

The disclosure focus ring also gains permanent horizontal padding so it does not crowd the label.

Its event phase now advances the actual 200 ms debounce with a fake clock, preserving the one-request, 400-row, and exact page-size assertions. All 471 sidebar cases pass before and after the change; targeted lint/formatting and fresh independent review pass. Exact-head hosted CI passed on `d2f08f001cec5779de5a6ca139ff5988c3c106cc`: 157 successful jobs and 13 skipped. The full check rollup is green.
