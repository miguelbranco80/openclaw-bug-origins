## Fix PR #202071 description (by daniel-lxs, opened 2026-11-19T21:26:38Z)

```text
Fixes #202045

## What Problem This Solves

A Gateway on a new install accepts connections only from its own computer. When an owner tries to create their first phone setup code, the dialog reports a configuration error and leaves them to figure out how to make the Gateway reachable.

## User Impact

**Connect a device** guides phone pairing through **Set up secure access** and announces that title to screen readers. Choose Tailscale Serve, a trusted home network, or an existing public HTTPS address. **Device** pairing keeps its existing setup error and **Reload** action.

## Why This Change Was Made

The Gateway sends a structured detail for the loopback refusal and keeps the error message available to the CLI and other setup flows. The Dashboard uses the detail only for phone pairing and keeps the instructions outside the title’s live region.

The Dashboard leaves configuration changes to the owner. Tailscale Serve keeps the Gateway on loopback and encrypts connections. The trusted-home-network option opens a plaintext LAN listener and explains how to undo it. Phone codes created over plaintext LAN have Limited access, which includes chat history and approvals.
```
