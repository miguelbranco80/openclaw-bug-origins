## What Problem This Solves

Deleting a retired worktree can still accumulate large btrfs metadata reservations despite fixed unlink batches. Apparent file sizes and entry counts do not bound outstanding delayed-reference work, and fast commits or low PSI do not establish low reservation pressure.

## User Impact

Retired-tree deletion now pauses when its btrfs filesystem has at least 40 GiB of metadata reservations and resumes below 20 GiB. The existing 128-entry/8-MiB batches and 100-ms pacing remain. Background cleanup may take longer under pressure. Retention, lossless capture, orphan recovery, and symlink protections are unchanged; no configuration or schema changes.

## Why This Change Was Made

The existing host-pressure probe accepts the retired root and binds its btrfs counter once through mount identity and backing-device identity. Hysteresis avoids resuming immediately below the high watermark. Non-Linux, non-btrfs, missing devices and inaccessible counters keep ordinary pacing. This does not add a poller, scan cache, or deletion owner.

The change waits for normal draining rather than forcing shared-filesystem commits. One indivisible unlink and other writers can exceed the watermark, so this is not a hard filesystem reservation cap. Persistent pressure remains subject to the existing 30-minute child timeout and retained-directory recovery.

+async function readKernelCounter(filePath: string): Promise<string> {
+  try {
+    const file = await fs.open(filePath, "r");
+    try {
+      const buffer = Buffer.alloc(4096);
+      const { bytesRead } = await file.read(buffer, 0, buffer.length, 0);
+      return buffer.toString("utf8", 0, bytesRead);
+    } finally {
+      await file.close();
+    }
+  } catch {
+    // Unsupported kernels, unmounted filesystems, and restricted proc/sys mounts
+    // still get the caller's unconditional pacing.
+    return "";
+  }
+}

+/** One maintenance owner samples host counters; no background poller or retained filesystem list. */
+export function createHostIoPressureProbe(): () => Promise<boolean> {
+  let previous = new Map<string, { commits: number; totalMs: number }>();
+  return async () => {
+    if (process.platform !== "linux") {
+      return false;
+    }
