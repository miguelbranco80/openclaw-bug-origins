```text
Related: #174888

## What Problem This Solves

Fixes: a temporary session row flashes under the agent's row in the Control UI sidebar when you create a new session while the sidebar is in **Show all** agents mode.

Reported by @Patrick-Erichsen.

## Work sessions

- [Discussion, implementation and verification](https://team.openclaw.ai/chat/roboclaw/~key/dashboard/da1d5329-2ac9-481a-bd77-b439a24555de)

## User Impact

User impact: creating a session from the **Show all** agent roster no longer flashes a row that disappears a moment later. The session list (chip) view still shows its provisional row, because that is where the new session actually lands.

## Why This Change Was Made

#174888 placed the pending new-session row in its "sidebar destination". The roster, though, became agent-only and never lists sessions, so that row was rendered under the agent (and below the pinned gallery) for one `sessions.create` round-trip and then dropped once the session was admitted. This change takes the provisional row out of the roster and pinned paths and keeps it only in the session list. The renderer no longer needs the agent filter.
```
