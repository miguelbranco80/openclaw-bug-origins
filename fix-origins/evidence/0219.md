## What Problem This Solves

Fixes: read-only Gateway callers can see host filesystem paths in `system.info`, including the state directory.

## User Impact

Read-only callers retain state-volume capacity totals but no longer receive `diskPath` or `disks`. Admin callers keep mounted-disk details and the state-directory fallback. Read-only Control UI connections consequently show no per-disk meters. No configuration or migration is required.

## Why This Change Was Made

The RPC uses the existing admin-scope check to decide whether to collect and return paths, matching the connection snapshot's state-directory policy. It skips mounted-disk discovery for non-admin callers and keeps the existing capacity sampler. No new state, cache, or policy owner is introduced; the added code covers the scoped response and its regression test.
