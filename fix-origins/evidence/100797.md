## Fix PR #152024 description (by steipete, opened 2026-09-18T17:55:40Z)

```text
## What Problem This Solves

Fixes the initial prompt disappearing while a cloud session starts, and provisioning progress appearing beneath the composer instead of in the conversation.

## User Impact

The submitted prompt remains visible while the worker provisions. Opening a session that is already provisioning also shows progress in the conversation. Sending, retry, and recovery behavior stay unchanged.

## Why This Change Was Made

Share the initial-turn presentation between the eager startup owner and its lazy runtime, preserving attachment identities across the handoff. Feed worker setup into the existing transcript progress indicator. Keep attachment restoration in a small shared module so immediate presentation does not pull the attachment-send implementation into startup.
```
