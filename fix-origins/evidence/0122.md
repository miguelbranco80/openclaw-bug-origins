## Fix PR #203613 description (by roboclaw-bot, opened 2026-11-22T19:45:04Z)

```text
## What Problem This Solves

In the chat transcript, double-clicking the empty gap between messages can select just a newline. WebKit paints that selection as a blue strip across the whole conversation column, even though neither message is highlighted.

## User Impact

Clicking the gap clears a selection instead of creating one. Dragging from text in one message into another still selects the words without coloring the space between them. No settings or migration are required.

## Why This Change Was Made

The transcript distinguishes a press on the empty row from a press on its contents. Message text, keyboard selection and message actions keep their native behavior; the row no longer paints the space around its contents. This preserves click-to-clear from #199123.

## Evidence

Compared the unmodified main build (`f1a6dbd25380`) with the fix (`a72a8b08cf80`) using synthetic messages in the real Control UI. WebKit selected a newline before and nothing after. Cross-message drags preserved the text range; the gap pixels stayed unchanged. Verified blank clicks, normal text selection and Select All on the built UI in Chromium and WebKit.

The UI built, and formatting and stylelint passed. The original build reported the same two size-budget warnings on unmodified main.

Maintainer verification on `5c692744fd21`: native single presses still allow a drag that begins in the gap. The corrected WebKit regression runs in the existing WebKit-enabled chat history suite. All 10 focused E2E cases passed in Chromium and WebKit on Studio.
```

```diff
+  const target = event.target;

+function boundMessageSelection(bubble: Element) {
+  const selection = bubble.ownerDocument.getSelection();
+  if (!selection || selection.isCollapsed || selection.rangeCount !== 1) {
+    return;
+  }
+  const range = selection.getRangeAt(0);
+  if (
+    !range.intersectsNode(bubble) ||
+    (bubble.contains(range.startContainer) && bubble.contains(range.endContainer))
+  ) {
+    return;
+  }
+  // Intersect only this multi-click gesture; ordinary drags and Select All stay native.
+  const backwards =
+    selection.anchorNode === range.endContainer && selection.anchorOffset === range.endOffset;

+    bounded.setEnd(contents.endContainer, contents.endOffset);
```
