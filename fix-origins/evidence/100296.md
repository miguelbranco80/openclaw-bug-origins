## What Problem This Solves

Fixes Chat and tool tabs pointing assistive technology at the wrong content after swapping panels or opening the same conversation in split panes.

## User Impact

Each tab identifies its own named content region in its own pane. Swapping Chat and Tasks preserves the association and live content. Closing a tab keeps keyboard focus in the correct tab group.

The shared side-panel container excluded Chat and reused the same ID across panes. The existing pane presentation identity now scopes stable Chat/tool regions and tab IDs. Tabs target their actual region instead of the shared container; layout and live iframe roots stay in place. Existing tab-strip callers with one shared content target retain their behavior.
