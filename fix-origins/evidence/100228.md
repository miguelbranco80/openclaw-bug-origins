## Fix PR #162294 description (by steipete, opened 2026-10-01T02:16:54Z)

```text
## What Problem This Solves

Chat boot downloads the whole Review side panel (file, attachment, PDF/HTML preview and diff views) before anyone opens it. `chat-sidebar.ts` imported `chat-detail-panel.ts` for its side effect, so the panel and its subtree sat in the measured boot groups. The same subtree then also reached New Session's boot set, even though New Session already loads the panel lazily. When this PR was opened, that eager subtree pushed the largest boot chunk to 217.1 KiB, over the 215 KiB budget. `main` has since brought the budget back under separately (198a4bed8b03 narrowed the shared partition size), so this PR is now about boot bytes, not the budget.

## User Impact

Chat and New Session boot no longer download the Review panel. It loads on first open, behind the panel's existing review loading skeleton, the same way the terminal, browser, desktop and other side panels already load. Tool output in the side panel still renders immediately.

## Why This Change Was Made

The sidebar already owns lazy panel elements (`LAZY_SIDEBAR_ELEMENTS` / `ensureLazySidebarElement` in `chat-pane-sidebar-layout.ts`), with loading, error and stale-chunk recovery. The Review panel was the one element still registered eagerly. This change:

- drops the side-effect import from `chat-sidebar.ts`, which is now a type and helper barrel;
- makes `renderChatDetailSlot` load `openclaw-chat-detail-panel` through `ensureLazySidebarElement` under a non-slot `detail-panel` key, the same pattern `region` uses. Only the panel branch waits; tool output, the slot's loading state and the unavailable callout stay synchronous;
- regenerates `ui/config/control-ui-boot-modules.json` with `pnpm ui:boot-manifest:gen` (current generator from #162382);
- updates tests that imported `chat-sidebar.ts` only to define the panel so they import `chat-detail-panel.ts` directly.

No budget, `maxSize`, minifier or naming changes.

Compared with a fresh regeneration of `main` (`a272cf0cd56e`), the PR's manifest has identical route entries. It drops 25 modules from `shared`: the panel subtree leaves boot entirely, and 12 modules New Session only reached through the eager panel (file view, diff render, draft recovery and others) move to the `chat` group. The manifest's remaining differences from `main`'s committed file are `main`'s own drift since its last regeneration; regenerating unmodified `main` produces the same drift (+95 shared modules).

Earlier in the window, camera capture (#160253) and the draft recovery dialogs (#159414, #158213) landed in the same directory run.

On that base this PR measured 217.1 → 203.4 KiB for the largest chunk, while a regeneration-only control stayed at 217.1 KiB.
```
