## What Problem This Solves

Fixes: cancelling a Gemini web search still allows citation redirect requests to run, including later batches.

## User Impact

Cancelling a Google search cancels active citation requests, prevents further citation requests, and preserves the caller's cancellation reason without caching a late result. Ordinary redirect failures still keep the original citation URL.

## Why This Change Was Made

Forward the search's existing AbortSignal to the citation resolver, which owns cancellation checks and guarded HEAD requests. The optional parameter preserves existing one-argument callers. This replacement covers cancellation; the original proposal's citation-admission optimization remains a separate follow-up.

Removed redundant header branching and the single-use header-cache-key binding in the same Google owner, preserving case-insensitive Headers.set precedence. Citation enrichment updates the provider's newly created objects directly, removing duplicate arrays and copies. Production delta: zero lines; tests: +63 lines.
