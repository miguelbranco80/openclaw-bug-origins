## Fix PR #151336 description (by roboclaw-bot, opened 2026-09-18T03:07:57Z)

```text
Related: #134939 (Android native UI parity).

## What Problem This Solves

Fixes: user messages change bubble width when delivery completes, and the assistant's working indicator uses different geometry from the reply that follows it.

## User Impact

User impact: queued, failed, recovered, streaming, and confirmed messages keep consistent geometry for their speaker without losing delivery actions or message actions.

## Why This Change Was Made

One existing bubble container now owns role-specific width, fill, padding, and corners. Confirmed messages delegate their shell to it while keeping the message-action host around the complete bubble; the duplicate pending-message shell is removed.

## Evidence

- Final independent candidate: 55 selected tests and `:app:ktlintCheck` passed. All three targeted regressions failed against the original production source with identical final tests.
- Full ChatScreen captures cover queued/working, failed/working, recovery, streaming, and confirmed states. The confirmed before/after capture is intentionally byte-identical; Retry/Delete visibility and relevant reader/disclosure siblings remain covered.
- Fresh P0/P1 local autoreview: scoped-clean against base `71b4bc427ac22cf4d477556299f5253e3843c334`.
- Proof uses native Robolectric production UI with synthetic data, not an installed device or live Gateway.

- Published source head: `ca75b487cf8e04b936f31cb6986f69e22e429634`. Hosted CI: [passed](https://github.com/openclaw/openclaw/actions/runs/35302526213) for this exact head, including Android Play/ThirdParty/Wear, Kotlin style, native i18n and the required CI gate.
```
