## What Problem This Solves

Fixes: expanded native chat steps show a generic “Exec — outcome unknown” title instead of the tool's local title when the Gateway has no terminal status for the call.

## User Impact

User impact: those steps use the native tool title, with the existing command/detail line. This does not turn an unknown outcome into success: unknown outcomes visibly retain “No result” on iPhone as well as in accessibility and on desktop. The shared row is used by both iOS and macOS.

## Why This Change Was Made

The Gateway deliberately substitutes an outcome-unknown title for ended calls without a status. Native chat already has a tool display registry; it now uses that local title in this one case and retains Gateway titles for other activity states. The linked issue is broader outcome-projection context, not a claim that this PR fixes missing outcome facts. Fold labels, step counts, and the working line are unchanged.
