## Fix PR #153836 description (by roboclaw-bot, opened 2026-09-20T16:22:42Z)

```text
## What Problem This Solves

Fixes New Session doing nothing while keyboard-shortcuts help is open, and the composer losing focus when reopening a warm New Session page.

Related: #153537.

## User Impact

Cmd/Ctrl+Shift+O closes shortcut help and focuses a New Session draft. Cmd/Ctrl+/ closes help without navigation. Returning to an already loaded New Session page keeps typing in the composer. Existing drafts, permissions, approval dialogs, and archive safeguards are preserved.

## Why This Change Was Made

Help owns its two permitted navigation chords and releases its modal before handing off to the existing session action. Drawer cleanup restores focus only when the drawer was actually open, rather than stealing focus during ordinary desktop navigation.
```
