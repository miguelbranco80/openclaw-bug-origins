## Fix PR #165291 description (by roboclaw-bot, opened 2026-10-05T02:48:32Z)

```text
Related: #164558

## What Problem This Solves

Fixes finished tool-authored replies hiding sibling failures, disappearing beside terminal tools, repeating pre-tool narration, or delivering content that result middleware withdrew.

## User Impact

Plugin tools can return a finished answer without a model restatement while unfinished or failed sibling work still receives a continuation. Only the originating input's preamble is replaced; earlier and later answers and errors remain visible. No configuration migration or automatic tool opt-in is introduced.

## Why This Change Was Made

Capture and completion now share the finalized batch after result rewriting. Codex keeps candidates private until the upstream response closes and every model-emitted call has an eligible result; raw receipts cover late request registration and native siblings. Explicit terminal siblings retain their completion contract without dropping a finished reply. Canonical assistant identity keeps reused call IDs distinct and recovery idempotent.

Reply content comes only from `details.sourceReply`. Calls nested inside Code Mode return data to that program, never an implicit send. Codex's direct-reply fast path requires the model-only `direct-only` catalog. Existing message-tool delivery remains separate.
```

+By default the model reads every tool result and writes the user-visible reply
