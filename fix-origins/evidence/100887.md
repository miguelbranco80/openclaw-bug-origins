## What Problem This Solves

Fixes local audio transcription selecting the wrong executable when a home-relative PATH entry traverses a symlink followed by `..`.

## User Impact

Local audio uses the executable reached by the configured PATH entry, preserving its precedence over lexical and later PATH decoys. Home directories containing the platform PATH delimiter remain intact. No configuration migration is required.

## Why This Change Was Made

Local audio now uses the shared executable resolver instead of maintaining a second lookup and cache. Home expansion passes prepared directory entries so delimiter characters and filesystem traversal semantics survive resolution. The change retains the existing empty-entry and cache-invalidation contracts.
