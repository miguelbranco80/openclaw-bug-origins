## Fix PR #180186 description (by roboclaw-bot, opened 2026-10-22T02:22:48Z)

```text
## What Problem This Solves

Fixes: pinned agents in the sidebar agent roster show a kebab button whose menu only offers Create Claw, so you can't unpin a pinned agent, open its Settings or Sessions, or delete it.

## User Impact

User impact: right-clicking a pinned agent (or pressing Shift+F10 / the context-menu key while it is focused) opens the same agent menu that unpinned roster rows use: Unpin, Sessions, Create Claw when Claws are enabled, Settings, and Delete. Pinned tiles no longer show a kebab. The pin item reads **Pin** with an outlined pin for unpinned agents and **Unpin** with a filled pin for pinned agents. Unpinned rows keep their kebab and also open the menu on right-click.

## Why This Change Was Made

Pinned tiles and roster rows now build their menu from one shared item list and selection handler, so the two surfaces can't drift apart again. Right-click and the keyboard shortcut open that menu at the pointer through the existing point-anchored menu trigger, the same way session rows open their context menus. Unpinning moves keyboard focus to the agent's roster row, matching how pinning focuses the new tile.

Touch: Android long-press fires `contextmenu`, so the menu opens there. iOS Safari doesn't fire it, so pinned tiles on iOS have no menu. That matches the menu-less pinned gallery from before Create Claw added a kebab.
```
