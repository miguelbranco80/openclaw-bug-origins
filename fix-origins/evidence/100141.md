## Fix PR #149318 description (by steipete, opened 2026-09-15T18:09:44Z)

```text
## What Problem This Solves

Sidebar attention icons say a session needs an answer or approval without explaining the request. Collapsed agent headers also hide their attention indicator when hover or keyboard focus reveals the action buttons.

## User Impact

Hover or keyboard-focus an attention icon to see the oldest pending question, compact command, or approval title, with a count of additional requests of the same kind. This works in the regular session list, Home, and the agent roster, including collapsed groups. Session rows remain compact, and collapsed-header attention stays accessible beside its actions.

## Why This Change Was Made

The browser already receives the request details. This change carries a bounded preview through the existing attention projection, preserves priority tiers, and uses creation order within the question/approval tier. Existing resolution and expiry events remove settled requests. Question previews read request text only; entered answers and credential drafts are excluded.

## Evidence

- Tested the running candidate in Chrome against an isolated real Gateway with synthetic sessions, question requests, and approval requests. Verified keyboard tooltips, additional-request counts, oldest-request selection, answering in the question card, cancellation, denial, and automatic expiry without reloading. - Focused sidebar/approval tests and UI typecheck passed. After rebase: 478 sidebar/tree tests and 26 browser E2E cases across question flow, approval flow, Home attention, and sidebar geometry. Geometry covers four cases covering 258–334 px widths, light/dark themes, touch, keyboard access, and action overlap.
```
