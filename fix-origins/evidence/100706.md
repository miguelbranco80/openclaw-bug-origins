Fixes contradictory repair advice and SQLite sidecar creation when an older OpenClaw build inspects state written by a newer release. Related: #166906 and #166857.

## User Impact

Doctor, Gateway startup, update status, and offline database preflight consistently recommend a compatible newer build or restoration of the backup matching the older build. They preserve the newer database's bytes, mtimes, and SQLite sidecars. No schema, migration, configuration option, CLI option, or dependency changes.

Reuse the existing newer-schema classification and artifact-preserving reader.
