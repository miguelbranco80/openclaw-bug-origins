## What Problem This Solves

Opening or refreshing Model Setup emits Solid 2's `STRICT_READ_UNTRACKED` diagnostic from route synchronization.

## User Impact

No rendered behavior changes. Model Setup keeps editable drafts and focus during rescans, and still waits for route data before starting detection.

## Why This Change Was Made

Model Setup's effect already captured route data, but discarded that value and reread the reactive prop during its apply phase. Solid 2 reports `STRICT_READ_UNTRACKED` during the existing refresh flow. Pass the captured value to the initial synchronization instead. Later selection and Gateway callbacks explicitly read current route data, preserving their dispatch-time behavior. The route argument is required so a captured `undefined` cannot fall back to another reactive read.

The existing refresh test now rejects the diagnostic while retaining its draft and focus assertions. An additional case covers mounting without route data and confirms that no detection request starts. No JSX, CSS, host tags, request authority, or lazy boundary changes.
