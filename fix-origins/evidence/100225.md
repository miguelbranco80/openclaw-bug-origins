## Fix message body

```text
## What Problem This Solves

Fixes: unsaved input in a Dashboard MCP App disappears when the side panel is minimized and reopened.

## User Impact

Loaded apps keep their local state through the panel transition. Existing offscreen teardown, lease expiration, reconnect, and lazy first-load policies remain unchanged. No configuration or migration is required.

## Why This Change Was Made

The Solid board port (#168871) let the content renderer see the new active flag before the lifecycle published its new visibility. Reopening briefly looked like an active offscreen app and tore down its iframe. The existing cell snapshot now publishes activity with the observed visibility instead of mixing two revisions. No new state owner or retention exception is introduced.

No overlap with Pash/Sarah changes.

## Evidence

On current main `5889e62f4902b8f3fa4b6eb2cecbbd26f5b8ceb0`, the production-bundle E2E run of the three reported files had **1 failure / 17 passes**: the board retention case received an empty string instead of `Keep this unsaved dashboard note`. All nine history-prepend cases and all four chat-scroll cases already passed; main's `84fb3196ed5` repairs their history/follow owners, so they are not duplicated here.

With this fix, the unchanged complete `board-mcp-app.e2e.test.ts` passes **5/5**, including retention through split, expanded, minimized, and inactive states; reconnect replacement; renewal; and offscreen lazy loading. The retention case takes 2.797 s, and the full bundled command takes 23.19 s. No tests, expectations, retries, or timeouts changed. A separate original-source capture reproduces the empty-note failure in 18.065 s.

Command: `node scripts/run-vitest.mjs run --config test/vitest/vitest.ui-e2e.config.ts --configLoader runner --project ui-e2e-bundled --maxWorkers=1 ui/src/e2e/board-mcp-app.e2e.test.ts`

Focused checks: all **14** board MCP lifecycle unit cases pass, including active-offscreen teardown, inactive retention, expiry, and reconnect. `pnpm tsgo:ui`, scoped oxlint, oxfmt, the line-cap ratchet against `origin/main`, and `git diff --check` pass. Independent Codex review of the final diff is scoped-clean through P2.

### Before and after reopening

Both screenshots use the same synthetic app. Before, the iframe restarts at its initial scroll position and loses the note. After, it remains at the note with its input intact.

Two-way door: reverting restores the old panel-transition behavior. Blast radius is the board MCP App renderer; no stored data, Gateway behavior, or channel delivery changes.
```
