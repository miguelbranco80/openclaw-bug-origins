## Fix PR #171842 description (by shakkernerd, opened 2026-10-14T06:21:11Z)

```text
Closes #171782.

## What Problem This Solves

A parent session outside a publishable repository can create a managed child whose tool policy permits GitHub publication, yet the child permanently loses `github_publish`. The inherited allowlist is captured from the parent's available tools after workspace discovery has omitted the publisher. The child's valid managed worktree cannot recover that missing name.

## User Impact

New children retain permitted publication when the parent cannot publish from its own workspace. The child still needs an eligible workspace and must pass the Gateway's publication checks. Existing children keep their recorded policy; this change does not retroactively widen them.

Explicit denies and restrictive profile, sender, sandbox, runtime, and inherited policies continue to apply. Publication credentials remain on the Gateway, and the parent's unavailable publisher stays hidden. Default sandbox allowances, publication destinations, PR editing, and merge permissions are unchanged by this PR.

## Why This Change Was Made

The capture owner now passes the real unavailable publisher definition through the existing parent policy pipeline before recording the child ceiling. It removes that definition from the parent's returned tools and cron authority. The built-in runner carries the permitted definition through its later capture refresh, including the final runtime restriction, so bundled-tool preparation cannot erase it again. Native harnesses use the same capture owner. Worker-hosted turns retain the approved capture inside the Gateway turn runtime and apply later prompt restrictions before child creation; the worker catalog and parent execution grant remain unchanged.

This repairs the producer and callers of the inherited snapshot without changing the stored policy format or adding a tool-name exemption. The delegation documentation explains the distinction between parent workspace availability and inherited permission.
```
