## What Problem This Solves

Fixes Gateway event handling stalling when a child run finishes while another process holds the shared state database.

## User Impact

Child completion and cancellation wait for their terminal signal without blocking unrelated Gateway work. Signal kinds, payloads, deduplication, retention, and best-effort recording behavior stay the same; no migration or operator action is required.

## Why This Change Was Made

The normalized terminal producer used the synchronous signal writer, so its SQLite coordinator wait ran on the event loop. It now uses the existing state worker, and each caller joins settlement with its current lifecycle or actor ownership. Transaction and commit admission reject superseded, corrected, or provisional outcomes before they can consume the first-write-wins terminal key.

The ACP test fixture now installs its in-memory flow store before constructing the task store, so the task store uses that same fixture owner. Terminal cases and the shared coordinator holder are extracted from oversized suites without weakening their assertions or deadlines.
