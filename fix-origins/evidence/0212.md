## What Problem This Solves

A failed Talk catalog lookup tells already-connected users to connect to the Gateway. The Gateway settings page also shows retry guidance during a healthy connection.

## User Impact

Talk shows the actual lookup failure while preserving connection guidance for disconnected clients. The Gateway retry hint appears only for a failed disconnected attempt.

## Why This Change Was Made

The Talk error boundary now retains its error instead of presenting every failure as disconnection. The catalog handler returns the existing readable message for an ambiguous Talk agent, without logging-only exception names and codes. No agent selection or authentication behavior changes.
