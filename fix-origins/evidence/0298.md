## What Problem This Solves

## User Impact

Workspace operations avoid transferring unused fingerprint data while retaining unchanged-file hash reuse. Production disk and latency savings have not been measured.

The existing snapshot reader selects the fingerprint needed by scan/probe or archive and returns null for unused fingerprint fields. It keeps the same snapshot, revision checks, source-path hydration and prepared-tree lifecycle.
