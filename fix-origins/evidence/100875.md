## Fix PR #154682 description (by vincentkoc, opened 2026-09-21T09:30:14Z)

## What Problem This Solves

Fixes chat turns and task lists failing with "SQLite transaction admission was refused" when a busy Gateway takes longer than five seconds to service a worker authority request.

## User Impact

Accepted database operations wait for the live owner's decision instead of failing solely because the host was delayed. Revoked authority still refuses the operation. No configuration, schema, durability, retention, or permission changes; updating requires no migration or operator action.

## Why This Change Was Made

The worker independently expired a request that the host still owned, preventing a later valid grant. Keep the shared decision pending until the host grants or refuses it. Broker failure still terminates and joins the worker before releasing custody; coordinator-lock and broker-capacity deadlines are unchanged. This also removes the race between a late host grant and worker-side refusal.
