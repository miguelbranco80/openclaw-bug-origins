## Fix message body

```text
fix(mcp): don't split an emoji in mcp.events.list descriptions

mcp.events.list cut event descriptions at 4096 UTF-16 units, which could split an emoji and return a lone surrogate (invalid Unicode) to clients. The cut now uses the existing truncateUtf16Safe owner and stops at a whole character; paging is unchanged.

Evidence: built Gateway, mcp.events.list over the public RPC. On main a description ending in an emoji came back as 4096 units with a lone U+D83D (twice); with this change it is 4095 units of valid text (twice). Short descriptions and the next-page cursor are unchanged.

Thanks @wangmiao0668000666.

Co-authored-by: Ayaan Zaidi <hi@obviy.us>
```

## Fix PR #181741 description (by wangmiao0668000666, opened 2026-10-23T16:02:58Z)

```text
## What Problem This Solves

`mcp.events.list` could split an astral character at the existing 4,096 UTF-16-unit description cap and return a lone surrogate. Reuse `truncateUtf16Safe`, following #176207 and #176230, without changing the cap or MCP catalog contract.

## Evidence

Built main and candidate in isolated Node 24.22.1 Docker. Configured the bundled MCP Events plugin normally against an external loopback Streamable HTTP fixture implementing `server/discover` and `events/list`. Called the running Gateway through shipped `gateway call mcp.events.list --json`.

- Main, twice: 4,096 units, not well formed; actual RPC description ends `aaaaaa\ud83d`.
- Candidate, twice: 4,095 units, well formed; actual RPC description ends `aaaaaaa`.
- Both short-description/cursor controls: `short 😀 description`, 20 units, well formed; `nextCursor: page2` preserved.

Simplification keeps the existing truncation owner: production +2/-1 lines; tests +15/-0 against main. The focused regression protects the split-surrogate boundary.

Thanks to @wangmiao0668000666 for reporting and fixing this.

Two-way door: a revert restores the previous read-only projection. No persisted state or config changes. Blast radius is descriptions in MCP event discovery RPC responses.
```
