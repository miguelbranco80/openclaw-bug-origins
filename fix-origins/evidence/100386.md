```text
## What Problem This Solves

Fixes browser snapshots and page-text inspection exhausting their deadline when cached tab identities stall or concurrent requests recover a stale browser connection.

## User Impact

A healthy tab no longer waits through a separate timeout for every unresponsive sibling. Recovery keeps a newer connection usable and preserves existing blocked-tab protections.

## Why This Change Was Made

Resolve bounded tab-identity probes concurrently, then recheck blocked state before selecting a page. Evict only the failed browser instance instead of retiring all state for the endpoint. Consolidate an impossible two-tabs/one-page test fixture into the distinct-page regression coverage.

## Evidence

- Three regressions fail on the original implementation: ten stalled siblings exhaust the inspection budget, late recovery closes a replacement connection, and reconnecting clears blocked-target state.
- All 109 focused browser tests pass across page selection, connections, enumeration, and navigation guards. The 13 page-selection tests also pass after switching the test fixture to the existing deferred-promise helper.
- Extension production/test typechecks, targeted lint, selected changed-file guards, documentation links, formatting, and `git diff --check` pass.
- Independent Codex review found no actionable P0–P2 findings.

The original live timeout cleared during diagnosis, so its exact initial trigger is not conclusively established. The recovery defects and repairs are demonstrated by the regression tests.
```
