## Fix message body

```text
fix(codex): order checkpointed work before terminal reasoning so final-answer recovery succeeds

When terminal reasoning came after already-completed work, the Codex final-answer recovery snapshot put the reasoning first, so recovery rejected the turn (provenance_rejected) and the agent exited without an answer. The snapshot now keeps the checkpointed work first; verification is unchanged and no prompt text changes.

Evidence: built Linux Gateway with the real Codex app-server 0.164.0 and a local Responses fixture. On main the turn ran its command once, made no finalizer request, exited 1 and had no recovered answer in the CLI or history (twice); with this change it ran the command once, made one finalizer request, exited 0 and the answer appeared in the CLI and both history reads (twice). The normal order works on both refs. Details: https://github.com/openclaw/openclaw/pull/185310#issuecomment-6433406222. Production +8/-8.

Thanks @ericcaiwx-star.

Co-authored-by: Ayaan Zaidi <hi@obviy.us>
```
