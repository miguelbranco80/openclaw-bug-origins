## Fix PR #202616 description (by daniel-lxs, opened 2026-11-20T17:08:25Z)

```text
Closes #202578

## What Problem This Solves

A chat can spend minutes showing typing while Codex retries a model request, leaving people in the group unsure why the answer is taking so long.

## User Impact

Chats that show model-wait progress display “Still working. Retrying…” once while Codex retries. The notice clears when the reply arrives.

## Why This Change Was Made

The app-server’s `willRetry` notification feeds the same progress path as a wait for a model slot. The channel’s preview settings control whether that progress appears.
