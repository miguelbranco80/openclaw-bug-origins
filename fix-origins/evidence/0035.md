```text
fix(skills): let skills browse commands run with an invalid config

Fixes #130569.

The four `skills` browse commands are already marked to skip the config guard, but they still read config with the strict reader, so an invalid config made them fail. They now use the existing best-effort reader, so browsing works and shows local skills through the offline fallback. Skill installs and other mutations still use strict config checks and refuse an invalid config. Agent selection and Gateway fallback are unchanged.

Evidence: built CLI on Node 24.22.1 in secretless Docker, 40 real commands. Details: https://github.com/openclaw/openclaw/pull/191044#issuecomment-6577587419.

Thanks @zhangguiping-xydt.
```
