## Fix PR #185292 description (by roboclaw-bot, opened 2026-10-27T01:14:59Z)

```text
## What Problem This Solves

Fixes: saved highlighted-text comments appear in Side chat but cannot be submitted unless the user types a second question.

## User Impact

Users can send a saved selection/comment on its own, or include a written question. Image-only questions and image retries keep their existing behavior. No configuration or migration is required.

## Why This Change Was Made

The existing Side chat question resolver recognized typed text and image attachments but ignored selection comments. It now supplies a neutral question for selection-only input, so the Ask button and keyboard submission use the same existing attachment path. Selection limits, upload restrictions, and pending-read gates are unchanged. No new state or lifecycle machinery is added (production +3/-1 lines, English copy +1, tests +42/-14; documentation also corrects obsolete quote-prefill guidance).

Reported by @Patrick-Erichsen.
```

```diff
+export function SessionRailComposer(props: {

+  connected: boolean;

+  submit: () => void;

+  let textarea!: HTMLTextAreaElement;
+  createEffect(
+    () => props.companion.draft,
+    (draft) => {
+      if (textarea.value !== draft) {
```
