## What Problem This Solves

Updates must not abort because an optional progress receipt encounters a busy shared-state writer. This addresses the `updater-runtime-retention` incident in #168072. Thanks @jlapenna for the incident evidence.

The latest CI failure exposed a production classification bug: main retained additional timing steps for diagnostic history, while this PR used that retention list to decide which writes recovery requires. Retaining a timer accidentally made its write fatal under contention.

## User Impact

The update CLI explicitly allows required worker-backed writes up to 120 seconds for SQLite writer admission. Gateway-side callers keep their ordinary five-second budget. Optional progress and timing writes use a one-second budget, then warn and continue without claiming a committed receipt.

Recovery-critical phase, ownership, rollback, and failure receipts remain required. History eviction priority now has no effect on that decision. No schema, config, environment, CLI option, or dependency change is authored by this PR.

## Why This Change Was Made

`isRequiredUpdateRunStep` now owns an explicit recovery policy rather than borrowing `isRetainedStep` from bounded-history compaction. The recovery policy keeps phase transitions, finalization, driver identity, notice custody, reconciliation, database recovery diagnostics, rollback, and failed/signaled receipts. Timing-only retention, candidate, and handoff observations remain best effort.

The long budget is opt-in from the update driver's existing asynchronous writer path. SQLite owns native busy retries; no transaction is held while an application retry loop waits, and admitted mutations are not replayed. Mutation and commit restore the ordinary five-second budget. The separate Doctor fix invalidates the parent's schema admission after its child settles, using the child's effective state path.

The exact failing CI merge base (`c3fcd1554c3405c942bc03ec85fcbac8a0bb12a3`) was integrated normally, without rewriting history, so local proof includes main's new retained timing keys. The production fix is independent of platform timing.
