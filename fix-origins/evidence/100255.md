Closes #166643

## What Problem This Solves

Fixes: session previews show raw Markdown link syntax, or lose the rest of the message, when a link label contains brackets or a link URL contains parentheses.

## User Impact

User impact: session list previews, sidebar narration, and mention excerpts show `Read the Report [Q3] and then deploy.` instead of `[Report [Q3]](https://...` cut off at the preview limit, and links to URLs such as `report_(Q3)` or `report\)Q3` no longer leave `)` or `Q3)` behind.

## Why This Change Was Made

`flattenMarkdownToPlainText` (`packages/normalization-core/src/markdown-plain-text.ts`) matched links with `\[([^\]]+)\]\([^)]*\)`, which stops at the first `]` and the first `)`. A nested label never matched, so the whole link stayed and its long URL used up the preview budget. A balanced or escaped `)` in the URL ended the match early and left the rest of the URL in the text.

The link step now pairs each `[` with its balanced `]`, skipping backslash escapes, and keeps only the label of each `[label](destination)` or `![label](destination)`. After the label it reads the destination the way CommonMark defines it: a bare destination with balanced parentheses, or `<...>`, then an optional `"..."`, `'...'`, or `(...)` title, then `)`. Parentheses inside a quoted title no longer count toward the destination, so `[docs](url "Docs (v2")` flattens to `docs` and the prose after it stays. Brackets inside a destination or title are skipped while labels are paired, so they never close a label: `[![build](badge[.svg)](ci)` and `[![build](badge.svg "Build [main")](ci)` flatten to `build`, as they did on `main`. Only ASCII spaces and control characters end a bare destination, and only ASCII whitespace separates the destination from its title, as CommonMark defines them, so a URL holding a non-breaking space (U+00A0) still flattens: `[docs](https://example.com/a b)` becomes `docs`, as on `main`. The scan is iterative and linear, so deeply nested or unbalanced input cannot exhaust the stack or go quadratic. The other flattening steps are unchanged.
