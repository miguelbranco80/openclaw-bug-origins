## Fix message body

```text
Standalone Doctor's original-state capture failed with "Update recovery
manifest is missing a root entry" on installs that still carry an
unmigrated legacy memory index. memory-core declares
memory/<agent>.sqlite plus its -wal, -shm and -journal paths as file
resources. Capture recognized the base file as a SQLite database and

manifest failed its own validation before sealing.

Capture now omits roots that are sidecars of a captured database, and
the capture-reuse comparer skips the same declarations so an unchanged
install can reuse the sealed baseline.
```

```text

## What Problem This Solves

Fixes: `openclaw doctor --fix` cannot create its pre-repair recovery copy ("Update recovery manifest is missing a root entry") when the install still has an unmigrated legacy memory index at `state/memory/<agent>.sqlite`.

## User Impact

User impact: older installs with a legacy memory index get a sealed recovery copy before Doctor repairs state again, instead of an advisory capture failure on every `doctor --fix` run. Later Doctor runs can reuse that copy while nothing changed.

## Why This Change Was Made

memory-core declares `memory/<agent>.sqlite` plus its `-wal`, `-shm` and `-journal` paths as backup resources. Capture already recognizes the base file as a SQLite database by its header and records its sidecars through the database image, the same way it treats sidecars found inside directory roots, but it still listed the declared sidecar paths as roots, so the manifest failed its own completeness check before it was sealed. Capture now omits roots that are sidecars of a captured database (they stay protected paths), and the reuse comparer skips the same declarations. Sidecar-named paths whose base is not a database keep their own entries.

The reporter in #199580 also saw "Doctor could not complete maintenance". The capture failure is advisory and did not stop maintenance in the native repro below, so that second failure has a different cause that this change does not address.

## Evidence

  - capture fix with base reuse: fails (`expected undefined to be defined`, the sealed copy can't be reused)
  - both changes: passes
- Capture suites `doctor-capture-reuse`, `doctor-original-capture`, `doctor-migration-preservation`, `doctor-rehearsal-capture`: 25/25 pass.
- `pnpm tsgo:core` clean, `oxfmt` clean, test-line ratchet +23 of 400.

  - this head built with `pnpm build`, `node openclaw.mjs doctor --fix --non-interactive`: capture sealed (`manifest.json` present), no capture warning, `memory/main.sqlite` recorded as a SQLite file entry, its sidecar paths absent from `roots`.
```
