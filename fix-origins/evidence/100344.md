## Fix PR #188176 description (by vincentkoc, opened 2026-10-30T08:00:49Z)

```text
## What Problem This Solves

Code Mode can silently replace injected arrays with text when QuickJS exhausts its heap while initializing namespace values.

## User Impact

Injected state preserves its complete structure or fails visibly before later tools execute. Existing normalization, host detachment and headless deep freezing remain in place.

## Why This Change Was Made

Namespace producers already normalize values, and initialization transfers them into the guest. The controller copied each leaf again through JSON; its broad fallback converted an allocation failure into `String(array)`. Consume the guest-owned value directly.

This removes the redundant serialization/parse cycle. No dependency, configuration, memory-limit or executor-default changes. Production delta: +1 comment line; tests: +83 lines. The separately reproduced QuickJS catalog-constructor corruption remains a dependency follow-up.

## Evidence

- Before: 100,000 indexed rows at a 16 MiB guest heap became a string of length 1,599,999, reported completion and executed the sentinel tool. At 128 MiB every row was intact.

The pressure regression requires complete data or visible failure before the sentinel.
