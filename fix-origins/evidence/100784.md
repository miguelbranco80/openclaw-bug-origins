## What Problem This Solves

Fixes empty utility results when a local reasoning model spends its short output allowance entirely on thinking.

## User Impact

Titles, observer digests, progress narration, activity recaps, and transcript summaries request thinking off without changing ordinary chat reasoning, task timeouts, or unrelated model settings. No configuration changes or migration are required. Models that cannot disable reasoning still use their provider's supported minimum and can still exhaust a short budget.

## Why This Change Was Made

The previous reasoning reserve increased output allowances but did not turn thinking off. Utility preparation and the title/transcript callers now select off explicitly; the isolated owner does not add a reasoning reserve for off requests. The final one-shot payload hook keeps configured Ollama and OpenAI-compatible boolean thinking switches from re-enabling it, preserving other payload fields and native provider effort mappings.
