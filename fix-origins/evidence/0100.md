First chat requests can fail with storage-unavailable errors while an agent database is starting. Permissive fixture umasks also prevent Gateway tests from reaching that behavior.

## User Impact

Cold chat requests retain the existing database preparation instead of rejecting its first registration. Filesystem permission, routing, lifetime and source-identity guards remain enforced. No migration or configuration change is required.
